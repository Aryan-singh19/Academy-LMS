## 🌟 Features
- **Linear Aesthetic**: Beautiful dark mode, glassmorphism, and smooth animations using Tailwind CSS.
- **Deep Topic Coverage**: Includes rich descriptions, metaphors, tables, and Mermaid.js diagrams for complex topics.
- **Interactive Quizzes**: Multiple-choice knowledge checks at the end of every topic with instant feedback.
- **Unit Exams**: In-depth essay-style questions to test comprehensive unit knowledge.
- **No Build Step Required**: Built entirely using Vanilla JavaScript and Tailwind CDN for maximum simplicity and portability.

## 📂 File Structure
- \`index.html\`: The main Application Shell.
- \`js/app.js\`: Contains all routing, UI logic, and quiz evaluation scripts.
- \`js/data.js\`: The database. Contains the structural definition of courses, units, and the deep HTML content for topics.
- \`html/\`: Contains additional pages like schedules and resources.
- \`assets/\`: Contains images, diagrams, and static assets.

## 🚀 How to Run Locally
Simply open \`index.html\` in any modern web browser or serve it via a local HTTP server (e.g., \`python -m http.server 8000\`). No \`npm install\` required!
