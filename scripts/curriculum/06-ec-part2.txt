@ ec601 | EC-601 | Digital Signal Processing | Discrete-time systems, Z-transform, DFT/FFT, FIR and IIR filter design, multirate DSP and DSP processors.
# Discrete-time Signals & Systems
- Discrete-time Signals | DSP works on sequences of samples. | Unit Sample Sequence = δ[n] = 1 at n = 0, else 0 | Periodic Sequence = x[n + N] = x[n] for integer N | Energy of Sequence = Σ x[n]² over all n
- LTI Systems & Convolution | LTI systems are fully described by impulse response. | Linear Convolution = y[n] = Σ x[k] h[n − k] | Causal System = h[n] = 0 for n < 0 | Stable System = Σ of absolute h[n] is finite
- Difference Equations | Recursive equations describe digital filters. | Recursive System = output depends on past outputs | Non-recursive System = output depends only on inputs (FIR) | Zero-state Response = response with zero initial conditions
- Correlation of Sequences | Correlation finds similarity and delay. | Cross-correlation = r_xy[l] = Σ x[n] y[n − l] | Autocorrelation = correlation of a sequence with itself | Application = radar echo delay estimation
# Z-Transform & Frequency Analysis
- Z-Transform & ROC | Z-transform analyses discrete systems. | Z-Transform = X(z) = Σ x[n] z^(−n) | ROC = values of z for which the series converges | Unit Circle = z = e^(jω); Z-transform on it gives DTFT
- System Function & Pole-Zero Analysis | H(z) reveals stability and frequency response. | System Function = H(z) = Y(z)/X(z) | Causal Stable System = all poles inside the unit circle | Minimum Phase System = all zeros inside the unit circle
- Frequency Response | Frequency response is H evaluated on the unit circle. | Magnitude Response = magnitude of H(e^jω) | Phase Response = angle of H(e^jω) | Linear Phase = constant group delay, no phase distortion
- Inverse Z-Transform | Time sequences are recovered from X(z). | Partial Fractions = expand into first-order terms | Long Division = gives samples as power series | One-sided Z-transform = handles initial conditions in difference equations
# DFT & FFT
- Discrete Fourier Transform | DFT samples the DTFT at N points. | DFT = X[k] = Σ x[n] e^(−j2πkn/N) | Twiddle Factor = W_N = e^(−j2π/N) | Frequency Resolution = fs/N
- DFT Properties | Properties simplify computation. | Circular Shift = shift in time multiplies DFT by a phase factor | Circular Convolution = product of DFTs | Zero Padding = appending zeros to interpolate the spectrum
- FFT Algorithms | FFT reduces DFT complexity. | Radix-2 DIT FFT = splits even and odd time samples | Butterfly = basic two-point FFT computation | FFT Complexity = (N/2) log2 N complex multiplications
- Linear Filtering via DFT | Long signals are filtered in blocks. | Overlap-Add Method = adds overlapping output blocks | Overlap-Save Method = discards aliased output samples | Linear via Circular = zero-pad to length L + M − 1
# Digital Filter Design
- FIR Filter Design by Windowing | FIR filters truncate an ideal impulse response. | Window Method = multiply ideal h[n] by a window | Hamming Window = reduces side lobes compared to rectangular | Linear Phase FIR = symmetric impulse response
- Frequency Sampling Design | FIR filters designed from frequency samples. | Frequency Sampling = specifies H at equally spaced frequencies | Transition Samples = intermediate values reduce ripple | Optimal Equiripple = Parks-McClellan minimax design
- IIR Filters from Analog Prototypes | IIR filters map analog designs to digital. | Butterworth Filter = maximally flat passband | Chebyshev Filter = equiripple passband, sharper roll-off | Elliptic Filter = ripple in both bands, sharpest transition
- Bilinear & Impulse Invariant Transformation | Mappings convert s-plane to z-plane. | Bilinear Transformation = s = (2/T)(z − 1)/(z + 1) | Frequency Warping = non-linear frequency mapping in bilinear transform; prewarp | Impulse Invariance = samples analog impulse response; suffers aliasing
# Filter Structures, Multirate & DSP Processors
- Filter Realisation Structures | Same filter can be built in several structures. | Direct Form I = separate delays for input and output | Direct Form II = canonic form with minimum delays | Cascade Form = second-order sections in series
- Finite Word-length Effects | Quantisation affects digital filters. | Coefficient Quantisation = changes pole-zero positions | Limit Cycles = sustained oscillations from rounding | Overflow = result exceeds register range
- Multirate Signal Processing | Sampling rates are changed by decimation and interpolation. | Decimation = filtering then downsampling by M | Interpolation = upsampling by L then filtering | Polyphase Filter = efficient structure for multirate filtering
- DSP Processors | Special processors execute DSP efficiently. | MAC Unit = multiply-accumulate in one cycle | Harvard Architecture = separate program and data memories | Circular Buffer = efficient delay-line addressing

@ ec602 | EC-602 | Antennas & Wave Propagation | Antenna parameters, radiation from dipoles, arrays, practical antennas, measurements and propagation modes.
# Antenna Fundamentals
- Radiation Mechanism | Accelerating charges radiate electromagnetic energy. | Antenna = transducer between guided and free-space waves | Near Field = reactive region close to the antenna | Far Field = region beyond 2D²/λ where pattern is stable
- Radiation Pattern & Beamwidth | Patterns show how power is distributed in space. | Radiation Pattern = plot of radiated power versus direction | HPBW = half-power beamwidth between −3 dB points | Side Lobe = minor lobe outside the main beam
- Directivity, Gain & Efficiency | Parameters quantify antenna performance. | Directivity = maximum radiation intensity over average | Gain = directivity × radiation efficiency | Effective Aperture = Ae = Gλ²/(4π)
- Radiation Resistance & Polarisation | Antennas present resistance and polarisation. | Radiation Resistance = resistance accounting for radiated power | Input Impedance = impedance seen at antenna terminals | Polarisation = orientation of radiated E-field
# Wire Antennas
- Hertzian Dipole | Infinitesimal dipole is the basic radiator. | Hertzian Dipole = short current element much smaller than λ | Radiation Resistance of Short Dipole = 80π²(dl/λ)² | Doughnut Pattern = sin θ field pattern
- Half-wave Dipole | Most common resonant antenna. | Half-wave Dipole = length λ/2, radiation resistance about 73 Ω | Directivity of Dipole = 1.64 (2.15 dBi) | Folded Dipole = input resistance about 292 Ω
- Monopole & Loop Antennas | Ground planes and loops give other options. | Quarter-wave Monopole = λ/4 over ground, about 36.5 Ω | Image Theory = ground plane creates image doubling the antenna | Small Loop = magnetic-dipole-like radiator used in receivers
- Travelling Wave Antennas | Non-resonant antennas give broadband operation. | Rhombic Antenna = terminated travelling-wave antenna for HF | Beverage Antenna = long wire for low-frequency reception | Helical Antenna = circularly polarised in axial mode
# Antenna Arrays
- Array Fundamentals | Arrays combine elements for higher directivity. | Array Factor = pattern of isotropic elements in the array | Pattern Multiplication = total pattern = element pattern × array factor | Uniform Linear Array = equal amplitude and spacing elements
- Broadside & End-fire Arrays | Phasing steers the main beam. | Broadside Array = maximum perpendicular to array axis; zero phase difference | End-fire Array = maximum along the array axis | Hansen-Woodyard Condition = increased directivity for end-fire
- Binomial & Phased Arrays | Amplitude and phase control shape the beam. | Binomial Array = amplitudes follow binomial coefficients; no side lobes | Phased Array = electronically steers beam by phase shifters | Grating Lobe = unwanted lobe when spacing exceeds λ
- Yagi-Uda Antenna | Parasitic arrays give directional gain. | Yagi-Uda = driven dipole with reflector and directors | Reflector = slightly longer parasitic element behind | Director = shorter elements in front increasing gain
# Microwave & Special Antennas
- Horn Antennas | Flared waveguides radiate efficiently. | Horn Antenna = flared waveguide for microwave radiation | Pyramidal Horn = flared in both planes | Optimum Horn = flare chosen for maximum gain with acceptable phase error
- Parabolic Reflectors | Reflectors produce narrow high-gain beams. | Parabolic Reflector = focuses waves from feed into a plane wave | Focal Point = feed location | Cassegrain Feed = sub-reflector folds the optics
- Microstrip Patch Antennas | Planar antennas suit modern devices. | Microstrip Patch = metal patch on dielectric over ground | Fringing Fields = cause radiation from patch edges | Bandwidth Limitation = patches are narrowband
- Antenna Measurements | Patterns and gain are measured in ranges. | Anechoic Chamber = room lined with absorber for measurement | Gain Comparison Method = compare with a standard gain antenna | Far-field Range = test distance at least 2D²/λ
# Wave Propagation
- Ground Wave Propagation | Low-frequency waves follow the Earth's surface. | Ground Wave = surface wave guided along Earth, used below 2 MHz | Surface Wave Attenuation = increases with frequency | Vertical Polarisation = preferred for ground waves
- Sky Wave Propagation | HF waves reflect from the ionosphere. | Ionosphere = ionised layers D, E, F1, F2 | Critical Frequency = highest frequency reflected at vertical incidence | MUF = maximum usable frequency = fc / cos θ
- Space Wave Propagation | VHF and above travel by line of sight. | Line-of-sight Range = d ≈ 4.12(√h1 + √h2) km with heights in metres | Radio Horizon = 4/3 Earth radius model for refraction | Duct Propagation = trapping in atmospheric layers
- Skip Distance & Fading | Sky waves create zones and fluctuations. | Skip Distance = minimum distance where sky wave returns | Virtual Height = apparent reflection height | Fading = signal strength variation due to multipath and ionosphere

@ ec702-itc | EC-702(B) | Information Theory & Coding | Entropy, source coding, channel capacity, block codes, cyclic codes, convolutional codes and modern codes.
# Information & Entropy
- Measure of Information | Information depends on probability. | Self-information = I(x) = −log2 p(x) bits | Unit of Information = bit for log base 2 | Less Probable Events = carry more information
- Entropy | Entropy is average information. | Entropy = H(X) = −Σ p log2 p | Maximum Entropy = log2 M for equiprobable symbols | Entropy of Binary Source = maximum 1 bit when p = 0.5
- Joint & Conditional Entropy | Entropies describe pairs of variables. | Joint Entropy = H(X,Y) | Conditional Entropy = H(Y given X), remaining uncertainty | Chain Rule = H(X,Y) = H(X) + H(Y given X)
- Mutual Information | Mutual information measures shared information. | Mutual Information = I(X;Y) = H(X) − H(X given Y) | Non-negativity = I(X;Y) ≥ 0 | Symmetry = I(X;Y) = I(Y;X)
# Source Coding
- Source Coding Theorem | Average code length is bounded by entropy. | Shannon's Source Coding Theorem = L ≥ H(X) | Code Efficiency = H/L | Redundancy = 1 − efficiency
- Prefix Codes & Kraft Inequality | Prefix codes are instantaneously decodable. | Prefix Code = no codeword is a prefix of another | Kraft Inequality = Σ 2^(−li) ≤ 1 | Uniquely Decodable = every sequence decodes in only one way
- Shannon-Fano & Huffman Coding | Constructive algorithms build efficient codes. | Shannon-Fano Coding = recursive splitting into equal-probability halves | Huffman Coding = merges two least probable symbols repeatedly | Optimal Code = Huffman gives minimum average length
- Lempel-Ziv & Arithmetic Coding | Universal methods adapt to data. | Lempel-Ziv = dictionary-based coding without known statistics | Arithmetic Coding = encodes a message as a sub-interval of [0,1) | Run-length Coding = encodes repeated symbols compactly
# Channel Capacity
- Discrete Memoryless Channels | Channels are modelled by transition probabilities. | DMC = channel where each output depends only on current input | Channel Matrix = matrix of P(y given x) | Binary Symmetric Channel = crossover probability p for both symbols
- Channel Capacity | Capacity is maximum mutual information. | Channel Capacity = C = max I(X;Y) over input distributions | BSC Capacity = C = 1 − H(p) | Noiseless Channel = capacity log2 M
- Shannon-Hartley Theorem | Capacity of band-limited AWGN channel. | Shannon-Hartley = C = B log2(1 + S/N) | Shannon Limit = Eb/N0 of −1.6 dB as bandwidth → ∞ | Bandwidth-Power Trade-off = increasing B reduces required S/N
- Channel Coding Theorem | Reliable transmission possible below capacity. | Channel Coding Theorem = error probability can be made arbitrarily small if R < C | Code Rate = R = k/n | Converse = reliable communication impossible if R > C
# Linear Block & Cyclic Codes
- Linear Block Codes | Codewords are linear combinations of basis vectors. | (n, k) Code = k message bits mapped to n-bit codewords | Generator Matrix = G = [I P] in systematic form | Parity Check Matrix = H with GH^T = 0
- Syndrome Decoding & Hamming Codes | Syndromes locate errors. | Syndrome = s = rH^T; zero if no detectable error | Hamming Code = single-error-correcting code with n = 2^m − 1 | Standard Array = table used for syndrome decoding
- Cyclic Codes | Cyclic codes are generated by polynomials. | Generator Polynomial = g(x) divides x^n − 1 | Systematic Cyclic Encoding = remainder of x^(n−k)m(x) / g(x) gives parity | Shift Register Encoder = LFSR implementation of cyclic encoding
- BCH & Reed-Solomon Codes | Powerful cyclic codes correct multiple errors. | BCH Code = cyclic code correcting multiple random errors | Reed-Solomon Code = non-binary code correcting burst errors | Application = RS codes in CDs, QR codes and DVB
# Convolutional & Modern Codes
- Convolutional Encoding | Encoders have memory. | Constraint Length = K, number of shifts affecting output | Code Tree = tree representation of encoder outputs | State Diagram = encoder states and transitions

# Optical Fibre Fundamentals
- Optical Communication Overview | Light carries data through glass fibres. | Optical Fibre = thin glass waveguide carrying light | Advantages of OFC = huge bandwidth, low loss, EMI immunity | Optical Windows = low-loss bands near 850, 1310 and 1550 nm
- Total Internal Reflection | Light is guided by refraction at core-cladding boundary. | Total Internal Reflection = reflection when angle exceeds critical angle | Critical Angle = sin θc = n2/n1 | Snell's Law = n1 sin θ1 = n2 sin θ2
- Numerical Aperture & Acceptance Angle | NA measures light-gathering ability. | Numerical Aperture = NA = √(n1² − n2²) | Acceptance Angle = maximum entry angle for guided rays | Relative Index Difference = Δ = (n1 − n2)/n1
- Modes & V-number | Fibres support modes depending on V. | V-number = V = (2πa/λ)·NA | Single-mode Condition = V < 2.405 | Number of Modes = approximately V²/2 for step-index fibre
# Fibre Types & Transmission Characteristics
- Step-index & Graded-index Fibres | Index profile affects dispersion. | Step-index Fibre = uniform core index with abrupt change | Graded-index Fibre = core index decreases radially, reducing modal dispersion | Single-mode Fibre = small core carrying one mode
- Attenuation | Signal power is lost along the fibre. | Attenuation = α = (10/L) log(Pin/Pout) dB/km | Rayleigh Scattering = loss proportional to 1/λ⁴ | Absorption Loss = due to impurities such as OH ions
- Dispersion | Pulses broaden and limit bandwidth. | Intermodal Dispersion = different modes arrive at different times | Chromatic Dispersion = different wavelengths travel at different speeds | Polarisation Mode Dispersion = differential delay of polarisation modes
- Bending & Splicing Losses | Mechanical effects cause loss. | Macrobending = loss from large-radius bends | Microbending = loss from small random distortions | Fusion Splice = joining fibres by melting, low loss
# Optical Sources
- LED Sources | LEDs are simple incoherent sources. | Surface-emitting LED = emits from the surface with broad pattern | Edge-emitting LED = higher brightness and narrower spectrum | Internal Quantum Efficiency = fraction of recombinations that emit photons
- Laser Diodes | Lasers give coherent narrow-linewidth light. | Stimulated Emission = photon triggers emission of identical photon | Population Inversion = more electrons in excited state than ground | Threshold Current = current above which lasing begins
- Laser Types | Structures improve single-mode operation. | DFB Laser = distributed feedback laser with grating, single longitudinal mode | VCSEL = vertical-cavity surface-emitting laser | Fabry-Perot Laser = simple cavity laser with multiple modes
- Modulation of Sources | Data is impressed on light. | Direct Modulation = varying drive current | External Modulator = e.g. Mach-Zehnder modulator for high speed | Chirp = frequency shift during modulation causing dispersion
# Optical Detectors & Receivers
- Photodetector Principles | Detectors convert light into current. | Responsivity = R = Ip/P0 A/W | Quantum Efficiency = electrons generated per incident photon | Cut-off Wavelength = λc = 1.24/Eg µm
- PIN & APD Photodiodes | Two main detector types. | PIN Photodiode = intrinsic layer widens depletion region | APD = avalanche photodiode with internal gain | Excess Noise Factor = extra noise due to avalanche multiplication
- Receiver Noise & Sensitivity | Noise limits detection. | Shot Noise = from discrete photon arrivals | Thermal Noise = from load resistor | Receiver Sensitivity = minimum power for a target BER
- Receiver Structures | Front ends amplify the photocurrent. | Transimpedance Amplifier = converts photocurrent to voltage | High-impedance Front End = low noise but limited bandwidth | Bit Error Rate = fraction of erroneous bits, often 10^−9 target
# Optical Links & Networks
- Link Power Budget | Budgets ensure enough power reaches the receiver. | Power Budget = Ptx − Prx(min) ≥ total losses + margin | System Margin = extra power allowed for ageing | Splice and Connector Loss = per-joint losses included in budget
- Rise Time Budget | Bandwidth is checked through rise times. | Rise Time Budget = system rise time is root-sum-square of components | NRZ Requirement = tsys ≤ 0.7/B | Component Rise Times = transmitter, fibre dispersion and receiver
- WDM & Optical Amplifiers | WDM multiplies fibre capacity. | WDM = multiple wavelengths on one fibre | DWDM = dense WDM with narrow channel spacing | EDFA = erbium-doped fibre amplifier for the 1550 nm band
- Optical Networks | Fibres form access and core networks. | SONET/SDH = synchronous optical network standards | PON = passive optical network for FTTH | OTDR = optical time domain reflectometer locating faults

# Wireless Channel
- Path Loss Models | Signal power drops with distance. | Free Space Model = Friis equation Pr = PtGtGrλ²/(4πd)² | Log-distance Model = path loss grows with 10n log(d) | Shadowing = log-normal variation due to obstacles
- Multipath Fading | Multiple paths cause rapid fades. | Flat Fading = signal bandwidth smaller than coherence bandwidth | Frequency-selective Fading = bandwidth larger than coherence bandwidth | Fast Fading = channel changes within a symbol period
- Doppler Spread & Coherence Time | Motion causes time variation. | Doppler Spread = spectral broadening due to motion | Coherence Time = Tc ≈ 0.423/fm | Slow Fading = channel constant over many symbols
- Channel Models | Statistical models describe fading. | Rayleigh Model = no LOS, envelope Rayleigh distributed | Rician K-factor = ratio of LOS power to scattered power | Jakes Model = classical Doppler spectrum model
# Diversity & Equalisation
- Diversity Types | Diversity provides independent copies. | Time Diversity = repeats or interleaves over time | Frequency Diversity = sends on separated frequencies | Antenna Diversity = multiple spaced antennas
- Combining Techniques | Diversity branches are combined. | Selection Combining = picks the strongest branch | Equal Gain Combining = co-phases and adds branches | Maximal Ratio Combining = optimal SNR weighting
- Equalisation | Equalisers fight ISI in frequency-selective channels. | Linear Equaliser = FIR filter reversing channel | Decision Feedback Equaliser = uses past decisions to cancel ISI | MLSE = maximum-likelihood sequence estimation
- Channel Estimation | Receivers estimate channel response. | Pilot Symbols = known symbols for channel estimation | Training Sequence = known preamble | Blind Estimation = estimation without pilots
# OFDM & MIMO
- OFDM Principles | OFDM divides bandwidth into orthogonal subcarriers. | OFDM = parallel orthogonal subcarriers implemented by IFFT/FFT | Subcarrier Spacing = Δf = 1/T | Cyclic Prefix = guard interval copied from symbol end to absorb delay spread
- OFDM Issues | OFDM has practical drawbacks. | PAPR = high peak-to-average power ratio | Carrier Frequency Offset = breaks subcarrier orthogonality | SC-FDMA = lower-PAPR uplink scheme in LTE
- MIMO Channel & Capacity | Multiple antennas multiply capacity. | MIMO Capacity = grows linearly with min(Nt, Nr) | Channel Matrix = H describing all antenna paths | Spatial Multiplexing Gain = parallel data streams
- Space-time Coding | Coding across antennas gives diversity. | Alamouti Code = 2×1 space-time block code giving full diversity | Diversity Gain = slope improvement of BER curve | Massive MIMO = very large antenna arrays at base station
# Multiple Access & Spread Spectrum
- Multiple Access Techniques | Users share the spectrum. | FDMA = separate frequencies | TDMA = separate time slots | OFDMA = separate subcarrier groups
- CDMA & Spread Spectrum | Codes separate users. | DSSS = spreads data with fast PN chips | Processing Gain = chip rate / bit rate | Power Control = equalises received power to solve near-far problem
- Random Access | Users contend for the channel. | ALOHA = transmit anytime; max throughput 18.4% | Slotted ALOHA = transmissions in slots; max 36.8% | CSMA/CA = carrier sense with collision avoidance used in Wi-Fi
- NOMA & Cognitive Radio | Newer access methods use spectrum efficiently. | NOMA = non-orthogonal multiple access using power domain | Cognitive Radio = senses and uses idle spectrum | Spectrum Sensing = detecting presence of primary users
# Wireless Standards & Networks
- Wireless LAN | IEEE 802.11 defines Wi-Fi. | 802.11ac = Wi-Fi 5 with MU-MIMO in 5 GHz | 802.11ax = Wi-Fi 6 with OFDMA | Access Point = node connecting wireless clients to the network
- WPAN Technologies | Short-range networks connect personal devices. | Bluetooth = 2.4 GHz WPAN with frequency hopping | Zigbee = low-power mesh networking | UWB = ultra-wideband short-range high-rate radio
- Cellular Standards | Cellular generations evolved rapidly. | LTE = 4G OFDMA-based standard | 5G NR = new radio supporting mmWave and low latency | Network Slicing = virtual networks tailored to services
- Wireless Sensor Networks | Sensor nodes monitor environments. | WSN = network of battery-powered sensing nodes | Clustering = cluster heads aggregate data, e.g. LEACH | Energy Efficiency = key design goal for long lifetime
