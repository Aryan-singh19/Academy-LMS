@ cs801 | CS-801 | Internet of Things | IoT architecture, sensors and actuators, networking, protocols (MQTT, CoAP), platforms, security and case studies.
# IoT Fundamentals & Architecture
- IoT Definition & Characteristics | IoT connects physical things to the Internet to sense, decide and act. | Internet of Things = network of physical objects with sensors, software and connectivity | Interoperability = ability of heterogeneous devices to work together | Self-configuring = devices discover and configure themselves with minimal human input
- IoT Conceptual & Architectural Framework | Layered architectures organise devices, networks and applications. | Three-layer Architecture = perception, network and application layers | Physical Design of IoT = the things, their interfaces and protocols | Logical Design of IoT = functional blocks and communication models
- M2M vs IoT | IoT extends machine-to-machine links with cloud and analytics. | M2M = direct point-to-point communication between machines | IoT Ecosystem = devices, gateways, cloud, analytics and users | Gateway = device bridging local sensor networks to the Internet
- IoT Communication Models | Devices exchange data using standard interaction patterns. | Request-Response Model = client requests, server replies | Publish-Subscribe Model = publishers send to topics, subscribers receive via a broker | Push-Pull Model = producers push to queues, consumers pull from them
# Sensors, Actuators & Hardware
- Sensors & Their Classification | Sensors convert physical quantities into electrical signals. | Sensor = device that detects a physical quantity and outputs a signal | Analog Sensor = produces a continuous output, e.g. thermistor | Digital Sensor = produces discrete output, e.g. DHT11 temperature-humidity sensor
- Actuators | Actuators convert control signals into physical action. | Actuator = device that moves or controls a mechanism | Servo Motor = motor with feedback for precise angular position | Relay = electrically operated switch for high-power loads
- Microcontrollers & Development Boards | Embedded boards run IoT device logic. | Arduino = open-source microcontroller board based on ATmega chips | Raspberry Pi = single-board Linux computer for gateways and edge tasks | ESP32 = low-cost microcontroller with built-in Wi-Fi and Bluetooth
- Embedded System Basics | IoT nodes are resource-constrained embedded systems. | Embedded System = computer system dedicated to a specific function | Duty Cycling = sleeping most of the time to save energy | GPIO = general-purpose input/output pins
# IoT Networking & Protocols
- IoT Network Technologies | Short- and long-range radios connect IoT devices. | Zigbee = low-power mesh networking on IEEE 802.15.4 | LoRaWAN = long-range, low-power wide-area network protocol | BLE = Bluetooth Low Energy for short-range low-power links
- MQTT | A lightweight publish-subscribe messaging protocol for constrained devices. | MQTT = publish-subscribe protocol over TCP using a broker | QoS Levels = MQTT offers 0 at most once, 1 at least once, 2 exactly once | Topic = hierarchical string to which messages are published
- CoAP, XMPP & AMQP | Other application protocols suit different IoT needs. | CoAP = RESTful protocol over UDP for constrained networks | XMPP = XML-based messaging protocol for real-time communication | AMQP = message-queue protocol with reliable delivery and routing
- 6LoWPAN & IPv6 for IoT | IPv6 gives every device an address. | 6LoWPAN = IPv6 over low-power wireless personal area networks | IPv6 Address Space = 128-bit addresses, enough for billions of devices | RPL = routing protocol for low-power and lossy networks
# IoT Platforms, Cloud & Data
- Cloud & Edge Computing for IoT | Processing can happen in the cloud, at the edge or in between. | Cloud Computing for IoT = remote storage and analytics for device data | Edge Computing = processing data near its source to cut latency | Fog Computing = intermediate layer between edge devices and cloud
- IoT Platforms | Platforms manage devices, data and applications. | AWS IoT Core = managed cloud service to connect and manage devices | Device Shadow = cloud copy of a device's last reported state | ThingSpeak = IoT analytics platform for collecting and visualising sensor data
- IoT Data Analytics | Sensor data is processed to extract insight. | Stream Processing = analysing data continuously as it arrives | Time-series Data = measurements indexed by time | Digital Twin = virtual model mirroring a physical asset in real time
- SDN & NFV for IoT | Software-defined networking simplifies large IoT networks. | SDN = separates control plane from data plane | NFV = network functions run as software on standard servers | Controller = central SDN component programming the switches
# IoT Security & Applications
- IoT Security Challenges | Constrained, numerous devices create a large attack surface. | Botnet = network of compromised devices used for attacks such as Mirai | Device Authentication = verifying a device's identity before granting access | Secure Boot = verifying firmware signatures at start-up
- Privacy & Trust | IoT collects personal data that must be protected. | Data Minimisation = collect only data needed for the purpose | Lightweight Cryptography = ciphers designed for constrained devices | End-to-end Encryption = data encrypted from device to final application
- Smart Home & Smart City | Common IoT application domains. | Smart Home = automated lighting, security and appliances controlled remotely | Smart City = IoT for traffic, waste, parking and utility management | Smart Grid = electricity network with sensing and two-way communication
- Industrial IoT, Healthcare & Agriculture | IoT improves industry, health and farming. | IIoT = industrial IoT for predictive maintenance and automation | Remote Patient Monitoring = wearable sensors transmit vital signs to clinicians | Smart Farming = soil moisture and weather sensors drive irrigation decisions

@ cs802-bc | CS-802(A) | Blockchain Technologies | Distributed ledgers, cryptographic primitives, consensus, Bitcoin, Ethereum smart contracts and enterprise blockchains.
# Blockchain Fundamentals
- What is Blockchain? | A blockchain is an append-only ledger replicated across peers. | Blockchain = chain of blocks, each linking to the previous block's hash | Distributed Ledger = database shared and synchronised across many nodes | Immutability = recorded data cannot be altered without breaking the chain
- Types of Blockchain | Networks differ in who can join and validate. | Public Blockchain = anyone can read, transact and validate, e.g. Bitcoin | Private Blockchain = controlled by one organisation | Consortium Blockchain = governed by a group of organisations
- Block Structure | Each block holds a header and transactions. | Block Header = contains previous hash, Merkle root, timestamp and nonce | Genesis Block = first block of a blockchain | Block Height = number of blocks before a given block
- Decentralisation & Trust | Blockchains replace central authorities with protocols. | Decentralisation = no single party controls the network | Double Spending = spending the same digital token twice | Trustless System = participants need not trust each other, only the protocol
# Cryptographic Foundations
- Hash Functions | Cryptographic hashes give fixed-size fingerprints of data. | SHA-256 = hash function producing a 256-bit digest, used in Bitcoin | Collision Resistance = infeasible to find two inputs with the same hash | Avalanche Effect = small input change produces a very different hash
- Merkle Trees | Merkle trees summarise many transactions in one hash. | Merkle Tree = binary tree of hashes whose root commits to all leaves | Merkle Root = top hash stored in the block header | Merkle Proof = path of hashes proving a transaction is in a block
- Public-key Cryptography & Signatures | Keys prove ownership and authorise transactions. | Public Key = shared key used to verify signatures and derive addresses | ECDSA = elliptic curve digital signature algorithm used in Bitcoin and Ethereum | Wallet = software storing private keys and creating transactions
- Zero-knowledge & Privacy Techniques | Advanced cryptography adds privacy. | Zero-knowledge Proof = proves a statement is true without revealing why | zk-SNARK = succinct non-interactive zero-knowledge proof | Ring Signature = signature from a group hiding the actual signer
# Consensus Mechanisms
- Proof of Work | Miners compete to solve a hash puzzle. | Proof of Work = consensus where miners find a nonce giving a hash below a target | Mining Difficulty = target adjusted to keep block time steady | 51% Attack = majority hash power can rewrite recent history
- Proof of Stake & Variants | Validators are chosen by stake instead of work. | Proof of Stake = validators selected in proportion to coins staked | Slashing = penalty destroying stake of misbehaving validators | Delegated PoS = token holders elect a small set of validators
- Byzantine Fault Tolerance | BFT protocols reach agreement despite faulty nodes. | Byzantine Generals Problem = reaching agreement when some participants are malicious | PBFT = practical BFT tolerating f faults with 3f + 1 nodes | Finality = point after which a transaction cannot be reversed
- Forks & Network Upgrades | Protocol changes and competing chains create forks. | Soft Fork = backward-compatible rule tightening | Hard Fork = non-backward-compatible change splitting the chain | Orphan Block = valid block not included in the main chain
# Bitcoin & Ethereum
- Bitcoin Transactions | Bitcoin tracks coins as unspent outputs. | UTXO = unspent transaction output model used by Bitcoin | Bitcoin Script = simple stack-based language locking outputs | Block Reward = new coins plus fees given to the miner
- Ethereum & the EVM | Ethereum is a programmable blockchain. | Ethereum Virtual Machine = runtime executing smart contract bytecode | Gas = fee unit measuring computation cost on Ethereum | Account Model = Ethereum tracks balances in externally owned and contract accounts
- Smart Contracts & Solidity | Contracts are programs that run on the chain. | Smart Contract = self-executing code enforcing agreement terms | Solidity = statically typed language for Ethereum contracts | Reentrancy Attack = exploit calling back into a contract before state updates
- Tokens & DApps | Standards define tokens and decentralised applications. | ERC-20 = standard for fungible tokens on Ethereum | ERC-721 = standard for non-fungible tokens | DApp = decentralised application whose backend runs on a blockchain
# Enterprise Blockchain & Applications
- Hyperledger Fabric | Permissioned frameworks serve business networks. | Hyperledger Fabric = modular permissioned blockchain framework | Chaincode = smart contract in Hyperledger Fabric | Endorsement Policy = rule specifying which peers must approve a transaction
- Blockchain Scalability | Layer-2 and sharding improve throughput. | Scalability Trilemma = trade-off among decentralisation, security and scalability | Sharding = splitting the network so shards process transactions in parallel | Lightning Network = Bitcoin layer-2 payment channels
- Applications Beyond Cryptocurrency | Blockchains serve supply chains, identity and finance. | Supply Chain Traceability = recording product movement on a shared ledger | Self-sovereign Identity = users control their own identity credentials | DeFi = decentralised finance services built on smart contracts
- Limitations, Oracles & Regulation | Blockchains face practical constraints. | Oracle = service bringing off-chain data onto the blockchain | Energy Consumption = PoW networks use very large amounts of electricity | Regulatory Compliance = KYC and AML rules applied to crypto services

@ cs803-ip | CS-803(A) | Image Processing & Computer Vision | Digital image fundamentals, enhancement, filtering, restoration, segmentation, morphology, features and recognition.
# Digital Image Fundamentals
- Image Formation & Representation | A digital image is a 2D array of intensity values. | Pixel = smallest element of a digital image | Sampling = digitising spatial coordinates | Quantisation = digitising intensity into discrete levels
- Resolution & Colour Models | Images vary in detail and colour encoding. | Spatial Resolution = number of pixels per unit length | RGB Model = additive colour model using red, green and blue | HSI Model = hue, saturation and intensity, closer to human perception
- Pixel Relationships | Neighbourhoods and connectivity define regions. | 4-Neighbourhood = horizontal and vertical neighbours of a pixel | 8-Connectivity = pixels connected through any of their 8 neighbours | Euclidean Distance = straight-line distance between two pixels
- Image Processing Pipeline | Vision systems move from acquisition to understanding. | Image Acquisition = capturing an image with a sensor | Preprocessing = noise removal and enhancement before analysis | Recognition = assigning a label to an object based on its features
# Image Enhancement
- Intensity Transformations | Point operations change pixel values independently. | Image Negative = s = L − 1 − r | Log Transformation = expands dark values and compresses bright ones | Gamma Correction = power-law transform s = c·r^γ
- Histogram Processing | Histograms describe the intensity distribution. | Histogram = count of pixels at each intensity level | Histogram Equalisation = spreads intensities to improve global contrast | Histogram Matching = transforms an image to a specified histogram
- Spatial Filtering | Masks convolve with the image to smooth or sharpen. | Mean Filter = averaging mask that smooths noise and blurs edges | Median Filter = replaces pixel by neighbourhood median; removes salt-and-pepper noise | Laplacian Filter = second-derivative mask used for sharpening
- Frequency Domain Filtering | Fourier transforms enable filtering by frequency. | 2D DFT = transforms an image into frequency components | Low-pass Filter = passes low frequencies, smoothing the image | Butterworth Filter = smooth-transition frequency filter avoiding ringing
# Restoration & Compression
- Noise Models | Restoration starts by modelling the degradation. | Gaussian Noise = noise with normally distributed intensity | Salt-and-Pepper Noise = random white and black pixels | Degradation Model = g(x,y) = h(x,y) * f(x,y) + η(x,y)
- Restoration Filters | Filters estimate the original image from a degraded one. | Inverse Filtering = divides by the degradation function in frequency domain | Wiener Filter = minimum mean square error restoration | Adaptive Filter = filter whose behaviour changes with local statistics
- Image Compression Fundamentals | Compression removes redundancy to save space. | Coding Redundancy = using more bits than needed for symbols | Lossless Compression = original image exactly recoverable, e.g. PNG | Lossy Compression = some information discarded, e.g. JPEG
- JPEG & Transform Coding | Transform coding packs energy into few coefficients. | DCT = discrete cosine transform used in JPEG | Run-length Encoding = stores runs of identical values as value-count pairs | Compression Ratio = original size divided by compressed size
# Segmentation & Morphology
- Edge Detection | Edges mark sharp intensity changes. | Sobel Operator = gradient mask emphasising horizontal or vertical edges | Canny Edge Detector = multi-stage detector with non-maximum suppression and hysteresis | Gradient Magnitude = strength of intensity change at a pixel
- Thresholding & Region-based Segmentation | Segmentation divides an image into meaningful regions. | Global Thresholding = single threshold separates object and background | Otsu's Method = chooses threshold maximising between-class variance | Region Growing = grows regions from seeds by adding similar neighbours
- Morphological Operations | Morphology processes shapes with structuring elements. | Dilation = expands objects, filling small holes | Erosion = shrinks objects, removing small specks | Opening = erosion followed by dilation; removes small objects
- Hough Transform | Hough transform detects parametric shapes. | Hough Transform = maps edge points to parameter space to find lines or circles | Accumulator Array = votes in parameter space; peaks indicate shapes | Line Parameterisation = ρ = x cos θ + y sin θ
# Features & Recognition
- Feature Extraction | Features describe image content compactly. | Corner Detection = finding points with strong change in two directions, e.g. Harris | SIFT = scale-invariant feature transform for keypoint description | HOG = histogram of oriented gradients descriptor for object detection
- Pattern Recognition Basics | Classifiers assign classes to feature vectors. | Feature Vector = list of numeric measurements describing an object | k-NN Classifier = assigns the majority class of the k nearest neighbours | Template Matching = compares image regions with a stored template
- CNNs for Vision | Deep networks learn features directly from pixels. | Convolutional Neural Network = network with convolution and pooling layers for images | Transfer Learning = reusing a pretrained network for a new task | Data Augmentation = creating training variants by flipping, cropping or rotating
- Vision Applications | Vision powers many real-world systems. | Object Detection = locating and classifying multiple objects, e.g. YOLO | Face Recognition = identifying people from facial features | OCR = optical character recognition converting text images to text

@ it402 | CSIT-402 | Analog & Digital Communication | Signals, AM/FM modulation, sampling, pulse modulation, digital modulation and information theory.
# Signals & Spectra
- Signals & Classification | Communication systems process signals in time and frequency. | Periodic Signal = repeats every fixed period T | Energy Signal = finite total energy, zero average power | Power Signal = finite non-zero average power, e.g. periodic signals
- Fourier Analysis of Signals | Fourier methods reveal frequency content. | Fourier Series = periodic signal expressed as sum of harmonics | Fourier Transform = frequency spectrum of a non-periodic signal | Bandwidth = range of frequencies a signal occupies
- Communication System Model | Every system has source, transmitter, channel and receiver. | Transmitter = converts message into a signal suitable for the channel | Channel = medium carrying the signal, adding noise and distortion | Receiver = recovers the message from the received signal
- Noise | Unwanted signals degrade communication. | Thermal Noise = noise power N = kTB from random electron motion | Signal-to-Noise Ratio = signal power divided by noise power, often in dB | Noise Figure = degradation of SNR caused by a device
# Analog Modulation
- Amplitude Modulation | Carrier amplitude varies with the message. | AM = carrier amplitude varied in proportion to the message | Modulation Index = ratio of message amplitude to carrier amplitude | AM Power = Pt = Pc(1 + m²/2)
- DSB-SC & SSB | Suppressing carrier or one sideband saves power and bandwidth. | DSB-SC = double sideband suppressed carrier modulation | SSB = single sideband transmission halving the bandwidth | Balanced Modulator = circuit producing DSB-SC by cancelling the carrier
- Frequency & Phase Modulation | Angle modulation varies frequency or phase. | FM = carrier frequency varied with the message | Frequency Deviation = maximum shift of carrier frequency from its centre | Carson's Rule = FM bandwidth ≈ 2(Δf + fm)
- Radio Receivers | Receivers select and demodulate the wanted station. | Superheterodyne Receiver = converts incoming signal to a fixed intermediate frequency | Envelope Detector = diode circuit demodulating AM | Image Frequency = unwanted frequency that also produces the IF
# Sampling & Pulse Modulation
- Sampling Theorem | Band-limited signals are recovered from samples. | Nyquist Rate = sampling at least twice the highest frequency, fs ≥ 2fm | Aliasing = overlap of spectra when sampling too slowly | Anti-aliasing Filter = low-pass filter before sampling
- PAM, PWM & PPM | Pulse parameters carry the message. | PAM = pulse amplitude modulation | PWM = pulse width varied with the message | PPM = pulse position varied with the message
- Pulse Code Modulation | PCM digitises analog signals. | PCM = sampling, quantising and encoding into binary | Quantisation Noise = error due to rounding samples to levels | Companding = compressing then expanding to equalise SNR, e.g. μ-law
- Delta & Adaptive Delta Modulation | DM sends one bit per sample of the change. | Delta Modulation = transmits whether the signal rose or fell | Slope Overload = staircase cannot follow a rapidly changing signal | Granular Noise = hunting of the staircase around a slowly varying signal
# Digital Modulation
- ASK, FSK & PSK | Digital data modulates amplitude, frequency or phase. | ASK = amplitude shift keying | FSK = frequency shift keying using two frequencies | BPSK = binary phase shift keying with phases 0° and 180°
- QPSK & QAM | Multi-level schemes send several bits per symbol. | QPSK = four phases, 2 bits per symbol | QAM = combines amplitude and phase changes | Constellation Diagram = plot of symbol points in the I-Q plane
- Line Coding | Line codes represent bits as voltage levels. | NRZ = non-return-to-zero line code | Manchester Coding = transition in the middle of every bit | AMI = alternate mark inversion with alternating polarity for 1s
- Multiplexing | Multiple signals share a single channel. | FDM = frequency division multiplexing | TDM = time division multiplexing | CDMA = code division multiple access using spreading codes
# Information Theory & Coding
- Information & Entropy | Information theory quantifies uncertainty. | Information Content = I = log2(1/p) bits | Entropy = average information per symbol, H = −Σ p log2 p | Information Rate = R = r × H bits per second
- Channel Capacity | Capacity limits the error-free data rate. | Shannon-Hartley Theorem = C = B log2(1 + S/N) | Channel Capacity = maximum reliable information rate of a channel | Bandwidth-SNR Trade-off = bandwidth can be exchanged for signal power
- Source Coding | Source codes remove redundancy. | Shannon-Fano Coding = splits symbols into equally probable groups | Huffman Coding = optimal prefix code from least probable merges | Code Efficiency = entropy divided by average code length
- Error Control Coding | Channel codes detect and correct errors. | Linear Block Code = n-bit codewords from k message bits | Cyclic Code = code where any cyclic shift is a codeword | CRC = cyclic redundancy check for error detection

# Semantics & Embeddings
- Lexical Semantics | Word meaning and relations between words. | Synonymy = different words with the same meaning | WordNet = lexical database of synsets and semantic relations | Word Sense Disambiguation = choosing the correct sense of a word in context
- Vector Semantics | Words are represented as vectors from their contexts. | Distributional Hypothesis = words in similar contexts have similar meanings | TF-IDF = term weight by frequency times inverse document frequency | Cosine Similarity = angle-based similarity of two vectors
- Word Embeddings | Dense embeddings capture semantic similarity. | Word2Vec = learns embeddings using skip-gram or CBOW | GloVe = embeddings from global co-occurrence statistics | Embedding Analogy = vector arithmetic such as king − man + woman ≈ queen
- Semantic Role Labelling & Coreference | Deeper semantics identifies who did what to whom. | Semantic Role Labelling = assigning roles like agent and patient | Coreference Resolution = linking mentions that refer to the same entity | Discourse = structure and coherence across sentences
# Transformers & Applications
- Attention & Transformers | Attention lets models weigh all positions at once. | Self-attention = each token attends to every other token in the sequence | Transformer = architecture of stacked attention and feed-forward layers | Positional Encoding = adds order information to token embeddings
- Pretrained Language Models | Large models are pretrained then fine-tuned. | BERT = bidirectional encoder pretrained with masked language modelling | GPT = autoregressive decoder pretrained to predict the next token | Fine-tuning = adapting a pretrained model to a specific task
- Machine Translation & Summarisation | Sequence-to-sequence tasks generate text. | Seq2Seq Model = encoder-decoder mapping input to output sequences | BLEU Score = n-gram overlap metric for translation quality | Abstractive Summarisation = generating new sentences that summarise text
- Question Answering, Chatbots & Sentiment | Applications bring NLP to users. | Question Answering = returning answers to natural-language questions | Chatbot = conversational agent interacting through text | Sentiment Classification = labelling text as positive, negative or neutral

@ it801 | CSIT-801 | Data Science | Data science lifecycle, statistics, data wrangling, exploratory analysis, machine learning, visualisation and big data tools.
# Introduction & Data Science Lifecycle
- What is Data Science? | Data science extracts knowledge from data using statistics and computing. | Data Science = interdisciplinary field extracting insight from data | Data Scientist = practitioner combining statistics, programming and domain knowledge | CRISP-DM = process model: business understanding, data understanding, preparation, modelling, evaluation, deployment
- Types of Data | Data is classified by structure and measurement level. | Structured Data = data organised in rows and columns | Unstructured Data = text, images or audio without a fixed schema | Nominal vs Ordinal = categories without order versus ordered categories
- Data Collection & Sources | Data comes from databases, APIs and the web. | Web Scraping = extracting data from web pages programmatically | API = interface for programmatic data access | Sampling Bias = sample that does not represent the population
- Tools of Data Science | Python and R ecosystems dominate. | NumPy = Python library for fast n-dimensional arrays | Pandas = Python library with DataFrame for tabular data | Jupyter Notebook = interactive environment mixing code, output and text
# Statistics for Data Science
- Descriptive Statistics | Summaries describe the centre and spread of data. | Mean = arithmetic average of values | Standard Deviation = square root of the average squared deviation from the mean | Skewness = measure of asymmetry of a distribution
- Probability & Distributions | Probability models randomness in data. | Normal Distribution = symmetric bell curve defined by mean and SD | Central Limit Theorem = sample means approach a normal distribution as n grows | Random Variable = numerical outcome of a random process
- Hypothesis Testing | Tests decide whether evidence supports a claim. | Null Hypothesis = default claim of no effect | p-value = probability of results at least as extreme if the null is true | Type I Error = rejecting a true null hypothesis
- Correlation & Regression | Relationships between variables are measured and modelled. | Correlation Coefficient = strength and direction of a linear relationship | Linear Regression = models y as a linear function of predictors | Correlation vs Causation = correlation alone does not prove cause
# Data Wrangling & Exploration
- Data Cleaning | Raw data must be cleaned before analysis. | Missing Value Imputation = filling gaps using mean, median or models | Outlier = observation far from the rest of the data | Data Deduplication = removing repeated records
- Data Transformation | Features are rescaled and encoded for modelling. | Normalisation = scaling values to a fixed range such as 0 to 1 | Standardisation = rescaling to zero mean and unit variance | One-hot Encoding = converting categories into binary indicator columns
- Exploratory Data Analysis | EDA reveals patterns, anomalies and hypotheses. | EDA = exploring data with summaries and plots before modelling | Box Plot = shows median, quartiles and outliers | Correlation Matrix = table of pairwise correlation coefficients
- Feature Engineering | Better features often beat better algorithms. | Feature Engineering = creating informative input variables from raw data | Feature Selection = choosing a subset of relevant features | Dimensionality Reduction = reducing variables, e.g. with PCA
# Machine Learning for Data Science
- Supervised Learning Models | Models learn from labelled examples. | Logistic Regression = models probability of a binary outcome | Random Forest = ensemble of decision trees using bagging | Support Vector Machine = finds the maximum-margin separating hyperplane
- Unsupervised Learning | Models find structure without labels. | K-Means Clustering = partitions data into k clusters around centroids | Hierarchical Clustering = builds a dendrogram by merging or splitting clusters | Association Rules = if-then patterns such as market-basket rules
- Model Evaluation | Metrics and validation estimate real-world performance. | Confusion Matrix = table of true and false positives and negatives | Cross-validation = rotating train-test splits to estimate performance | F1 Score = harmonic mean of precision and recall
- Overfitting & Regularisation | Models must generalise beyond training data. | Overfitting = model fits noise in training data and fails on new data | Bias-Variance Trade-off = balance between underfitting and overfitting | Regularisation = penalising model complexity, e.g. L1 or L2
# Visualisation, Big Data & Ethics
- Data Visualisation Principles | Good charts communicate clearly. | Data Visualisation = graphical representation of data | Histogram = bar chart of value frequencies in bins | Scatter Plot = plot showing the relationship of two numeric variables
- Visualisation Tools | Libraries and BI tools create charts and dashboards. | Matplotlib = foundational Python plotting library | Seaborn = statistical visualisation library built on Matplotlib | Tableau = business intelligence tool for interactive dashboards
- Big Data Tools | Large datasets need distributed tools. | Apache Spark = in-memory distributed data processing engine | HDFS = Hadoop distributed file system | NoSQL Database = non-relational store such as MongoDB or Cassandra
- Data Ethics & Privacy | Responsible data science protects people. | Data Privacy = protecting personal data from misuse | Anonymisation = removing identifiers from data | Data Governance = policies for data quality, security and use

@ it802-dwm | CSIT-802(A) | Data Warehousing & Mining | Data warehouse architecture, OLAP, preprocessing, association rules, classification, clustering and web mining.
# Data Warehousing Concepts
- Data Warehouse Fundamentals | A warehouse integrates historical data for decision support. | Data Warehouse = subject-oriented, integrated, time-variant, non-volatile data collection | OLTP vs OLAP = transaction processing versus analytical processing | Data Mart = subset of a warehouse for one department
- Warehouse Architecture | Data flows from sources through ETL into the warehouse. | Three-tier Architecture = bottom warehouse server, middle OLAP server, top client tools | ETL = extract, transform and load process | Metadata Repository = data about warehouse data and processes
- Multidimensional Data Model | Data is viewed as cubes of facts and dimensions. | Fact Table = table of measures with foreign keys to dimensions | Dimension Table = descriptive attributes such as time, product, location | Data Cube = multidimensional view of measures
- Schemas for Warehouses | Schemas arrange fact and dimension tables. | Star Schema = central fact table joined to denormalised dimensions | Snowflake Schema = dimensions normalised into sub-tables | Fact Constellation = multiple fact tables sharing dimensions
# OLAP & Preprocessing
- OLAP Operations | OLAP lets analysts navigate cubes. | Roll-up = aggregating to a higher level of a hierarchy | Drill-down = moving to more detailed data | Slice and Dice = selecting one dimension value or a sub-cube
- OLAP Servers | OLAP engines store cubes in different ways. | ROLAP = relational OLAP storing data in relational tables | MOLAP = multidimensional OLAP using array-based storage | HOLAP = hybrid combining ROLAP and MOLAP
- Data Preprocessing | Mining needs clean, integrated, reduced data. | Data Cleaning = filling missing values and smoothing noise | Data Integration = combining data from multiple sources | Binning = smoothing by grouping values into bins
- Data Reduction & Discretisation | Smaller representations speed mining. | Dimensionality Reduction = reducing attributes, e.g. PCA | Numerosity Reduction = replacing data with models or samples | Concept Hierarchy = mapping low-level values to higher-level concepts
# Association Rule Mining
- Frequent Itemsets | Mining finds items that often occur together. | Support = fraction of transactions containing an itemset | Confidence = support(A ∪ B) divided by support(A) | Frequent Itemset = itemset meeting the minimum support
- Apriori Algorithm | Apriori generates candidates level by level. | Apriori Property = every subset of a frequent itemset is frequent | Candidate Generation = joining frequent k-itemsets to form (k+1)-itemsets | Pruning Step = discarding candidates with an infrequent subset
- FP-Growth | FP-Growth mines without candidate generation. | FP-Tree = compressed prefix tree of transactions | Conditional Pattern Base = prefix paths ending in an item | FP-Growth = recursive mining of conditional FP-trees
- Interestingness Measures | Strong rules are not always interesting. | Lift = confidence divided by support of the consequent | Lift Greater Than 1 = positive correlation between antecedent and consequent | Closed Itemset = no superset has the same support
# Classification
- Decision Tree Induction | Trees split data on informative attributes. | Information Gain = reduction in entropy after a split, used by ID3 | Gain Ratio = normalised information gain used by C4.5 | Gini Index = impurity measure used by CART
- Bayesian Classification | Probabilistic classifiers apply Bayes' theorem. | Naive Bayes = assumes attributes are conditionally independent given the class | Posterior Probability = P(class given data) | Laplace Correction = avoids zero probabilities by adding one to counts
- Rule-based & Lazy Learners | Other classifiers use rules or nearest neighbours. | Rule-based Classifier = IF-THEN rules for classification | k-Nearest Neighbour = lazy learner using the majority of nearest training tuples | Eager Learner = builds a model before seeing test data
- Classifier Evaluation | Accuracy alone can mislead. | Precision = TP divided by (TP + FP) | Recall = TP divided by (TP + FN) | ROC Curve = true positive rate versus false positive rate
# Clustering & Advanced Mining
- Partitioning Methods | Partitioning divides data into k groups. | K-Means = assigns points to nearest centroid and updates centroids | K-Medoids = uses actual data points as cluster centres; robust to outliers | Sum of Squared Error = clustering quality measure for K-Means
- Hierarchical & Density-based Methods | Other clustering methods need no fixed k or find odd shapes. | Agglomerative Clustering = bottom-up merging of closest clusters | DBSCAN = density-based clustering finding arbitrary shapes and noise | Dendrogram = tree diagram of hierarchical clustering
- Outlier Analysis | Outlier detection finds rare, unusual objects. | Outlier = object deviating significantly from the rest | Statistical Outlier Detection = flags points in low-probability regions | Distance-based Outlier = point with few neighbours within a radius
- Web, Text & Spatial Mining | Mining extends to complex data types. | Web Usage Mining = discovering patterns from web logs | Text Mining = extracting knowledge from unstructured text | PageRank = link analysis ranking web pages by incoming links
