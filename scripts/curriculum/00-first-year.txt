- Softening Methods | Hardness is removed by chemical or ion exchange processes. | Lime-Soda Process = adds lime and soda to precipitate hardness | Zeolite Process = sodium zeolite exchanges Na⁺ for Ca²⁺ and Mg²⁺ | Ion Exchange = cation and anion resins give demineralised water

- Polymers | Polymers are long chain molecules. | Addition Polymerisation = monomers add without by-product, e.g. polyethylene | Condensation Polymerisation = monomers join with loss of small molecules, e.g. nylon | Thermosetting Polymer = sets permanently on heating, e.g. bakelite
- Rubber & Composites | Elastomers and engineered polymers. | Vulcanisation = cross-linking rubber with sulphur | Conducting Polymer = polymer that conducts electricity, e.g. polyaniline | Biodegradable Polymer = decomposes naturally

- Rolle's & Mean Value Theorems | Mean value theorems link function values and derivatives. | Rolle's Theorem = f(a) = f(b) implies f'(c) = 0 for some c in (a,b) | Lagrange MVT = f'(c) = (f(b) − f(a))/(b − a) | Cauchy MVT = generalisation using two functions

- Indeterminate Forms | Limits of forms like 0/0 are evaluated. | L'Hospital's Rule = limit of f/g equals limit of f'/g' for 0/0 or ∞/∞ | Indeterminate Forms = 0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞ | Logarithmic Method = handles 1^∞ and 0^0 forms
- Maxima & Minima | Extreme values are found from derivatives. | Stationary Point = f'(x) = 0 | Second Derivative Test = f''(x) < 0 gives maximum | Point of Inflection = curvature changes sign
# Sequences & Series
- Sequences | Sequences are ordered lists with limits. | Convergent Sequence = approaches a finite limit | Monotonic Sequence = always increasing or always decreasing | Bounded Sequence = all terms lie within a fixed range
- Tests for Convergence | Tests decide whether series converge. | Comparison Test = compare with a known series | D'Alembert's Ratio Test = converges if limit of a(n+1)/a(n) < 1 | Cauchy's Root Test = converges if nth root of a(n) tends to below 1
- p-series & Alternating Series | Standard series aid testing. | p-series = Σ 1/n^p converges for p > 1 | Leibniz Test = alternating series converges if terms decrease to zero | Absolute Convergence = convergence of series of absolute values
- Fourier Series Basics | Periodic functions as sine-cosine sums. | Fourier Coefficients = a0, an and bn computed by integration | Half-range Series = sine or cosine series over half period | Even Function Series = contains only cosine terms

- System of Linear Equations | Consistency is decided by ranks. | Consistent System = rank of A equals rank of augmented matrix | Unique Solution = rank equals number of unknowns | Homogeneous System = AX = 0 always has trivial solution
- Eigenvalues & Eigenvectors | Eigen-analysis finds invariant directions. | Characteristic Equation = det(A − λI) = 0 | Eigenvector = non-zero X with AX = λX | Sum of Eigenvalues = trace of A
- Cayley-Hamilton & Diagonalisation | Matrices satisfy their characteristic equation. | Cayley-Hamilton Theorem = every square matrix satisfies its characteristic equation | Diagonalisation = P⁻¹AP = D using eigenvectors | Inverse by Cayley-Hamilton = A⁻¹ from the characteristic polynomial
# Multivariable Calculus
- Partial Differentiation | Derivatives with respect to one variable at a time. | Partial Derivative = rate of change keeping other variables constant | Euler's Theorem = x∂u/∂x + y∂u/∂y = nu for homogeneous u | Total Derivative = du = (∂u/∂x)dx + (∂u/∂y)dy

- Lagrange Multipliers | Constrained optimisation. | Lagrange Multiplier Method = extremise f subject to g = 0 using F = f + λg | Constraint = condition the variables must satisfy | Stationary Conditions = ∂F/∂x = ∂F/∂y = ∂F/∂λ = 0

- Double Integrals | Area and volume via double integration. | Double Integral = ∫∫ f(x,y) dx dy over a region | Change of Order = swapping integration order with new limits | Area by Double Integral = ∫∫ dx dy

# Engineering Materials
- Classification of Materials | Materials are metals, non-metals and composites. | Ferrous Metal = contains iron, e.g. steel | Non-ferrous Metal = no iron, e.g. copper and aluminium | Composite = combination of two or more materials
- Mechanical Properties | Properties describe response to loads. | Ductility = ability to be drawn into wire | Malleability = ability to be hammered into sheets | Toughness = energy absorbed before fracture
- Stress-Strain Diagram | Tensile behaviour of mild steel. | Elastic Limit = stress up to which material regains shape | Yield Point = stress where plastic deformation begins | Ultimate Stress = maximum stress in the test
- Heat Treatment Basics | Heating and cooling change properties. | Annealing = softening by slow cooling | Hardening = quenching to increase hardness | Tempering = reheating to reduce brittleness
# Measurement & Machine Tools
- Measuring Instruments | Precision instruments measure dimensions. | Vernier Caliper = least count 0.02 mm | Micrometer = least count 0.01 mm | Dial Gauge = measures small deviations
- Lathe Machine | Lathe makes cylindrical parts. | Lathe Operations = turning, facing, threading and taper turning | Headstock = holds spindle and drive | Tailstock = supports long work
- Drilling & Milling | Holes and flat surfaces are machined. | Drilling Machine = makes holes using twist drill | Milling Machine = multi-point cutter removes metal | Shaper = reciprocating tool for flat surfaces
- Basic Manufacturing Processes | Shaping methods for metals. | Casting = pouring molten metal into mould | Welding = joining by fusion | Forging = shaping by compressive force
# Fluid Mechanics Basics
- Fluid Properties | Fluids are characterised by properties. | Density = mass per unit volume | Viscosity = resistance to flow | Specific Gravity = density relative to water
- Pressure Measurement | Pressure is measured by manometers and gauges. | Pascal's Law = pressure transmitted equally in all directions | Manometer = liquid column instrument | Bourdon Gauge = mechanical pressure gauge
- Bernoulli's Equation | Energy conservation in fluid flow. | Bernoulli's Equation = p/ρg + v²/2g + z = constant | Continuity Equation = A1v1 = A2v2 | Venturimeter = measures flow rate
- Hydraulic Machines | Machines convert fluid energy. | Pump = adds energy to fluid | Turbine = extracts energy from fluid | Hydraulic Press = force multiplication using Pascal's law
# Thermodynamics
- Basic Concepts | Systems exchange heat and work. | Thermodynamic System = quantity of matter under study | Property = measurable characteristic like p, V, T | Thermal Equilibrium = no temperature difference
- Laws of Thermodynamics | Laws govern energy conversion. | Zeroth Law = basis of temperature measurement | First Law = energy conservation, Q − W = ΔU | Second Law = heat cannot fully convert into work in a cycle
- Ideal Gas Processes | Gases follow simple relations. | Ideal Gas Equation = pV = mRT | Isothermal Process = constant temperature | Adiabatic Process = no heat transfer; pV^γ = constant
- Heat Engines & Efficiency | Engines convert heat into work. | Heat Engine = device converting heat into work | Carnot Efficiency = 1 − T2/T1 | Refrigerator = transfers heat from cold to hot using work
# Steam Boilers & IC Engines
- Properties of Steam | Steam is a common working fluid. | Wet Steam = mixture of water and vapour | Dry Saturated Steam = no water particles | Superheated Steam = heated above saturation temperature
- Steam Boilers | Boilers produce steam. | Fire-tube Boiler = hot gases in tubes, e.g. Cochran | Water-tube Boiler = water in tubes, e.g. Babcock and Wilcox | Boiler Mountings = safety valves and gauges
- IC Engines | Engines burn fuel inside the cylinder. | Four-stroke Engine = suction, compression, power, exhaust | Two-stroke Engine = power stroke every revolution | Petrol vs Diesel = spark ignition versus compression ignition
- Engine Performance Basics | Engines are rated by power and efficiency. | Indicated Power = power in cylinder | Brake Power = output at shaft | Mechanical Efficiency = BP/IP

# Building Materials
- Stones, Bricks & Lime | Traditional materials for construction. | First Class Brick = well burnt, standard size, water absorption below 20% | Stone = natural material for masonry | Lime = binding material from limestone
- Cement & Concrete | Cement binds aggregates into concrete. | OPC = ordinary Portland cement | Water-Cement Ratio = governs concrete strength | Concrete Grade = M20 means 20 N/mm² characteristic strength
- Timber, Steel & Modern Materials | Other construction materials. | Seasoning of Timber = removing moisture to prevent decay | Structural Steel = rolled sections for frames | Fly Ash Brick = eco-friendly brick from fly ash
- Tests on Materials | Tests ensure quality. | Slump Test = measures workability of concrete | Compressive Strength Test = cube test of concrete | Setting Time Test = Vicat apparatus for cement
# Surveying
- Principles of Surveying | Surveying measures positions on Earth. | Plane Surveying = Earth's curvature ignored | Working from Whole to Part = principle to limit error accumulation | Chain Surveying = measuring distances with chain or tape
- Compass Surveying | Compass measures bearings. | Bearing = direction of a line with respect to meridian | Whole Circle Bearing = measured clockwise from north 0-360° | Local Attraction = magnetic disturbance affecting compass
- Levelling | Levelling finds relative elevations. | Benchmark = point of known elevation | Reduced Level = elevation relative to datum | Height of Instrument Method = RL = HI − staff reading
- Modern Surveying Instruments | Electronic instruments improve accuracy. | Total Station = combines theodolite and EDM | GPS Surveying = satellite-based positioning | Theodolite = measures horizontal and vertical angles
# Building Construction
- Foundations | Foundations transfer loads to soil. | Shallow Foundation = depth less than width, e.g. isolated footing | Deep Foundation = piles transferring load to deeper strata | Bearing Capacity = load per unit area soil can safely support
- Masonry & Walls | Walls are built of bricks or stones. | English Bond = alternate courses of headers and stretchers | Load-bearing Wall = carries loads from above | Damp Proof Course = layer preventing moisture rise
- Floors, Roofs & Building Components | Other building elements. | Lintel = beam over openings | RCC Slab = reinforced concrete floor or roof | Staircase = steps connecting floors
- Building Planning & Bye-laws | Planning ensures function and safety. | Orientation = positioning building for sun and wind | FAR = floor area ratio | Setback = open space between building and boundary
# Engineering Mechanics: Forces
- System of Forces | Forces are vectors acting on bodies. | Coplanar Forces = forces in the same plane | Resultant = single force equivalent to a system | Parallelogram Law = resultant of two forces by diagonal
- Lami's Theorem & Equilibrium | Bodies in equilibrium have zero resultant. | Lami's Theorem = P/sin α = Q/sin β = R/sin γ for three concurrent forces | Equilibrium Conditions = ΣFx = 0, ΣFy = 0, ΣM = 0 | Free Body Diagram = isolated body with all forces
- Moments & Couples | Forces cause rotation. | Moment = force × perpendicular distance | Varignon's Theorem = moment of resultant equals sum of moments | Couple = two equal, opposite, parallel forces
- Support Reactions & Trusses | Beams and trusses are analysed for reactions. | Simple Support = provides vertical reaction | Method of Joints = equilibrium at each truss joint | Method of Sections = cutting truss to find member forces
# Friction & Properties of Sections
- Laws of Friction | Friction opposes relative motion. | Coefficient of Friction = μ = F/N | Angle of Friction = tan φ = μ | Limiting Friction = maximum static friction
- Applications of Friction | Friction problems include ladders and wedges. | Ladder Friction = equilibrium of ladder against wall | Wedge = uses friction to lift loads | Angle of Repose = equals angle of friction
- Centroid & Centre of Gravity | Centroid locates the geometric centre. | Centroid = point where area is concentrated | Centroid of Triangle = h/3 from base | Composite Area Centroid = x̄ = ΣAx/ΣA
- Moment of Inertia | Area moment of inertia measures resistance to bending. | Moment of Inertia = ∫ y² dA | Rectangle I = bd³/12 | Parallel Axis Theorem = I = Ig + Ah²

# Computer Fundamentals
- Computer Organisation | A computer has input, processing, memory and output units. | CPU = central processing unit with ALU and control unit | Primary Memory = RAM and ROM directly accessed by CPU | Secondary Storage = HDD, SSD for permanent storage
- Number Systems | Computers use binary representation. | Binary = base 2 | Hexadecimal = base 16 | Bit and Byte = 8 bits make one byte
- Generations & Types of Computers | Computers evolved through generations. | First Generation = vacuum tubes | Fourth Generation = microprocessors | Supercomputer = highest performance computer
- Software Types | Software is system or application software. | System Software = operating system, compilers | Application Software = programs for user tasks | Compiler vs Interpreter = whole program translation versus line-by-line
# Operating Systems
- OS Functions | OS manages hardware and resources. | Operating System = interface between user and hardware | Process Management = scheduling and executing programs | Memory Management = allocating memory to processes
- Types of OS | OS designs serve different needs. | Batch OS = jobs processed in batches | Time-sharing OS = CPU time shared among users | Real-time OS = strict timing constraints
- File Systems & Commands | OS organises files in directories. | File System = method of storing and organising files | Directory = container of files | Linux Commands = ls, cd, mkdir, cp
- Windows & Linux | Popular operating systems. | Windows = GUI-based OS by Microsoft | Linux = open-source Unix-like OS | Shell = command-line interpreter
# Programming in C++
- Basics of C++ | C++ supports procedural and object-oriented programming. | Variable = named storage location | Data Types = int, float, char, bool | cin and cout = standard input and output
- Control Structures | Control flow directs program execution. | if-else = conditional branching | for Loop = repeats a known number of times | switch = multi-way branching
- Functions & Arrays | Functions modularise code; arrays store lists. | Function = reusable block of code | Array = collection of same-type elements | Call by Reference = function modifies caller's variable
- OOP Concepts | C++ supports classes and objects. | Class = blueprint for objects | Inheritance = deriving new class from existing | Polymorphism = same interface, different behaviour
# Networking & Internet
- Computer Networks | Networks connect computers to share resources. | LAN = local area network | WAN = wide area network | Topology = arrangement such as star, bus, ring
- Internet & Protocols | Internet uses standard protocols. | TCP/IP = protocol suite of the Internet | IP Address = unique address of a device | HTTP = protocol for web pages
- Network Devices | Devices route and connect traffic. | Router = forwards packets between networks | Switch = connects devices within a LAN | Modem = modulates and demodulates signals
- Cyber Security Basics | Protecting systems from threats. | Malware = malicious software such as viruses | Firewall = filters network traffic | Encryption = encoding data for confidentiality
# Databases & Emerging Technologies
- Database Basics | Databases store structured data. | DBMS = software managing databases | Table = rows and columns of data | SQL = language to query databases
- Cloud Computing | Computing delivered over the Internet. | Cloud Computing = on-demand resources over network | SaaS = software as a service | Virtualisation = running multiple OS on one machine
- IoT & AI | New technologies connect devices and add intelligence. | IoT = network of connected devices | Artificial Intelligence = machines performing intelligent tasks | Machine Learning = learning from data
- Big Data & Blockchain | Data scale and distributed ledgers. | Big Data = very large and complex datasets | Blockchain = distributed tamper-proof ledger | Data Analytics = examining data to draw conclusions
