@ cs302 | CS-302 | Discrete Structure | Sets, relations, logic, algebraic structures, graphs, posets and combinatorics.
# Set Theory, Relations & Functions
- Sets & Set Operations | Sets are the basic language for collections in computing and proofs. | Power Set = set of all subsets of A; it has 2^n elements | De Morgan's Law = complement of (A ∪ B) equals A' ∩ B' | Cartesian Product = A × B, the set of all ordered pairs (a, b)
- Relations & Their Properties | A relation on A is a subset of A × A classified by its properties. | Reflexive Relation = every element is related to itself, (a, a) ∈ R | Symmetric Relation = (a, b) ∈ R implies (b, a) ∈ R | Transitive Relation = (a, b) and (b, c) in R imply (a, c) in R
- Equivalence Relations & Partitions | Equivalence relations split a set into disjoint classes. | Equivalence Relation = relation that is reflexive, symmetric and transitive | Equivalence Class = set of all elements related to a given element | Partition = collection of disjoint non-empty subsets whose union is the whole set
- Functions & Pigeonhole Principle | Functions map each input to exactly one output. | Bijective Function = both one-one and onto; has an inverse | Composition of Functions = (g ∘ f)(x) = g(f(x)) | Pigeonhole Principle = n + 1 objects in n boxes force some box to hold two
# Algebraic Structures
- Groups & Semigroups | Algebraic structures are sets with operations obeying axioms. | Semigroup = set with an associative binary operation | Monoid = semigroup with an identity element | Group = monoid in which every element has an inverse
- Abelian, Cyclic Groups & Subgroups | Special groups have extra structure useful in coding and cryptography. | Abelian Group = group whose operation is commutative | Cyclic Group = group generated by a single element | Subgroup = subset that is itself a group under the same operation
- Cosets & Lagrange's Theorem | Cosets partition a group and fix the possible orders of subgroups. | Left Coset = aH = {ah : h ∈ H} for subgroup H | Lagrange's Theorem = the order of a subgroup divides the order of a finite group | Normal Subgroup = subgroup whose left and right cosets coincide
- Rings, Fields & Homomorphisms | Rings and fields carry two operations, the basis of modular arithmetic. | Ring = abelian group under + with an associative × distributing over + | Field = commutative ring where every non-zero element has a multiplicative inverse | Homomorphism = structure-preserving map f(a * b) = f(a) * f(b)
# Propositional Logic & Proofs
- Propositions & Connectives | Logic formalises statements and how they combine. | Proposition = declarative statement that is either true or false | Conditional p → q = false only when p is true and q is false | Biconditional p ↔ q = true when p and q have the same truth value
- Tautology, Contradiction & Normal Forms | Formulas are classified by truth tables and rewritten into standard forms. | Tautology = formula true for every truth assignment | Contradiction = formula false for every truth assignment | CNF = conjunction of clauses, each a disjunction of literals
- Predicates & Quantifiers | Predicate logic adds variables and quantifiers. | Universal Quantifier = ∀x P(x), P holds for every x in the domain | Existential Quantifier = ∃x P(x), P holds for at least one x | Negation Rule = ¬∀x P(x) is equivalent to ∃x ¬P(x)
- Rules of Inference & Mathematical Induction | Valid arguments derive conclusions; induction proves statements for all n. | Modus Ponens = from p and p → q conclude q | Modus Tollens = from ¬q and p → q conclude ¬p | Mathematical Induction = prove base case and P(k) ⇒ P(k+1) to prove P(n) for all n
# Graph Theory & Trees
- Graph Terminology & Representation | Graphs model networks of vertices and edges. | Handshaking Lemma = sum of vertex degrees equals twice the number of edges | Adjacency Matrix = n × n matrix with 1 where an edge joins two vertices | Isomorphic Graphs = graphs with an edge-preserving bijection between vertex sets
- Euler & Hamiltonian Paths | Special walks cover every edge or every vertex exactly once. | Euler Circuit = closed walk using every edge once; exists iff all degrees are even | Hamiltonian Cycle = cycle visiting every vertex exactly once | Konigsberg Problem = classic bridge puzzle proved impossible by Euler
- Planar Graphs & Graph Colouring | Planarity and colouring model layout and scheduling problems. | Euler's Formula = for a connected planar graph v − e + f = 2 | Chromatic Number = minimum colours to colour vertices with no adjacent pair alike | Four Colour Theorem = every planar map can be coloured with four colours
- Trees & Spanning Trees | Trees are connected acyclic graphs used in search and networks. | Tree Property = a tree with n vertices has exactly n − 1 edges | Spanning Tree = subgraph that is a tree containing all vertices | Kruskal's Algorithm = builds a minimum spanning tree by adding cheapest safe edges
# Posets, Lattices & Combinatorics
- Partial Order & Hasse Diagrams | Posets capture ordering where not every pair is comparable. | Partial Order = reflexive, antisymmetric and transitive relation | Hasse Diagram = drawing of a poset omitting loops and transitive edges | Total Order = partial order where every pair of elements is comparable
- Lattices & Boolean Algebra | Lattices have a least upper bound and greatest lower bound for every pair. | Lattice = poset where every pair has a join and a meet | Distributive Lattice = lattice where meet distributes over join | Boolean Algebra = complemented distributive lattice
- Permutations & Combinations | Counting principles count arrangements and selections. | Permutation = ordered arrangement, nPr = n!/(n − r)! | Combination = unordered selection, nCr = n!/(r!(n − r)!) | Inclusion-Exclusion = size of A ∪ B = size of A + size of B − size of A ∩ B
- Recurrence Relations & Generating Functions | Recurrences define sequences from earlier terms. | Recurrence Relation = equation expressing a(n) in terms of earlier terms | Characteristic Equation = polynomial whose roots give the homogeneous solution | Generating Function = power series Σ a(n) x^n encoding a sequence

@ cs303 | CS-303 | Data Structure | Arrays, stacks, queues, linked lists, trees, graphs, sorting, searching and hashing.
# Introduction, Arrays & Complexity
- Abstract Data Types & Complexity | Data structures organise data so operations are efficient. | Abstract Data Type = model defined by its operations, not its implementation | Big-O Notation = asymptotic upper bound on growth rate of running time | Space Complexity = memory an algorithm needs as a function of input size
- Arrays & Address Calculation | Arrays store elements in contiguous memory with constant-time indexing. | Row-major Order = elements of a row stored together; address = base + ((i·n) + j)·w | Column-major Order = elements of a column stored together | Sparse Matrix = matrix with mostly zero entries, stored as triplets
- Strings & Pattern Operations | Strings are character arrays with special operations. | String = sequence of characters terminated by a null in C | Naive Pattern Matching = compares pattern at every shift; O(nm) worst case | Concatenation = joining two strings end to end
- Recursion | A function that calls itself solves problems by smaller instances. | Base Case = condition that stops further recursive calls | Tail Recursion = recursive call is the last action of the function | Tower of Hanoi = classic recursion needing 2^n − 1 moves
# Stacks & Queues
- Stack Operations | A stack is a LIFO structure used for calls and expression evaluation. | LIFO = last in, first out access order | Push and Pop = insert and remove at the top of the stack | Stack Overflow = push attempted on a full stack
- Expression Conversion & Evaluation | Stacks convert infix expressions to postfix and evaluate them. | Infix Expression = operator between operands, e.g. A + B | Postfix Expression = operator after operands, e.g. AB+; needs no parentheses | Operator Precedence = rule deciding which operator is applied first
- Queues & Circular Queues | A queue is a FIFO structure used for scheduling and buffering. | FIFO = first in, first out access order | Circular Queue = queue where rear wraps to the front to reuse space | Queue Full Condition = (rear + 1) mod size == front in a circular queue
- Deque & Priority Queue | Variants of queues relax the FIFO rule. | Deque = double-ended queue allowing insert and delete at both ends | Priority Queue = elements served by priority rather than arrival order | Input-restricted Deque = insertion allowed at only one end
# Linked Lists
- Singly Linked List | Nodes hold data and a pointer to the next node. | Node = structure holding data and a link field | Head Pointer = pointer to the first node of the list | Traversal = visiting each node from head until NULL
- Doubly & Circular Linked Lists | Extra links allow two-way traversal or cyclic access. | Doubly Linked List = each node has next and previous pointers | Circular Linked List = last node points back to the first | Sentinel Node = dummy header node that simplifies edge cases
- Linked Implementation of Stack & Queue | Dynamic memory removes fixed-size limits. | Linked Stack = push and pop at the head in O(1) | Linked Queue = insert at rear and delete at front pointers | Dynamic Allocation = memory obtained at run time with malloc or new
- Polynomial Representation | Linked lists store sparse polynomials term by term. | Polynomial Node = stores coefficient, exponent and next pointer | Polynomial Addition = merge two lists by comparing exponents | Garbage Collection = reclaiming memory of nodes no longer referenced
# Trees
- Binary Tree Basics & Traversals | Binary trees give hierarchical storage with at most two children per node. | Full Binary Tree = every node has 0 or 2 children | Inorder Traversal = left subtree, root, right subtree | Level-order Traversal = visits nodes level by level using a queue
- Binary Search Tree | BST keeps keys ordered for fast search. | BST Property = left subtree keys < node key < right subtree keys | BST Deletion = node with two children is replaced by its inorder successor | Skewed Tree = degenerate BST that behaves like a linked list
- AVL Trees & Balancing | Self-balancing trees keep height logarithmic. | Balance Factor = height(left) − height(right), kept in {−1, 0, 1} | LL Rotation = single right rotation fixing left-left imbalance | AVL Height = O(log n), guaranteeing logarithmic operations
- B-Trees, Heaps & Threaded Trees | Multi-way and specialised trees serve disks and priority queues. | B-Tree = balanced multi-way search tree used in databases and file systems | Max Heap = complete binary tree where each parent ≥ its children | Threaded Binary Tree = null links replaced by pointers to inorder predecessor or successor
# Graphs, Sorting, Searching & Hashing
- Graph Representation & Traversal | Graphs are stored as matrices or lists and explored systematically. | Adjacency List = array of lists holding neighbours of each vertex | BFS = breadth-first search using a queue; finds shortest paths in unweighted graphs | DFS = depth-first search using a stack or recursion
- Shortest Path & Spanning Trees | Graph algorithms find minimum-cost routes and connections. | Dijkstra's Algorithm = single-source shortest paths with non-negative weights | Prim's Algorithm = grows a minimum spanning tree from a start vertex | Topological Sort = linear ordering of a DAG respecting edge directions
- Sorting Algorithms | Sorting arranges data to speed up searching and merging. | Quick Sort = partition-based; average O(n log n), worst O(n²) | Merge Sort = divide and conquer; O(n log n) always, needs extra space | Heap Sort = builds a heap then repeatedly extracts the maximum; O(n log n)
- Searching & Hashing | Search structures trade memory for faster lookup. | Binary Search = halves a sorted array each step; O(log n) | Hash Function = maps a key to a table index, e.g. key mod table size | Collision Resolution = handling equal hash indices by chaining or open addressing

@ cs304 | CS-304 | Digital Systems | Number systems, Boolean algebra, combinational and sequential circuits, logic families and A/D conversion.
# Number Systems & Codes
- Number Systems & Conversion | Digital systems use binary but humans read decimal, octal and hex. | Binary = base-2 system with digits 0 and 1 | Hexadecimal = base-16 system using 0-9 and A-F; one digit = 4 bits | Radix Conversion = repeated division for integers, repeated multiplication for fractions
- Complements & Signed Arithmetic | Complements let subtraction be done by addition. | 1's Complement = invert every bit | 2's Complement = 1's complement plus 1; standard signed representation | Overflow = result exceeds the range representable in n bits
- Binary Codes | Codes represent decimal digits and characters. | BCD = each decimal digit encoded as 4 bits | Gray Code = successive values differ in only one bit | Excess-3 Code = BCD value plus 3; self-complementing
- Error Detecting & Correcting Codes | Extra bits detect or correct transmission errors. | Parity Bit = bit added to make the count of 1s even or odd | Hamming Code = places parity bits at powers of 2 to correct single-bit errors | Hamming Distance = number of bit positions in which two codewords differ
# Boolean Algebra & Minimisation
- Boolean Laws & Theorems | Boolean algebra manipulates logic expressions. | De Morgan's Theorem = (A + B)' = A'·B' and (A·B)' = A' + B' | Absorption Law = A + A·B = A | Duality Principle = swapping + with · and 0 with 1 gives another valid identity
- Logic Gates & Universal Gates | Gates implement Boolean functions in hardware. | NAND Gate = universal gate; output 0 only when all inputs are 1 | XOR Gate = output 1 when inputs differ | Universal Gate = gate from which any Boolean function can be built
- SOP, POS & Canonical Forms | Functions are expressed as sums of products or products of sums. | Minterm = product term containing every variable once | Maxterm = sum term containing every variable once | Canonical SOP = function written as a sum of its minterms
- K-Map & Quine-McCluskey | Graphical and tabular methods minimise logic. | Karnaugh Map = grid of cells in Gray-code order for grouping adjacent 1s | Don't Care = input combination whose output does not matter; may be grouped | Prime Implicant = group that cannot be combined into a larger group
# Combinational Circuits
- Adders & Subtractors | Arithmetic circuits add and subtract binary numbers. | Half Adder = adds two bits; Sum = A ⊕ B, Carry = A·B | Full Adder = adds three bits including carry-in | Carry Look-ahead Adder = computes carries in parallel to cut propagation delay
- Multiplexers & Demultiplexers | Data selectors route one of many inputs to an output. | Multiplexer = selects one of 2^n inputs using n select lines | Demultiplexer = sends one input to one of many outputs | MUX as Function Generator = any n-variable function realised with a 2^n:1 MUX
- Decoders, Encoders & Comparators | Code converters and comparators support addressing and decisions. | Decoder = n inputs activate one of 2^n outputs | Priority Encoder = outputs the code of the highest-priority active input | Magnitude Comparator = outputs A > B, A = B or A < B
- Code Converters & Parity Generators | Combinational logic converts codes and checks integrity. | Binary to Gray Converter = G(n) = B(n) and G(i) = B(i+1) ⊕ B(i) | BCD to 7-Segment Decoder = drives display segments a-g from a BCD digit | Parity Generator = XOR tree producing an even or odd parity bit
# Sequential Circuits
- Latches & Flip-Flops | Sequential elements store one bit of state. | SR Latch = basic memory element; S = R = 1 is the forbidden state | JK Flip-Flop = J = K = 1 toggles the output | D Flip-Flop = output follows D at the clock edge
- Flip-Flop Conversion & Timing | Characteristic and excitation tables convert one flip-flop into another. | Excitation Table = required inputs for each present-to-next state transition | Setup Time = minimum time input must be stable before the clock edge | Race-around Condition = JK output toggles repeatedly when clock pulse is too long
- Registers & Shift Registers | Groups of flip-flops store and move multi-bit data. | SISO Register = serial-in serial-out shift register | PIPO Register = parallel-in parallel-out register | Ring Counter = shift register with output fed back to input
- Counters | Counters step through a defined sequence of states. | Asynchronous Counter = ripple counter where each flip-flop clocks the next | Synchronous Counter = all flip-flops share a common clock | Mod-N Counter = counter that resets after N states
# Logic Families & Converters
- Logic Family Characteristics | Families are compared by speed, power and noise immunity. | Fan-out = number of gate inputs one output can drive reliably | Propagation Delay = time between input change and output change | Noise Margin = tolerance to unwanted voltage on logic levels
- TTL, ECL & CMOS | Different transistor technologies implement logic gates. | TTL = transistor-transistor logic; fast but higher power | ECL = emitter-coupled logic; fastest because transistors never saturate | CMOS = complementary MOS; very low static power consumption
- Digital-to-Analog Converters | DACs convert digital codes into proportional voltages. | Weighted Resistor DAC = resistors in binary-weighted ratios | R-2R Ladder DAC = uses only two resistor values; easy to fabricate | DAC Resolution = smallest output step, Vref/2^n
- Analog-to-Digital Converters | ADCs sample and quantise analog signals. | Flash ADC = fastest ADC using 2^n − 1 comparators | Successive Approximation ADC = binary search on the input; n clock cycles | Quantisation Error = difference between analog value and its digital level

@ cs305 | CS-305 | Object Oriented Programming & Methodology | Classes, objects, encapsulation, inheritance, polymorphism, exceptions, templates and UML.
# OOP Concepts & Classes
- Procedural vs Object-Oriented Programming | OOP organises programs around objects that combine data and behaviour. | Object = instance of a class with state and behaviour | Class = blueprint defining attributes and methods | Procedural Programming = program organised as functions acting on shared data
- Encapsulation & Data Hiding | Encapsulation bundles data with methods and restricts direct access. | Encapsulation = wrapping data and functions into a single unit | Access Specifier = private, protected or public visibility control | Getter and Setter = methods giving controlled access to private fields
- Constructors & Destructors | Special member functions manage object lifetime. | Constructor = method with the class name called automatically at creation | Copy Constructor = creates an object as a copy of another object | Destructor = called when an object is destroyed to release resources
- Static Members & Friend Functions | Some members belong to the class rather than objects. | Static Data Member = single copy shared by all objects of a class | Friend Function = non-member function allowed to access private members | this Pointer = implicit pointer to the object invoking a member function
# Inheritance
- Inheritance Basics | A derived class reuses and extends a base class. | Base Class = class whose members are inherited | Derived Class = class that inherits and adds members | IS-A Relationship = inheritance models that a derived object is a kind of base
- Types of Inheritance | Classes can be combined in several hierarchies. | Multilevel Inheritance = class derived from another derived class | Multiple Inheritance = class derived from more than one base class | Hierarchical Inheritance = many classes derived from one base
- Diamond Problem & Virtual Base Class | Multiple inheritance can duplicate a common ancestor. | Diamond Problem = ambiguity when two parents share a base class | Virtual Base Class = ensures only one copy of the shared base | Constructor Order = base constructors run before derived constructors
- Composition vs Inheritance | Objects can also be built from other objects. | Composition = HAS-A relationship where an object contains others | Aggregation = weak HAS-A where parts can exist independently | Liskov Substitution = derived objects must be usable wherever base objects are
# Polymorphism
- Function Overloading | Same name, different parameter lists, resolved at compile time. | Function Overloading = multiple functions sharing a name with different signatures | Compile-time Polymorphism = binding decided by the compiler | Default Arguments = parameters given values when the caller omits them
- Operator Overloading | Operators can be redefined for user-defined types. | Operator Overloading = giving an operator a meaning for class objects | Unary Operator Overload = operator function with no explicit argument as a member | Non-overloadable Operators = scope ::, member access ., sizeof and ?:
- Virtual Functions & Runtime Polymorphism | Dynamic binding chooses the method from the object type. | Virtual Function = member function resolved at runtime through a base pointer | Late Binding = function call bound during execution | vtable = table of virtual function pointers kept per class
- Abstract Classes & Interfaces | Abstract classes define contracts for subclasses. | Pure Virtual Function = virtual function declared = 0 with no body | Abstract Class = class with at least one pure virtual function; cannot be instantiated | Interface = class containing only abstract methods, defining a contract
# Exceptions, Templates & I/O
- Exception Handling | Exceptions separate error handling from normal logic. | try Block = code that may throw an exception | catch Block = handler that receives a thrown exception | finally or Cleanup = code that always runs, e.g. to release resources
- Templates & Generic Programming | Templates write type-independent code. | Function Template = generic function parameterised by type | Class Template = generic class such as a container of any type | STL = standard template library of containers, iterators and algorithms
- Streams & File Handling | Streams abstract input and output devices. | Stream = sequence of bytes flowing to or from a device | ifstream and ofstream = classes for reading and writing files | File Modes = flags such as ios::in, ios::out and ios::app
- Java Basics for OOP | Java enforces object orientation with a managed runtime. | JVM = Java virtual machine executing platform-independent bytecode | Garbage Collector = automatically frees unreachable objects | Interface in Java = type declaring methods a class must implement
# Object-Oriented Design & UML
- Object-Oriented Analysis & Design | OOAD identifies objects and their responsibilities from requirements. | OOA = analysis modelling the problem domain as objects | OOD = design defining classes, interfaces and collaborations | Cohesion and Coupling = good design has high cohesion and low coupling
- UML Class & Object Diagrams | Structural diagrams show classes and relationships. | Class Diagram = shows classes, attributes, methods and associations | Multiplicity = number of instances participating in an association, e.g. 1..* | Generalisation = UML arrow showing inheritance
- UML Behavioural Diagrams | Dynamic diagrams show interactions and states. | Use Case Diagram = actors and the services the system provides | Sequence Diagram = ordered message exchange between objects over time | State Chart Diagram = states of an object and transitions between them
- Design Patterns Overview | Patterns are reusable solutions to recurring design problems. | Singleton Pattern = ensures a class has only one instance | Factory Pattern = creates objects without exposing creation logic | Observer Pattern = notifies dependents automatically when a subject changes
