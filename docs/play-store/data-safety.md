# Data safety, content rating and app content answers

These answers match [PRIVACY.md](../../PRIVACY.md). If the app's data handling changes, update both.

## Data safety form

**Does your app collect or share any of the required user data types?** Yes. The data is collected only when the user chooses to sign in.

**Is all of the user data collected by your app encrypted in transit?** Yes (HTTPS only).

**Do you provide a way for users to request that their data is deleted?** Yes. Users email the maintainer; the address is listed in the privacy policy.

| Data type | Collected | Shared | Optional? | Purpose |
|---|---|---|---|---|
| Personal info → Name | Yes | No | Optional (sign-in) | Account management |
| Personal info → Email address | Yes | No | Optional (sign-in) | Account management |
| Photos and videos → Photos | Yes | No | Optional (avatar / PDF uploads) | App functionality |
| Messages → Other in-app messages | Yes | No | Optional (comments, chat) | App functionality |
| App activity → Other user-generated content | Yes | No | Optional (notes and study progress sync) | App functionality |
| Device or other IDs | Yes | No | Required for sync | App functionality |

Not collected: location, contacts, financial info, health, web browsing history, audio, files outside uploads, ads data.

**Ads:** No, the app contains no ads.

## Content rating questionnaire (IARC)

- **Category:** Reference, News, or Educational
- **Violence, sexual content, profanity, drugs, gambling:** No to all
- **User interaction:** Yes. Users can interact through comments and chat. Content is moderated with reporting and bans.
- **Shares user location:** No
- **Digital purchases:** No

The expected result is **Everyone / 3+** or 12+, because of the user-generated chat.

## Target audience

- **Age groups:** 18 and over. Optionally add 16–17; the app is aimed at university students.
- **Appeals to children:** No
