Privacy overview

Academy LMS stores study progress in the browser and can sync selected learning activity to Neon when the cloud profile is enabled. That includes notes, bookmarks, quiz attempts, practice sessions, comments, messages, and lecture presence.

This version is a prototype and should not be treated as a secure identity system yet. Before a full launch, add authentication, moderation, consent flows, and stricter data retention controls.
