## Unit 1: Power Semiconductor Devices

### Short answer (2-3 marks)

- **Q.** Define *Power Diode*.  
  **Ans.** uncontrolled two-layer switch
- **Q.** Define *SCR*.  
  **Ans.** four-layer PNPN device turned on by gate
- **Q.** Define *Holding Current*.  
  **Ans.** minimum current to stay on
- **Q.** Define *Forward Blocking Mode*.  
  **Ans.** off state with forward voltage
- **Q.** Define *Latching Current*.  
  **Ans.** minimum current to latch on
- **Q.** Define *Gate Triggering*.  
  **Ans.** turning on by gate pulse
- **Q.** Define *Natural Commutation*.  
  **Ans.** AC supply reverses current
- **Q.** Define *Forced Commutation*.  
  **Ans.** circuit forces current to zero
- **Q.** Define *Turn-off Time*.  
  **Ans.** time to regain blocking
- **Q.** Define *Power MOSFET*.  
  **Ans.** fast switching, low voltage
- **Q.** Define *IGBT*.  
  **Ans.** combines MOSFET gate and BJT conduction
- **Q.** Define *GTO*.  
  **Ans.** gate turn-off thyristor

### Long answer (7 marks)

- **Q.** Explain *Power Diodes & Thyristors* in detail with a neat diagram.

## Unit 2: Controlled Rectifiers

### Short answer (2-3 marks)

- **Q.** Define *Firing Angle*.  
  **Ans.** delay α before triggering
- **Q.** Define *Average Output*.  
  **Ans.** Vdc = (Vm/2π)(1 + cos α) for R load
- **Q.** Define *Freewheeling Diode*.  
  **Ans.** provides path for inductive current
- **Q.** Define *Full Converter*.  
  **Ans.** Vdc = (2Vm/π) cos α
- **Q.** Define *Semi Converter*.  
  **Ans.** mix of SCRs and diodes
- **Q.** Define *Inversion Mode*.  
  **Ans.** α > 90° returns power to source
- **Q.** Define *Three-phase Full Converter*.  
  **Ans.** Vdc = (3√3 Vm/π) cos α
- **Q.** Define *Six-pulse Output*.  
  **Ans.** lower ripple
- **Q.** Define *Overlap Angle*.  
  **Ans.** due to source inductance
- **Q.** Define *Input Power Factor*.  
  **Ans.** depends on firing angle
- **Q.** Define *Harmonics*.  
  **Ans.** non-sinusoidal input current
- **Q.** Define *Dual Converter*.  
  **Ans.** two converters for four-quadrant operation

### Long answer (7 marks)

- **Q.** Explain *Single-phase Full Converters* in detail with a neat diagram.

- **Q.** Explain *Converter Performance* in detail with a neat diagram.
