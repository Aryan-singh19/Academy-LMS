# EC-702(B) Information Theory & Coding — Unit-wise Study Notes

> Entropy, source coding, channel capacity, block codes, cyclic codes, convolutional codes and modern codes.

## Unit 1: Information & Entropy

### Measure of Information

Information depends on probability.

- **Self-information:** I(x) = −log2 p(x) bits
- **Unit of Information:** bit for log base 2
- **Less Probable Events:** carry more information

### Entropy

Entropy is average information.

- **Entropy:** H(X) = −Σ p log2 p
- **Maximum Entropy:** log2 M for equiprobable symbols
- **Entropy of Binary Source:** maximum 1 bit when p = 0.5

### Joint & Conditional Entropy

Entropies describe pairs of variables.

- **Joint Entropy:** H(X,Y)
- **Conditional Entropy:** H(Y given X), remaining uncertainty
- **Chain Rule:** H(X,Y) = H(X) + H(Y given X)

### Mutual Information

Mutual information measures shared information.

- **Mutual Information:** I(X;Y) = H(X) − H(X given Y)
- **Non-negativity:** I(X;Y) ≥ 0
- **Symmetry:** I(X;Y) = I(Y;X)

## Unit 2: Source Coding

### Source Coding Theorem

Average code length is bounded by entropy.

- **Shannon's Source Coding Theorem:** L ≥ H(X)
- **Code Efficiency:** H/L
- **Redundancy:** 1 − efficiency

### Prefix Codes & Kraft Inequality

Prefix codes are instantaneously decodable.

- **Prefix Code:** no codeword is a prefix of another
- **Kraft Inequality:** Σ 2^(−li) ≤ 1
- **Uniquely Decodable:** every sequence decodes in only one way

### Shannon-Fano & Huffman Coding

Constructive algorithms build efficient codes.

- **Shannon-Fano Coding:** recursive splitting into equal-probability halves
- **Huffman Coding:** merges two least probable symbols repeatedly
- **Optimal Code:** Huffman gives minimum average length

### Lempel-Ziv & Arithmetic Coding

Universal methods adapt to data.

- **Lempel-Ziv:** dictionary-based coding without known statistics
- **Arithmetic Coding:** encodes a message as a sub-interval of [0,1)
- **Run-length Coding:** encodes repeated symbols compactly

## Unit 3: Channel Capacity

### Discrete Memoryless Channels

Channels are modelled by transition probabilities.

- **DMC:** channel where each output depends only on current input
- **Channel Matrix:** matrix of P(y given x)
- **Binary Symmetric Channel:** crossover probability p for both symbols

### Channel Capacity

Capacity is maximum mutual information.

- **Channel Capacity:** C = max I(X;Y) over input distributions
- **BSC Capacity:** C = 1 − H(p)
- **Noiseless Channel:** capacity log2 M

### Shannon-Hartley Theorem

Capacity of band-limited AWGN channel.

- **Shannon-Hartley:** C = B log2(1 + S/N)
- **Shannon Limit:** Eb/N0 of −1.6 dB as bandwidth → ∞
- **Bandwidth-Power Trade-off:** increasing B reduces required S/N

### Channel Coding Theorem

Reliable transmission possible below capacity.

- **Channel Coding Theorem:** error probability can be made arbitrarily small if R < C
- **Code Rate:** R = k/n
- **Converse:** reliable communication impossible if R > C

## Unit 4: Linear Block & Cyclic Codes

### Linear Block Codes

Codewords are linear combinations of basis vectors.

- **(n, k) Code:** k message bits mapped to n-bit codewords
- **Generator Matrix:** G = [I P] in systematic form
- **Parity Check Matrix:** H with GH^T = 0

### Syndrome Decoding & Hamming Codes

Syndromes locate errors.

- **Syndrome:** s = rH^T; zero if no detectable error
- **Hamming Code:** single-error-correcting code with n = 2^m − 1
- **Standard Array:** table used for syndrome decoding

### Cyclic Codes

Cyclic codes are generated by polynomials.

- **Generator Polynomial:** g(x) divides x^n − 1
- **Systematic Cyclic Encoding:** remainder of x^(n−k)m(x) / g(x) gives parity
- **Shift Register Encoder:** LFSR implementation of cyclic encoding

### BCH & Reed-Solomon Codes

Powerful cyclic codes correct multiple errors.

- **BCH Code:** cyclic code correcting multiple random errors
- **Reed-Solomon Code:** non-binary code correcting burst errors
- **Application:** RS codes in CDs, QR codes and DVB

## Unit 5: Convolutional & Modern Codes

### Convolutional Encoding

Encoders have memory.

- **Constraint Length:** K, number of shifts affecting output
- **Code Tree:** tree representation of encoder outputs
- **State Diagram:** encoder states and transitions

### Viterbi Decoding

Maximum-likelihood decoding uses the trellis.

- **Trellis:** time-indexed state diagram
- **Path Metric:** accumulated distance along a path
- **Survivor Path:** best path into each state retained

### Interleaving & Concatenated Codes

Combining codes handles bursts.

- **Interleaver:** spreads burst errors into random errors
- **Concatenated Code:** inner and outer codes combined
- **Burst Error:** consecutive bit errors

### Turbo & LDPC Codes

Modern codes approach Shannon limit.

- **Turbo Code:** parallel concatenated convolutional codes with iterative decoding
- **LDPC Code:** low-density parity-check code decoded by belief propagation
- **Polar Code:** capacity-achieving code used in 5G control channels
