## Answer Hints (Set A)

- **Q1(a):** SOA: architecture of interoperable services exposed over a network
- **Q1(b):** SOAP: XML-based messaging protocol for web services | WSDL: XML language describing a web service interface | UDDI: registry for publishing and discovering services
- **Q2(a):** Type 2 Hypervisor: runs on a host OS, e.g. VirtualBox
- **Q2(b):** Container: isolated user-space instance sharing the host OS kernel | Docker: platform for building and running containers | Kubernetes: system for orchestrating containers across clusters
- **Q3(a):** Pay-per-execution: billing only for actual function run time
- **Q3(b):** SLA: service level agreement defining guaranteed availability and performance | Pay-as-you-go: paying only for resources consumed | CapEx vs OpEx: cloud shifts capital expenditure to operating expenditure
- **Q4(a):** OpenStack: open-source platform for building private clouds
- **Q4(b):** AWS: Amazon Web Services, largest public cloud provider | Microsoft Azure: Microsoft's cloud platform | Google Cloud Platform: Google's cloud services such as Compute Engine and BigQuery
- **Q5(a):** Data Breach: unauthorised access to stored data
- **Q5(b):** IAM: identity and access management service | Principle of Least Privilege: grant only the permissions needed | Multi-factor Authentication: login requiring two or more proofs of identity
- **Q6(a):** Measured Service: usage is metered and billed
- **Q6(b):** SOA: architecture of interoperable services exposed over a network | Loose Coupling: services depend minimally on each other's internals | Service Contract: formal description of a service's interface
- **Q7(a):** IaaS: infrastructure as a service: VMs, storage and networks, e.g. AWS EC2
- **Q7(b):** Public Cloud: services offered to the general public by a provider | Private Cloud: cloud operated for one organisation | Hybrid Cloud: combination of public and private clouds
- **Q8(a):** Principle of Least Privilege: grant only the permissions needed
- **Q8(b):** Availability Zone: isolated data-centre location within a region | RTO: recovery time objective, maximum acceptable downtime | RPO: recovery point objective, maximum acceptable data loss
