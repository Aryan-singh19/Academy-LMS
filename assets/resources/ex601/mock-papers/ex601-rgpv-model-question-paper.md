## Answer Hints (Set A)

- **Q1(a):** Per-unit Value: actual value / base value
- **Q1(b):** Single Line Diagram: one-line representation of three-phase system | Impedance Diagram: equivalent circuit for analysis | Reactance Diagram: resistance neglected
- **Q2(a):** Acceleration Factor: speeds convergence, about 1.6
- **Q2(b):** Newton-Raphson Load Flow: uses Jacobian matrix | Jacobian: partial derivatives of power equations | Convergence: few iterations
- **Q3(a):** Priority List Method: commits cheapest units first
- **Q3(b):** Hydrothermal Scheduling: minimise thermal cost using hydro | Water Value: equivalent cost of water | Short-term Scheduling: daily operation
- **Q4(a):** Fault Current from Zbus: If = Vf/(Zkk + Zf)
- **Q4(b):** Symmetrical Fault: three-phase fault | Short Circuit MVA: base MVA / Zpu | Current Limiting Reactor: limits fault current
- **Q5(a):** Transient Stability: large sudden disturbances
- **Q5(b):** Equal Area Criterion: accelerating area equals decelerating area | Critical Clearing Angle: maximum angle for stability | Critical Clearing Time: time to clear fault
- **Q6(a):** Sparsity: Ybus is sparse
- **Q6(b):** Per-unit Value: actual value / base value | Base Impedance: Zb = kVb²/MVAb | Change of Base: Znew = Zold (MVAnew/MVAold)(kVold/kVnew)²
- **Q7(a):** Incremental Cost: dC/dP of generator
- **Q7(b):** B-coefficients: model transmission loss | Penalty Factor: Li = 1/(1 − ∂PL/∂Pi) | Loss Formula: PL = Σ Σ Pi Bij Pj
- **Q8(a):** Critical Clearing Angle: maximum angle for stability
- **Q8(b):** Speed Governor: adjusts mechanical power | Speed Regulation: R = Δf/ΔP | AGC: automatic generation control
