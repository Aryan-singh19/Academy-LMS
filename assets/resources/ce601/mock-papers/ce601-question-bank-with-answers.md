## Unit 1: Design Philosophies

### Short answer (2-3 marks)

- **Q.** Define *Working Stress Method*.  
  **Ans.** elastic stresses within permissible limits
- **Q.** Define *Limit State Method*.  
  **Ans.** safety against collapse and serviceability
- **Q.** Define *IS 456:2000*.  
  **Ans.** Indian code for plain and reinforced concrete
- **Q.** Define *Limit State of Collapse*.  
  **Ans.** flexure, shear, torsion, compression
- **Q.** Define *Limit State of Serviceability*.  
  **Ans.** deflection and cracking
- **Q.** Define *Partial Safety Factor*.

  **Ans.** 95% exceedance value
- **Q.** Define *Design Strength*.  
  **Ans.** characteristic strength / partial safety factor

  **Ans.** 95% non-exceedance load
- **Q.** Define *Concrete Stress Block*.  
  **Ans.** parabolic-rectangular, max 0.446 fck
- **Q.** Define *Ultimate Concrete Strain*.  
  **Ans.** 0.0035 in flexure
- **Q.** Define *Steel Design Stress*.  
  **Ans.** 0.87 fy

## Unit 2: Design of Beams

### Short answer (2-3 marks)

- **Q.** Define *Limiting Depth of Neutral Axis*.  
  **Ans.** xu,max = 0.48d for Fe 415
- **Q.** Define *Moment of Resistance*.  
  **Ans.** Mu = 0.36 fck b xu (d − 0.42 xu)
- **Q.** Define *Under-reinforced Section*.  
  **Ans.** steel yields before concrete crushes
- **Q.** Define *Doubly Reinforced Beam*.  
  **Ans.** steel in tension and compression
- **Q.** Define *Additional Moment*.  
  **Ans.** Mu − Mu,lim taken by compression steel
- **Q.** Define *Compression Steel Stress*.  
  **Ans.** from strain compatibility
- **Q.** Define *Effective Flange Width*.  
  **Ans.** lo/6 + bw + 6Df for T-beam
- **Q.** Define *Neutral Axis in Flange*.  
  **Ans.** rectangular beam behaviour
- **Q.** Define *T-beam*.  
  **Ans.** monolithic beam and slab
- **Q.** Define *Nominal Shear Stress*.  
  **Ans.** τv = Vu/(bd)
- **Q.** Define *Stirrups*.  
  **Ans.** vertical shear reinforcement
- **Q.** Define *Development Length*.  
  **Ans.** Ld = φσs/(4τbd)

### Long answer (7 marks)

- **Q.** Explain *Singly Reinforced Beams* in detail with a neat diagram.  
  **Key points:** Tension steel resists bending. Limiting Depth of Neutral Axis — xu,max = 0.48d for Fe 415; Moment of Resistance — Mu = 0.36 fck b xu (d − 0.42 xu); Under-reinforced Section — steel yields before concrete crushes.
- **Q.** Explain *Doubly Reinforced Beams* in detail with a neat diagram.  
  **Key points:** Compression steel adds capacity. Doubly Reinforced Beam — steel in tension and compression; Additional Moment — Mu − Mu,lim taken by compression steel; Compression Steel Stress — from strain compatibility.
- **Q.** Explain *Flanged Beams* in detail with a neat diagram.  
  **Key points:** T and L beams use slab as flange. Effective Flange Width — lo/6 + bw + 6Df for T-beam; Neutral Axis in Flange — rectangular beam behaviour; T-beam — monolithic beam and slab.
- **Q.** Explain *Shear & Bond* in detail with a neat diagram.  
  **Key points:** Shear reinforcement prevents diagonal tension failure. Nominal Shear Stress — τv = Vu/(bd); Stirrups — vertical shear reinforcement; Development Length — Ld = φσs/(4τbd).
