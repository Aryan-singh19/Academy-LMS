- **Q.** Define *Direct Axis Reactance*.

- **Q.** Define *Quadrature Axis Reactance*.

- **Q.** Define *Slip Test*.  
  **Ans.** determines Xd and Xq

### Long answer (7 marks)

- **Q.** Explain *Alternator Construction* in detail with a neat diagram.  
  **Key points:** Rotating field produces AC. Salient Pole Rotor — for low-speed hydro alternators; Cylindrical Rotor — for high-speed turbo alternators; Synchronous Speed — Ns = 120f/P.
- **Q.** Explain *EMF Equation & Winding Factors* in detail with a neat diagram.  
  **Key points:** Winding design affects EMF. Alternator EMF — E = 4.44 f Φ T Kp Kd; Pitch Factor — Kp = cos(α/2); Distribution Factor — Kd = sin(mβ/2)/(m sin(β/2)).

### Short answer (2-3 marks)

  **Ans.** pulsating field as two opposite rotating fields
- **Q.** Define *Not Self-starting*.  
  **Ans.** net starting torque is zero
- **Q.** Define *Forward and Backward Slip*.  
  **Ans.** s and 2 − s
- **Q.** Define *Split-phase Motor*.  
  **Ans.** resistance difference creates phase shift
- **Q.** Define *Capacitor Start Motor*.  
  **Ans.** high starting torque
- **Q.** Define *Permanent Split Capacitor*.  
  **Ans.** capacitor always in circuit
- **Q.** Define *Shaded Pole Motor*.  
  **Ans.** shading ring creates rotating field
- **Q.** Define *Universal Motor*.  
  **Ans.** series motor running on AC and DC
- **Q.** Define *Reluctance Motor*.  
  **Ans.** runs at synchronous speed
- **Q.** Define *Fans*.  
  **Ans.** PSC motors
- **Q.** Define *Mixer*.  
  **Ans.** universal motor
- **Q.** Define *Compressor*.  
  **Ans.** capacitor start capacitor run motor

### Long answer (7 marks)

- **Q.** Explain *Double Field Revolving Theory* in detail with a neat diagram.  
  **Key points:** Single-phase field is two rotating fields. Double Revolving Field Theory — pulsating field as two opposite rotating fields; Not Self-starting — net starting torque is zero; Forward and Backward Slip — s and 2 − s.
- **Q.** Explain *Split-phase & Capacitor Motors* in detail with a neat diagram.  
  **Key points:** Auxiliary winding provides starting torque. Split-phase Motor — resistance difference creates phase shift; Capacitor Start Motor — high starting torque; Permanent Split Capacitor — capacitor always in circuit.
- **Q.** Explain *Shaded Pole & Universal Motors* in detail with a neat diagram.  
  **Key points:** Small motors for appliances. Shaded Pole Motor — shading ring creates rotating field; Universal Motor — series motor running on AC and DC; Reluctance Motor — runs at synchronous speed.
- **Q.** Explain *Applications* in detail with a neat diagram.  
  **Key points:** Motors suit different loads. Fans — PSC motors; Mixer — universal motor; Compressor — capacitor start capacitor run motor.
