## Answer Hints (Set A)

- **Q1(a):** Nyquist Criterion: sample at fs ≥ 2fm
- **Q1(b):** PCM Bit Rate: n × fs | SQNR: about 6.02n + 1.76 dB for n bits | Companding: μ-law or A-law compression for non-uniform quantisation
- **Q2(a):** Eye Opening: margin against noise
- **Q2(b):** Equaliser: filter reversing channel distortion | Zero-forcing Equaliser: forces ISI to zero at sampling instants | Adaptive Equaliser: updates coefficients using LMS
- **Q3(a):** Bandwidth Efficiency: bits per second per hertz
- **Q3(b):** MSK: minimum shift keying with h = 0.5 | GMSK: Gaussian-filtered MSK used in GSM | Continuous Phase: no abrupt phase changes
- **Q4(a):** Symbol Synchronisation: finding correct sampling instants
- **Q4(b):** Maximum Likelihood Detection: chooses symbol with highest likelihood | Decision Region: signal-space region assigned to each symbol | Signal Space: vector representation using orthonormal basis functions
- **Q5(a):** PN Sequence: pseudo-noise binary sequence with noise-like properties
- **Q5(b):** DSSS: data multiplied by a fast PN chip sequence | FHSS: carrier frequency hops by a PN pattern | CDMA: multiple users share band using different codes
- **Q6(a):** Manchester Code: self-clocking with mid-bit transition
- **Q6(b):** Nyquist Criterion: sample at fs ≥ 2fm | Uniform Quantisation: equal step sizes | Quantisation Noise Power: Δ²/12
- **Q7(a):** BASK: on-off keying of a carrier
- **Q7(b):** DPSK: information in phase change between symbols | QPSK: 2 bits per symbol with four phases | Offset QPSK: staggered quadrature avoids 180° phase jumps
- **Q8(a):** FHSS: carrier frequency hops by a PN pattern
- **Q8(b):** Generator Matrix: produces codewords from messages | Syndrome: s = rH^T reveals error pattern | Minimum Distance: dmin; corrects (dmin − 1)/2 errors
