## Answer Hints (Set A)

- **Q1(a):** Active Element: supplies energy, e.g. voltage source
- **Q1(b):** KCL: algebraic sum of currents at a node is zero | KVL: algebraic sum of voltages around a loop is zero | Source Transformation: converting a voltage source with series R to a current source with parallel R
- **Q2(a):** Norton Equivalent: current source IN in parallel with RN
- **Q2(b):** Maximum Power Transfer: load resistance equals source resistance | AC Maximum Power: load impedance is the complex conjugate of source impedance | Efficiency at Maximum Power: 50%
- **Q3(a):** Final Value Theorem: f(∞) = lim s·F(s) as s → 0
- **Q3(b):** Unit Step Response: output to a sudden constant input | Impulse Response: output to a unit impulse; inverse Laplace of H(s) | Convolution: output equals input convolved with impulse response
- **Q4(a):** Series Connection: Z-parameters add
- **Q4(b):** Driving Point Impedance: ratio of voltage to current at the same port | Transfer Function: output transform divided by input transform | Poles and Zeros: roots of denominator and numerator
- **Q5(a):** Q-factor: Q = ω0L/R
- **Q5(b):** Anti-resonance: parallel resonance with maximum impedance | Dynamic Resistance: L/(CR) at parallel resonance | Selectivity: ability to discriminate between nearby frequencies
- **Q6(a):** Incidence Matrix: node-branch matrix of a network graph
- **Q6(b):** Active Element: supplies energy, e.g. voltage source | Passive Element: absorbs or stores energy, e.g. R, L, C | Dependent Source: source whose value depends on another circuit quantity
- **Q7(a):** Time Constant RC: τ = RC; capacitor charges to 63.2% in τ
- **Q7(b):** Damping Ratio: ζ = (R/2)√(C/L) for a series RLC | Underdamped Response: oscillatory decaying response when ζ < 1 | Critically Damped: fastest non-oscillatory response, ζ = 1
- **Q8(a):** Dynamic Resistance: L/(CR) at parallel resonance
- **Q8(b):** Low-pass Filter: passes frequencies below cut-off | Constant-k Filter: filter with Z1·Z2 = k² independent of frequency | m-derived Filter: sharper cut-off than constant-k
