## Answer Hints (Set A)

- **Q1(a):** AES: 128-bit block cipher with 10-14 rounds
- **Q1(b):** RSA: security from integer factorisation | Diffie-Hellman: key exchange over insecure channel | Elliptic Curve Cryptography: smaller keys for same security
- **Q2(a):** Forward Secrecy: past sessions safe if long-term key leaks
- **Q2(b):** Replay Attack: reusing captured messages | Man-in-the-middle: intercepting and altering communication | Downgrade Attack: forcing weaker protocol versions
- **Q3(a):** RBAC: role-based access control
- **Q3(b):** TEE: trusted execution environment, e.g. Intel SGX | Remote Attestation: proves software state | Sandbox: restricts untrusted code
- **Q4(a):** SIEM: security information and event management
- **Q4(b):** Firewall: filters traffic by rules | IDS/IPS: detects and blocks intrusions | Network Segmentation: limits lateral movement
- **Q5(a):** k-Anonymity: each record indistinguishable from k − 1 others
- **Q5(b):** DPDP Act 2023: India's digital personal data protection law | GDPR: EU data protection regulation | Data Minimisation: collect only what is needed
- **Q6(a):** Certificate Authority: issues and signs certificates
- **Q6(b):** AES: 128-bit block cipher with 10-14 rounds | Block Cipher Modes: CBC, CTR and GCM | Authenticated Encryption: confidentiality plus integrity, e.g. AES-GCM
- **Q7(a):** Buffer Overflow: writing beyond buffer bounds
- **Q7(b):** ASLR: randomises memory layout | DEP/NX: non-executable memory regions | Stack Canary: detects stack smashing
- **Q8(a):** GDPR: EU data protection regulation
- **Q8(b):** Adversarial Example: small perturbation causing misclassification | Data Poisoning: corrupting training data | Model Extraction: stealing model via queries
