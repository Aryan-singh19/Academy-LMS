# CE-504(B) Remote Sensing & GIS — Question Bank with Answer Hints

## Unit 1: Remote Sensing Physics

### Short answer (2-3 marks)

- **Q.** Define *EMR*.  
  **Ans.** energy propagating as waves
- **Q.** Define *Atmospheric Window*.  
  **Ans.** wavelengths passing through atmosphere
- **Q.** Define *Scattering*.  
  **Ans.** redirection of radiation by particles
- **Q.** Define *Reflectance*.  
  **Ans.** ratio of reflected to incident energy
- **Q.** Define *Spectral Signature*.  
  **Ans.** reflectance curve of material
- **Q.** Define *Vegetation Red Edge*.  
  **Ans.** sharp rise in reflectance near 700 nm
- **Q.** Define *Spatial Resolution*.  
  **Ans.** ground pixel size
- **Q.** Define *Spectral Resolution*.  
  **Ans.** number and width of bands
- **Q.** Define *Temporal Resolution*.  
  **Ans.** revisit frequency
- **Q.** Define *Sun-synchronous Orbit*.  
  **Ans.** same local time crossing
- **Q.** Define *Geostationary Orbit*.  
  **Ans.** fixed over equator
- **Q.** Define *Swath*.  
  **Ans.** width of ground imaged

### Long answer (7 marks)

- **Q.** Explain *Electromagnetic Radiation* in detail with a neat diagram.  
  **Key points:** Energy interacts with atmosphere and surface. EMR — energy propagating as waves; Atmospheric Window — wavelengths passing through atmosphere; Scattering — redirection of radiation by particles.
- **Q.** Explain *Energy Interaction with Surface* in detail with a neat diagram.  
  **Key points:** Features reflect energy differently. Reflectance — ratio of reflected to incident energy; Spectral Signature — reflectance curve of material; Vegetation Red Edge — sharp rise in reflectance near 700 nm.
- **Q.** Explain *Resolutions* in detail with a neat diagram.  
  **Key points:** Sensors are characterised by resolution. Spatial Resolution — ground pixel size; Spectral Resolution — number and width of bands; Temporal Resolution — revisit frequency.
- **Q.** Explain *Orbits & Platforms* in detail with a neat diagram.  
  **Key points:** Satellites carry sensors in orbits. Sun-synchronous Orbit — same local time crossing; Geostationary Orbit — fixed over equator; Swath — width of ground imaged.

## Unit 3: Digital Image Processing

### Short answer (2-3 marks)

- **Q.** Define *Radiometric Correction*.  
  **Ans.** removes sensor and atmospheric errors
- **Q.** Define *Geometric Correction*.  
  **Ans.** aligns image to map
- **Q.** Define *Georeferencing*.  
  **Ans.** assigning coordinates to image
- **Q.** Define *Contrast Stretching*.  
  **Ans.** expands range of values
- **Q.** Define *NDVI*.  
  **Ans.** (NIR − Red)/(NIR + Red) vegetation index
- **Q.** Define *Filtering*.  
  **Ans.** smooths or sharpens image
- **Q.** Define *Supervised Classification*.  
  **Ans.** uses training samples
- **Q.** Define *Unsupervised Classification*.  
  **Ans.** clustering without training
- **Q.** Define *Maximum Likelihood Classifier*.  
  **Ans.** statistical classifier
- **Q.** Define *Error Matrix*.  
  **Ans.** compares classified and reference data
- **Q.** Define *Overall Accuracy*.  
  **Ans.** correct pixels / total
- **Q.** Define *Kappa Coefficient*.  
  **Ans.** agreement beyond chance

### Long answer (7 marks)

- **Q.** Explain *Preprocessing* in detail with a neat diagram.  
  **Key points:** Corrections remove distortions. Radiometric Correction — removes sensor and atmospheric errors; Geometric Correction — aligns image to map; Georeferencing — assigning coordinates to image.
- **Q.** Explain *Image Enhancement* in detail with a neat diagram.  
  **Key points:** Enhancement improves visual interpretation. Contrast Stretching — expands range of values; NDVI — (NIR − Red)/(NIR + Red) vegetation index; Filtering — smooths or sharpens image.
- **Q.** Explain *Image Classification* in detail with a neat diagram.  
  **Key points:** Pixels are grouped into classes. Supervised Classification — uses training samples; Unsupervised Classification — clustering without training; Maximum Likelihood Classifier — statistical classifier.
- **Q.** Explain *Accuracy Assessment* in detail with a neat diagram.  
  **Key points:** Maps are checked against ground truth. Error Matrix — compares classified and reference data; Overall Accuracy — correct pixels / total; Kappa Coefficient — agreement beyond chance.
