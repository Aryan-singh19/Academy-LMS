## Answer Hints (Set A)

- **Q1(a):** BIS SP-46: Indian code for engineering drawing practice
- **Q1(b):** Aligned System: dimensions read from bottom or right | Unidirectional System: all dimensions read from bottom | Dimension Line: thin line with arrowheads
- **Q2(a):** Concentric Circle Method: draws ellipse from two circles
- **Q2(b):** Cycloid: locus of a point on a circle rolling on a straight line | Epicycloid: circle rolls outside another circle | Hypocycloid: circle rolls inside another circle
- **Q3(a):** Traces: points where line meets reference planes
- **Q3(b):** Plane Perpendicular to One Plane: appears as a line in that view | Inclined Plane: drawn in two or three stages | True Shape: seen when plane is parallel to projection plane
- **Q4(a):** Parallel Line Development: used for prisms and cylinders
- **Q4(b):** Prism: two equal end faces joined by rectangles | Pyramid: polygon base with triangular faces meeting at apex | Cone: circular base tapering to apex
- **Q5(a):** Isometric Scale: 0.816 of true length
- **Q5(b):** Orthographic from Isometric: draw front, top and side views | Isometric from Orthographic: build up using box method | Hidden Lines: shown dashed in orthographic views
- **Q6(a):** Scale of Chords: used to set off angles
- **Q6(b):** BIS SP-46: Indian code for engineering drawing practice | Line Types: continuous thick for visible, dashed for hidden edges | Lettering: standard single-stroke letters
- **Q7(a):** First Angle Projection: object between observer and plane; used in India
- **Q7(b):** Front View: projection on vertical plane | Top View: projection on horizontal plane | Quadrant: position of point relative to HP and VP
- **Q8(a):** Isometric from Orthographic: build up using box method
- **Q8(b):** CAD: computer aided design | AutoCAD: popular 2D and 3D drafting software | Layers: organise drawing elements
