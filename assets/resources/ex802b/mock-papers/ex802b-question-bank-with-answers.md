## Unit 1: Stepper Motors

### Short answer (2-3 marks)

- **Q.** Define *Stepper Motor*.  
  **Ans.** converts pulses into steps
- **Q.** Define *Step Angle*.  
  **Ans.** 360°/(steps per revolution)
- **Q.** Define *Holding Torque*.  
  **Ans.** torque at standstill when energised
- **Q.** Define *Variable Reluctance Stepper*.  
  **Ans.** toothed soft-iron rotor
- **Q.** Define *Permanent Magnet Stepper*.  
  **Ans.** magnet rotor
- **Q.** Define *Hybrid Stepper*.  
  **Ans.** combines both
- **Q.** Define *Full Step*.  
  **Ans.** one or two phases energised
- **Q.** Define *Half Step*.  
  **Ans.** alternates one and two phases
- **Q.** Define *Microstepping*.  
  **Ans.** proportional currents for small steps
- **Q.** Define *Pull-in Torque*.  
  **Ans.** maximum torque to start in step
- **Q.** Define *Pull-out Torque*.  
  **Ans.** maximum torque while running
- **Q.** Define *Resonance*.  
  **Ans.** vibration at certain step rates

### Long answer (7 marks)

- **Q.** Explain *Stepper Motor Principle* in detail with a neat diagram.  
  **Key points:** Steppers move in discrete steps. Stepper Motor — converts pulses into steps; Step Angle — 360°/(steps per revolution); Holding Torque — torque at standstill when energised.
- **Q.** Explain *Types of Stepper Motors* in detail with a neat diagram.  
  **Key points:** Construction varies. Variable Reluctance Stepper — toothed soft-iron rotor; Permanent Magnet Stepper — magnet rotor; Hybrid Stepper — combines both.
- **Q.** Explain *Drive Modes* in detail with a neat diagram.  
  **Key points:** Excitation modes change performance. Full Step — one or two phases energised; Half Step — alternates one and two phases; Microstepping — proportional currents for small steps.
- **Q.** Explain *Characteristics* in detail with a neat diagram.  
  **Key points:** Performance curves. Pull-in Torque — maximum torque to start in step; Pull-out Torque — maximum torque while running; Resonance — vibration at certain step rates.

## Unit 2: Switched Reluctance Motors

### Short answer (2-3 marks)

- **Q.** Define *SRM*.  
  **Ans.** salient stator and rotor, no windings on rotor
- **Q.** Define *Stator Phases*.  
  **Ans.** concentrated windings
- **Q.** Define *Rotor Position*.  
  **Ans.** determines phase switching
- **Q.** Define *Reluctance Torque*.  
  **Ans.** T = ½ i² dL/dθ
- **Q.** Define *Aligned Position*.  
  **Ans.** minimum reluctance
- **Q.** Define *Unaligned Position*.  
  **Ans.** maximum reluctance
- **Q.** Define *Asymmetric Bridge Converter*.  
  **Ans.** two switches per phase
- **Q.** Define *Commutation*.  
  **Ans.** switching phases in sequence
- **Q.** Define *Current Chopping*.  
  **Ans.** controls phase current
- **Q.** Define *Advantages*.  
  **Ans.** robust, low cost
- **Q.** Define *Torque Ripple*.  
  **Ans.** main drawback
- **Q.** Define *Applications*.  
  **Ans.** EVs, aerospace, appliances

### Long answer (7 marks)

- **Q.** Explain *SRM Construction* in detail with a neat diagram.  
  **Key points:** Doubly salient structure. SRM — salient stator and rotor, no windings on rotor; Stator Phases — concentrated windings; Rotor Position — determines phase switching.
- **Q.** Explain *Torque Production* in detail with a neat diagram.  
  **Key points:** Torque from reluctance variation. Reluctance Torque — T = ½ i² dL/dθ; Aligned Position — minimum reluctance; Unaligned Position — maximum reluctance.
- **Q.** Explain *SRM Converters* in detail with a neat diagram.  
  **Key points:** Converters energise phases. Asymmetric Bridge Converter — two switches per phase; Commutation — switching phases in sequence; Current Chopping — controls phase current.
- **Q.** Explain *SRM Applications* in detail with a neat diagram.  
  **Key points:** Rugged motors for harsh conditions. Advantages — robust, low cost; Torque Ripple — main drawback; Applications — EVs, aerospace, appliances.
