- **Q2(a):** Bayes' Rule: posterior ∝ likelihood × prior
- **Q2(b):** Maximum Likelihood Estimation: parameter maximising likelihood | MAP Estimation: maximises posterior | Unbiased Estimator: expected value equals true parameter
- **Q3(a):** Utilisation: ρ = λ/μ
- **Q3(b):** HMM: Markov chain with unobserved states | Forward Algorithm: computes observation likelihood | Viterbi Decoding: most likely hidden state sequence
- **Q4(a):** Simplex Method: moves along vertices of feasible region
- **Q4(b):** Convex Function: line between points lies above graph | Convex Set: contains segment between any two points | Global Minimum: every local minimum of a convex function
- **Q5(a):** Bipartite Matching: pairs vertices across two sets
- **Q5(b):** Graph Laplacian: L = D − A | Algebraic Connectivity: second smallest Laplacian eigenvalue | Spectral Clustering: clusters using Laplacian eigenvectors
- **Q6(a):** Ill-conditioned System: small input changes give large output changes
- **Q6(b):** Vector Space: set closed under addition and scalar multiplication | Basis: linearly independent spanning set | Rank-Nullity Theorem: rank + nullity = number of columns
- **Q7(a):** Stationary Process: statistics invariant to time shift
- **Q7(b):** Markov Property: memoryless state transitions | Transition Matrix: probabilities between states | Stationary Distribution: π = πP
- **Q8(a):** Algebraic Connectivity: second smallest Laplacian eigenvalue
- **Q8(b):** Generating Function: power series encoding sequences | Catalan Numbers: count binary trees and balanced parentheses | Inclusion-Exclusion: counts union by alternating sums
