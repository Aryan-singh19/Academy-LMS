## Unit 4: Three-phase Induction Motor

### Short answer (2-3 marks)

- **Q.** Define *Rotating Magnetic Field*.  
  **Ans.** produced by three-phase currents
- **Q.** Define *Squirrel Cage Rotor*.  
  **Ans.** bars short-circuited by end rings
- **Q.** Define *Slip Ring Rotor*.  
  **Ans.** wound rotor with external resistance
- **Q.** Define *Slip*.  
  **Ans.** s = (Ns − N)/Ns
- **Q.** Define *Rotor Frequency*.  
  **Ans.** f2 = s f
- **Q.** Define *Rotor EMF*.  
  **Ans.** sE2
- **Q.** Define *Torque*.  
  **Ans.** T ∝ s E2² R2/(R2² + (sX2)²)
- **Q.** Define *Maximum Torque Condition*.  
  **Ans.** R2 = sX2
- **Q.** Define *Starting Torque*.  
  **Ans.** maximum when R2 = X2
- **Q.** Define *Rotor Input*.  
  **Ans.** Pg
- **Q.** Define *Rotor Copper Loss*.  
  **Ans.** s × Pg
- **Q.** Define *Mechanical Power*.  
  **Ans.** (1 − s) Pg

### Long answer (7 marks)

- **Q.** Explain *Construction & Principle* in detail with a neat diagram.  
  **Key points:** Rotating field induces rotor currents. Rotating Magnetic Field — produced by three-phase currents; Squirrel Cage Rotor — bars short-circuited by end rings; Slip Ring Rotor — wound rotor with external resistance.
- **Q.** Explain *Slip & Rotor Quantities* in detail with a neat diagram.  
  **Key points:** Rotor frequency depends on slip. Slip — s = (Ns − N)/Ns; Rotor Frequency — f2 = s f; Rotor EMF — sE2.
- **Q.** Explain *Torque Equation* in detail with a neat diagram.  
  **Key points:** Torque depends on slip and rotor parameters. Torque — T ∝ s E2² R2/(R2² + (sX2)²); Maximum Torque Condition — R2 = sX2; Starting Torque — maximum when R2 = X2.
- **Q.** Explain *Power Flow* in detail with a neat diagram.  
  **Key points:** Power splits into losses and output. Rotor Input — Pg; Rotor Copper Loss — s × Pg; Mechanical Power — (1 − s) Pg.
