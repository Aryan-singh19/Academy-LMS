## Unit 1: Antenna Fundamentals

### Short answer (2-3 marks)

- **Q.** Define *Antenna*.

- **Q.** Define *Near Field*.  
  **Ans.** reactive region close to the antenna
- **Q.** Define *Far Field*.  
  **Ans.** region beyond 2D²/λ where pattern is stable
- **Q.** Define *Radiation Pattern*.  
  **Ans.** plot of radiated power versus direction
- **Q.** Define *HPBW*.  
  **Ans.** half-power beamwidth between −3 dB points
- **Q.** Define *Side Lobe*.  
  **Ans.** minor lobe outside the main beam
- **Q.** Define *Directivity*.  
  **Ans.** maximum radiation intensity over average
- **Q.** Define *Gain*.  
  **Ans.** directivity × radiation efficiency
- **Q.** Define *Effective Aperture*.  
  **Ans.** Ae = Gλ²/(4π)
- **Q.** Define *Radiation Resistance*.  
  **Ans.** resistance accounting for radiated power
- **Q.** Define *Input Impedance*.  
  **Ans.** impedance seen at antenna terminals
- **Q.** Define *Polarisation*.  
  **Ans.** orientation of radiated E-field

### Long answer (7 marks)

- **Q.** Explain *Radiation Mechanism* in detail with a neat diagram.  
  **Key points:** Accelerating charges radiate electromagnetic energy. Antenna — transducer between guided and free-space waves; Near Field — reactive region close to the antenna; Far Field — region beyond 2D²/λ where pattern is stable.
- **Q.** Explain *Radiation Pattern & Beamwidth* in detail with a neat diagram.  
  **Key points:** Patterns show how power is distributed in space. Radiation Pattern — plot of radiated power versus direction; HPBW — half-power beamwidth between −3 dB points; Side Lobe — minor lobe outside the main beam.

## Unit 2: Wire Antennas

### Short answer (2-3 marks)

- **Q.** Define *Hertzian Dipole*.  
  **Ans.** short current element much smaller than λ
- **Q.** Define *Radiation Resistance of Short Dipole*.  
  **Ans.** 80π²(dl/λ)²
- **Q.** Define *Doughnut Pattern*.  
  **Ans.** sin θ field pattern
- **Q.** Define *Half-wave Dipole*.  
  **Ans.** length λ/2, radiation resistance about 73 Ω
- **Q.** Define *Directivity of Dipole*.  
  **Ans.** 1.64 (2.15 dBi)
- **Q.** Define *Folded Dipole*.  
  **Ans.** input resistance about 292 Ω
- **Q.** Define *Quarter-wave Monopole*.  
  **Ans.** λ/4 over ground, about 36.5 Ω
- **Q.** Define *Image Theory*.  
  **Ans.** ground plane creates image doubling the antenna
- **Q.** Define *Small Loop*.  
  **Ans.** magnetic-dipole-like radiator used in receivers
- **Q.** Define *Rhombic Antenna*.  
  **Ans.** terminated travelling-wave antenna for HF
- **Q.** Define *Beverage Antenna*.  
  **Ans.** long wire for low-frequency reception
- **Q.** Define *Helical Antenna*.  
  **Ans.** circularly polarised in axial mode

### Long answer (7 marks)

- **Q.** Explain *Hertzian Dipole* in detail with a neat diagram.  
  **Key points:** Infinitesimal dipole is the basic radiator. Hertzian Dipole — short current element much smaller than λ; Radiation Resistance of Short Dipole — 80π²(dl/λ)²; Doughnut Pattern — sin θ field pattern.
- **Q.** Explain *Half-wave Dipole* in detail with a neat diagram.  
  **Key points:** Most common resonant antenna. Half-wave Dipole — length λ/2, radiation resistance about 73 Ω; Directivity of Dipole — 1.64 (2.15 dBi); Folded Dipole — input resistance about 292 Ω.
- **Q.** Explain *Monopole & Loop Antennas* in detail with a neat diagram.  
  **Key points:** Ground planes and loops give other options. Quarter-wave Monopole — λ/4 over ground, about 36.5 Ω; Image Theory — ground plane creates image doubling the antenna; Small Loop — magnetic-dipole-like radiator used in receivers.
- **Q.** Explain *Travelling Wave Antennas* in detail with a neat diagram.  
  **Key points:** Non-resonant antennas give broadband operation. Rhombic Antenna — terminated travelling-wave antenna for HF; Beverage Antenna — long wire for low-frequency reception; Helical Antenna — circularly polarised in axial mode.

## Unit 3: Antenna Arrays

### Short answer (2-3 marks)

- **Q.** Define *Array Factor*.  
  **Ans.** pattern of isotropic elements in the array
- **Q.** Define *Pattern Multiplication*.  
  **Ans.** total pattern = element pattern × array factor
- **Q.** Define *Uniform Linear Array*.  
  **Ans.** equal amplitude and spacing elements
- **Q.** Define *Broadside Array*.  
  **Ans.** maximum perpendicular to array axis; zero phase difference
- **Q.** Define *End-fire Array*.  
  **Ans.** maximum along the array axis
- **Q.** Define *Hansen-Woodyard Condition*.  
  **Ans.** increased directivity for end-fire
- **Q.** Define *Binomial Array*.  
  **Ans.** amplitudes follow binomial coefficients; no side lobes
- **Q.** Define *Phased Array*.  
  **Ans.** electronically steers beam by phase shifters
- **Q.** Define *Grating Lobe*.  
  **Ans.** unwanted lobe when spacing exceeds λ
- **Q.** Define *Yagi-Uda*.  
  **Ans.** driven dipole with reflector and directors
- **Q.** Define *Reflector*.  
  **Ans.** slightly longer parasitic element behind
- **Q.** Define *Director*.  
  **Ans.** shorter elements in front increasing gain

### Long answer (7 marks)

- **Q.** Explain *Array Fundamentals* in detail with a neat diagram.  
  **Key points:** Arrays combine elements for higher directivity. Array Factor — pattern of isotropic elements in the array; Pattern Multiplication — total pattern = element pattern × array factor; Uniform Linear Array — equal amplitude and spacing elements.
- **Q.** Explain *Broadside & End-fire Arrays* in detail with a neat diagram.  
  **Key points:** Phasing steers the main beam. Broadside Array — maximum perpendicular to array axis; zero phase difference; End-fire Array — maximum along the array axis; Hansen-Woodyard Condition — increased directivity for end-fire.
- **Q.** Explain *Binomial & Phased Arrays* in detail with a neat diagram.  
  **Key points:** Amplitude and phase control shape the beam. Binomial Array — amplitudes follow binomial coefficients; no side lobes; Phased Array — electronically steers beam by phase shifters; Grating Lobe — unwanted lobe when spacing exceeds λ.
- **Q.** Explain *Yagi-Uda Antenna* in detail with a neat diagram.  
  **Key points:** Parasitic arrays give directional gain. Yagi-Uda — driven dipole with reflector and directors; Reflector — slightly longer parasitic element behind; Director — shorter elements in front increasing gain.

## Unit 5: Wave Propagation

### Short answer (2-3 marks)

- **Q.** Define *Ground Wave*.  
  **Ans.** surface wave guided along Earth, used below 2 MHz
- **Q.** Define *Surface Wave Attenuation*.  
  **Ans.** increases with frequency
- **Q.** Define *Vertical Polarisation*.  
  **Ans.** preferred for ground waves
- **Q.** Define *Ionosphere*.  
  **Ans.** ionised layers D, E, F1, F2
- **Q.** Define *Critical Frequency*.  
  **Ans.** highest frequency reflected at vertical incidence
- **Q.** Define *MUF*.  
  **Ans.** maximum usable frequency = fc / cos θ
- **Q.** Define *Line-of-sight Range*.  
  **Ans.** d ≈ 4.12(√h1 + √h2) km with heights in metres
- **Q.** Define *Radio Horizon*.  
  **Ans.** 4/3 Earth radius model for refraction
- **Q.** Define *Duct Propagation*.  
  **Ans.** trapping in atmospheric layers
- **Q.** Define *Skip Distance*.  
  **Ans.** minimum distance where sky wave returns
- **Q.** Define *Virtual Height*.  
  **Ans.** apparent reflection height
- **Q.** Define *Fading*.  
  **Ans.** signal strength variation due to multipath and ionosphere

### Long answer (7 marks)

- **Q.** Explain *Ground Wave Propagation* in detail with a neat diagram.  
  **Key points:** Low-frequency waves follow the Earth's surface. Ground Wave — surface wave guided along Earth, used below 2 MHz; Surface Wave Attenuation — increases with frequency; Vertical Polarisation — preferred for ground waves.
- **Q.** Explain *Sky Wave Propagation* in detail with a neat diagram.  
  **Key points:** HF waves reflect from the ionosphere. Ionosphere — ionised layers D, E, F1, F2; Critical Frequency — highest frequency reflected at vertical incidence; MUF — maximum usable frequency = fc / cos θ.
- **Q.** Explain *Space Wave Propagation* in detail with a neat diagram.  
  **Key points:** VHF and above travel by line of sight. Line-of-sight Range — d ≈ 4.12(√h1 + √h2) km with heights in metres; Radio Horizon — 4/3 Earth radius model for refraction; Duct Propagation — trapping in atmospheric layers.
- **Q.** Explain *Skip Distance & Fading* in detail with a neat diagram.  
  **Key points:** Sky waves create zones and fluctuations. Skip Distance — minimum distance where sky wave returns; Virtual Height — apparent reflection height; Fading — signal strength variation due to multipath and ionosphere.
