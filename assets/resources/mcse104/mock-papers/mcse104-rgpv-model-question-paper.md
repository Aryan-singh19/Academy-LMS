## Answer Hints (Set A)

- **Q1(a):** OSI Model: seven-layer reference model
- **Q1(b):** Circuit Switching: dedicated path for session | Packet Switching: packets routed independently | Virtual Circuit: connection-oriented packet switching
- **Q2(a):** AS Path: list of ASes a route traverses
- **Q2(b):** IP Multicast: group communication | PIM: protocol independent multicast | IGMP: hosts join multicast groups
- **Q3(a):** Token Bucket: traffic shaping mechanism
- **Q3(b):** RED: random early detection | Bufferbloat: excessive buffering causing latency | Fair Queuing: equal share among flows
- **Q4(a):** P4: language for programming packet processing
- **Q4(b):** SDN: centralised programmable network control | OpenFlow: protocol between controller and switches | Flow Table: match-action rules in switch
- **Q5(a):** Hidden Terminal Problem: stations not hearing each other
- **Q5(b):** MANET: mobile ad hoc network | AODV: on-demand routing protocol | DTN: delay tolerant networking
- **Q6(a):** CDN: content delivery network caching near users
- **Q6(b):** OSI Model: seven-layer reference model | TCP/IP Model: four-layer Internet model | End-to-end Principle: intelligence at end hosts
- **Q7(a):** AIMD: additive increase multiplicative decrease
- **Q7(b):** QUIC: UDP-based transport with built-in TLS | BBR: congestion control based on bandwidth and RTT | Multipath TCP: uses several paths simultaneously
- **Q8(a):** AODV: on-demand routing protocol
- **Q8(b):** TLS: transport layer security | IPsec: network-layer security | VPN: secure tunnel over public network
