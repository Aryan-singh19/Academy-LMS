## Answer Hints (Set A)

- **Q1(a):** Software Crisis: projects running late, over budget and unreliable
- **Q1(b):** Waterfall Model: sequential phases from requirements to maintenance | V-Model: each development phase paired with a testing phase | Phase Containment: catching errors in the phase that created them
- **Q2(a):** Characteristics of SRS: correct, unambiguous, complete, consistent and verifiable
- **Q2(b):** Data Flow Diagram: shows processes, data stores and flows between them | Data Dictionary: definitions of all data elements used in models | ER Diagram: models entities, attributes and relationships
- **Q3(a):** Architectural Style: pattern such as layered, client-server or pipe-and-filter
- **Q3(b):** Golden Rules: place user in control, reduce memory load, keep interface consistent | Usability: ease with which users achieve goals | Heuristic Evaluation: expert review against usability principles
- **Q4(a):** Unit Testing: testing individual modules in isolation
- **Q4(b):** Verification: are we building the product right | Validation: are we building the right product | Test Case: inputs, steps and expected result for checking a feature
- **Q5(a):** Function Point: size measure from inputs, outputs, inquiries, files and interfaces
- **Q5(b):** Gantt Chart: bar chart showing task durations over time | Critical Path: longest path in the activity network deciding project duration | RMMM: risk mitigation, monitoring and management plan
- **Q6(a):** Extreme Programming: practices such as pair programming and test-driven development
- **Q6(b):** Software Crisis: projects running late, over budget and unreliable | Software Process: framework of activities for building software | Software Characteristics: software is developed, not manufactured, and does not wear out
- **Q7(a):** Abstraction: hiding details to focus on essentials
- **Q7(b):** Cohesion: how closely the functions within one module belong together | Coupling: degree of interdependence between modules | Ideal Design: high functional cohesion with low data coupling
- **Q8(a):** Critical Path: longest path in the activity network deciding project duration
- **Q8(b):** SQA: planned activities ensuring software quality | ISO 9001: quality management standard applied to software | CMM: capability maturity model with five process maturity levels
