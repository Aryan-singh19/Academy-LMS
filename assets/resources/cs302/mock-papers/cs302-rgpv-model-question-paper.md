## Answer Hints (Set A)

- **Q1(a):** Power Set: set of all subsets of A; it has 2^n elements
- **Q1(b):** Reflexive Relation: every element is related to itself, (a, a) ∈ R | Symmetric Relation: (a, b) ∈ R implies (b, a) ∈ R | Transitive Relation: (a, b) and (b, c) in R imply (a, c) in R
- **Q2(a):** Cyclic Group: group generated by a single element
- **Q2(b):** Left Coset: aH = {ah : h ∈ H} for subgroup H | Lagrange's Theorem: the order of a subgroup divides the order of a finite group | Normal Subgroup: subgroup whose left and right cosets coincide
- **Q3(a):** Negation Rule: ¬∀x P(x) is equivalent to ∃x ¬P(x)
- **Q3(b):** Modus Ponens: from p and p → q conclude q | Modus Tollens: from ¬q and p → q conclude ¬p | Mathematical Induction: prove base case and P(k) ⇒ P(k+1) to prove P(n) for all n
- **Q4(a):** Tree Property: a tree with n vertices has exactly n − 1 edges
- **Q4(b):** Handshaking Lemma: sum of vertex degrees equals twice the number of edges | Adjacency Matrix: n × n matrix with 1 where an edge joins two vertices | Isomorphic Graphs: graphs with an edge-preserving bijection between vertex sets
- **Q5(a):** Hasse Diagram: drawing of a poset omitting loops and transitive edges
- **Q5(b):** Lattice: poset where every pair has a join and a meet | Distributive Lattice: lattice where meet distributes over join | Boolean Algebra: complemented distributive lattice
- **Q6(a):** Pigeonhole Principle: n + 1 objects in n boxes force some box to hold two
- **Q6(b):** Power Set: set of all subsets of A; it has 2^n elements | De Morgan's Law: complement of (A ∪ B) equals A' ∩ B' | Cartesian Product: A × B, the set of all ordered pairs (a, b)
- **Q7(a):** Proposition: declarative statement that is either true or false
- **Q7(b):** Tautology: formula true for every truth assignment | Contradiction: formula false for every truth assignment | CNF: conjunction of clauses, each a disjunction of literals
- **Q8(a):** Distributive Lattice: lattice where meet distributes over join
- **Q8(b):** Permutation: ordered arrangement, nPr = n!/(n − r)! | Combination: unordered selection, nCr = n!/(r!(n − r)!) | Inclusion-Exclusion: size of A ∪ B = size of A + size of B − size of A ∩ B
