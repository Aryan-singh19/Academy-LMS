- **Q.** Define *Transitive Relation*.

- **Q.** Define *Equivalence Relation*.

- **Q.** Define *Composition of Functions*.  
  **Ans.** (g ∘ f)(x) = g(f(x))
- **Q.** Define *Pigeonhole Principle*.  
  **Ans.** n + 1 objects in n boxes force some box to hold two

## Unit 2: Algebraic Structures

### Short answer (2-3 marks)

- **Q.** Define *Semigroup*.  
  **Ans.** set with an associative binary operation
- **Q.** Define *Monoid*.  
  **Ans.** semigroup with an identity element
- **Q.** Define *Group*.  
  **Ans.** monoid in which every element has an inverse
- **Q.** Define *Abelian Group*.  
  **Ans.** group whose operation is commutative
- **Q.** Define *Cyclic Group*.  
  **Ans.** group generated by a single element
- **Q.** Define *Subgroup*.  
  **Ans.** subset that is itself a group under the same operation
- **Q.** Define *Left Coset*.  
  **Ans.** aH = {ah : h ∈ H} for subgroup H
- **Q.** Define *Lagrange's Theorem*.  
  **Ans.** the order of a subgroup divides the order of a finite group
- **Q.** Define *Normal Subgroup*.  
  **Ans.** subgroup whose left and right cosets coincide
- **Q.** Define *Ring*.  
  **Ans.** abelian group under + with an associative × distributing over +
- **Q.** Define *Field*.  
  **Ans.** commutative ring where every non-zero element has a multiplicative inverse
- **Q.** Define *Homomorphism*.  
  **Ans.** structure-preserving map f(a * b) = f(a) * f(b)

### Long answer (7 marks)

- **Q.** Explain *Groups & Semigroups* in detail with a neat diagram.  
  **Key points:** Algebraic structures are sets with operations obeying axioms. Semigroup — set with an associative binary operation; Monoid — semigroup with an identity element; Group — monoid in which every element has an inverse.
- **Q.** Explain *Abelian, Cyclic Groups & Subgroups* in detail with a neat diagram.  
  **Key points:** Special groups have extra structure useful in coding and cryptography. Abelian Group — group whose operation is commutative; Cyclic Group — group generated by a single element; Subgroup — subset that is itself a group under the same operation.
- **Q.** Explain *Cosets & Lagrange's Theorem* in detail with a neat diagram.  
  **Key points:** Cosets partition a group and fix the possible orders of subgroups. Left Coset — aH = {ah : h ∈ H} for subgroup H; Lagrange's Theorem — the order of a subgroup divides the order of a finite group; Normal Subgroup — subgroup whose left and right cosets coincide.
- **Q.** Explain *Rings, Fields & Homomorphisms* in detail with a neat diagram.  
  **Key points:** Rings and fields carry two operations, the basis of modular arithmetic. Ring — abelian group under + with an associative × distributing over +; Field — commutative ring where every non-zero element has a multiplicative inverse; Homomorphism — structure-preserving map f(a * b) = f(a) * f(b).

## Unit 3: Propositional Logic & Proofs

### Short answer (2-3 marks)

- **Q.** Define *Proposition*.  
  **Ans.** declarative statement that is either true or false
- **Q.** Define *Conditional p → q*.  
  **Ans.** false only when p is true and q is false
- **Q.** Define *Biconditional p ↔ q*.  
  **Ans.** true when p and q have the same truth value
- **Q.** Define *Tautology*.  
  **Ans.** formula true for every truth assignment
- **Q.** Define *Contradiction*.  
  **Ans.** formula false for every truth assignment
- **Q.** Define *CNF*.  
  **Ans.** conjunction of clauses, each a disjunction of literals
- **Q.** Define *Universal Quantifier*.  
  **Ans.** ∀x P(x), P holds for every x in the domain
- **Q.** Define *Existential Quantifier*.  
  **Ans.** ∃x P(x), P holds for at least one x
- **Q.** Define *Negation Rule*.  
  **Ans.** ¬∀x P(x) is equivalent to ∃x ¬P(x)
- **Q.** Define *Modus Ponens*.  
  **Ans.** from p and p → q conclude q
- **Q.** Define *Modus Tollens*.  
  **Ans.** from ¬q and p → q conclude ¬p
- **Q.** Define *Mathematical Induction*.  
  **Ans.** prove base case and P(k) ⇒ P(k+1) to prove P(n) for all n

### Long answer (7 marks)

- **Q.** Explain *Propositions & Connectives* in detail with a neat diagram.  
  **Key points:** Logic formalises statements and how they combine. Proposition — declarative statement that is either true or false; Conditional p → q — false only when p is true and q is false; Biconditional p ↔ q — true when p and q have the same truth value.
- **Q.** Explain *Tautology, Contradiction & Normal Forms* in detail with a neat diagram.  
  **Key points:** Formulas are classified by truth tables and rewritten into standard forms. Tautology — formula true for every truth assignment; Contradiction — formula false for every truth assignment; CNF — conjunction of clauses, each a disjunction of literals.
- **Q.** Explain *Predicates & Quantifiers* in detail with a neat diagram.  
  **Key points:** Predicate logic adds variables and quantifiers. Universal Quantifier — ∀x P(x), P holds for every x in the domain; Existential Quantifier — ∃x P(x), P holds for at least one x; Negation Rule — ¬∀x P(x) is equivalent to ∃x ¬P(x).
- **Q.** Explain *Rules of Inference & Mathematical Induction* in detail with a neat diagram.  
  **Key points:** Valid arguments derive conclusions; induction proves statements for all n. Modus Ponens — from p and p → q conclude q; Modus Tollens — from ¬q and p → q conclude ¬p; Mathematical Induction — prove base case and P(k) ⇒ P(k+1) to prove P(n) for all n.

## Unit 4: Graph Theory & Trees

### Short answer (2-3 marks)

- **Q.** Define *Handshaking Lemma*.  
  **Ans.** sum of vertex degrees equals twice the number of edges
- **Q.** Define *Adjacency Matrix*.  
  **Ans.** n × n matrix with 1 where an edge joins two vertices
- **Q.** Define *Isomorphic Graphs*.  
  **Ans.** graphs with an edge-preserving bijection between vertex sets
- **Q.** Define *Euler Circuit*.  
  **Ans.** closed walk using every edge once; exists iff all degrees are even
- **Q.** Define *Hamiltonian Cycle*.  
  **Ans.** cycle visiting every vertex exactly once
- **Q.** Define *Konigsberg Problem*.  
  **Ans.** classic bridge puzzle proved impossible by Euler
- **Q.** Define *Euler's Formula*.  
  **Ans.** for a connected planar graph v − e + f = 2
- **Q.** Define *Chromatic Number*.  
  **Ans.** minimum colours to colour vertices with no adjacent pair alike
- **Q.** Define *Four Colour Theorem*.  
  **Ans.** every planar map can be coloured with four colours
- **Q.** Define *Tree Property*.  
  **Ans.** a tree with n vertices has exactly n − 1 edges
- **Q.** Define *Spanning Tree*.  
  **Ans.** subgraph that is a tree containing all vertices
- **Q.** Define *Kruskal's Algorithm*.  
  **Ans.** builds a minimum spanning tree by adding cheapest safe edges

### Long answer (7 marks)

- **Q.** Explain *Graph Terminology & Representation* in detail with a neat diagram.  
  **Key points:** Graphs model networks of vertices and edges. Handshaking Lemma — sum of vertex degrees equals twice the number of edges; Adjacency Matrix — n × n matrix with 1 where an edge joins two vertices; Isomorphic Graphs — graphs with an edge-preserving bijection between vertex sets.
- **Q.** Explain *Euler & Hamiltonian Paths* in detail with a neat diagram.  
  **Key points:** Special walks cover every edge or every vertex exactly once. Euler Circuit — closed walk using every edge once; exists iff all degrees are even; Hamiltonian Cycle — cycle visiting every vertex exactly once; Konigsberg Problem — classic bridge puzzle proved impossible by Euler.
- **Q.** Explain *Planar Graphs & Graph Colouring* in detail with a neat diagram.  
  **Key points:** Planarity and colouring model layout and scheduling problems. Euler's Formula — for a connected planar graph v − e + f = 2; Chromatic Number — minimum colours to colour vertices with no adjacent pair alike; Four Colour Theorem — every planar map can be coloured with four colours.
- **Q.** Explain *Trees & Spanning Trees* in detail with a neat diagram.  
  **Key points:** Trees are connected acyclic graphs used in search and networks. Tree Property — a tree with n vertices has exactly n − 1 edges; Spanning Tree — subgraph that is a tree containing all vertices; Kruskal's Algorithm — builds a minimum spanning tree by adding cheapest safe edges.

## Unit 5: Posets, Lattices & Combinatorics

### Short answer (2-3 marks)

- **Q.** Define *Partial Order*.  
  **Ans.** reflexive, antisymmetric and transitive relation
- **Q.** Define *Hasse Diagram*.  
  **Ans.** drawing of a poset omitting loops and transitive edges
- **Q.** Define *Total Order*.  
  **Ans.** partial order where every pair of elements is comparable
- **Q.** Define *Lattice*.  
  **Ans.** poset where every pair has a join and a meet
- **Q.** Define *Distributive Lattice*.  
  **Ans.** lattice where meet distributes over join
- **Q.** Define *Boolean Algebra*.  
  **Ans.** complemented distributive lattice
- **Q.** Define *Permutation*.  
  **Ans.** ordered arrangement, nPr = n!/(n − r)!
- **Q.** Define *Combination*.  
  **Ans.** unordered selection, nCr = n!/(r!(n − r)!)
- **Q.** Define *Inclusion-Exclusion*.  
  **Ans.** size of A ∪ B = size of A + size of B − size of A ∩ B
- **Q.** Define *Recurrence Relation*.  
  **Ans.** equation expressing a(n) in terms of earlier terms
- **Q.** Define *Characteristic Equation*.  
  **Ans.** polynomial whose roots give the homogeneous solution
- **Q.** Define *Generating Function*.  
  **Ans.** power series Σ a(n) x^n encoding a sequence

### Long answer (7 marks)

- **Q.** Explain *Partial Order & Hasse Diagrams* in detail with a neat diagram.  
  **Key points:** Posets capture ordering where not every pair is comparable. Partial Order — reflexive, antisymmetric and transitive relation; Hasse Diagram — drawing of a poset omitting loops and transitive edges; Total Order — partial order where every pair of elements is comparable.
- **Q.** Explain *Lattices & Boolean Algebra* in detail with a neat diagram.  
  **Key points:** Lattices have a least upper bound and greatest lower bound for every pair. Lattice — poset where every pair has a join and a meet; Distributive Lattice — lattice where meet distributes over join; Boolean Algebra — complemented distributive lattice.
- **Q.** Explain *Permutations & Combinations* in detail with a neat diagram.  
  **Key points:** Counting principles count arrangements and selections. Permutation — ordered arrangement, nPr = n!/(n − r)!; Combination — unordered selection, nCr = n!/(r!(n − r)!); Inclusion-Exclusion — size of A ∪ B = size of A + size of B − size of A ∩ B.
- **Q.** Explain *Recurrence Relations & Generating Functions* in detail with a neat diagram.  
  **Key points:** Recurrences define sequences from earlier terms. Recurrence Relation — equation expressing a(n) in terms of earlier terms; Characteristic Equation — polynomial whose roots give the homogeneous solution; Generating Function — power series Σ a(n) x^n encoding a sequence.
