- **Q.** Define *Incremental Encoder*.  
  **Ans.** pulses for relative motion
- **Q.** Define *Absolute Encoder*.  
  **Ans.** unique code for each position
- **Q.** Define *Inductive Proximity Sensor*.  
  **Ans.** detects metal objects
- **Q.** Define *Hall Effect Sensor*.  
  **Ans.** senses magnetic field
- **Q.** Define *Tachogenerator*.

- **Q.** Define *Piezoelectric Sensor*.  
  **Ans.** charge produced by force
- **Q.** Define *Strain Gauge Load Cell*.  
  **Ans.** measures force
- **Q.** Define *Thermocouple*.  
  **Ans.** temperature sensor based on Seebeck effect
- **Q.** Define *Range*.  
  **Ans.** limits of measurable input
- **Q.** Define *Response Time*.  
  **Ans.** time to reach a stated output
- **Q.** Define *Repeatability*.  
  **Ans.** consistency of output for same input

### Long answer (7 marks)

- **Q.** Explain *Displacement & Position Sensors* in detail with a neat diagram.  
  **Key points:** Position is sensed in many ways. Optical Encoder — disk with slots giving digital position; Incremental Encoder — pulses for relative motion; Absolute Encoder — unique code for each position.
- **Q.** Explain *Proximity & Velocity Sensors* in detail with a neat diagram.  
  **Key points:** Non-contact sensing of presence and speed. Inductive Proximity Sensor — detects metal objects; Hall Effect Sensor — senses magnetic field; Tachogenerator — voltage proportional to speed.
- **Q.** Explain *Force, Pressure & Temperature Sensors* in detail with a neat diagram.  
  **Key points:** Common physical quantities are sensed. Piezoelectric Sensor — charge produced by force; Strain Gauge Load Cell — measures force; Thermocouple — temperature sensor based on Seebeck effect.
- **Q.** Explain *Selection of Sensors* in detail with a neat diagram.  
  **Key points:** Sensors are chosen by specifications. Range — limits of measurable input; Response Time — time to reach a stated output; Repeatability — consistency of output for same input.

- **Q.** Define *Differential Amplifier*.  
  **Ans.** amplifies difference of two inputs
- **Q.** Define *Instrumentation Amplifier*.  
  **Ans.** high CMRR for small signals
- **Q.** Define *Low-pass Filter*.  
  **Ans.** removes high-frequency noise
- **Q.** Define *Optical Isolation*.  
  **Ans.** optocoupler separates circuits
- **Q.** Define *Wheatstone Bridge*.  
  **Ans.** converts resistance change to voltage
- **Q.** Define *ADC*.  
  **Ans.** converts analog signal into digital value
- **Q.** Define *Resolution*.  
  **Ans.** smallest change detectable, Vref/2^n
- **Q.** Define *DAC*.  
  **Ans.** converts digital value into analog signal
- **Q.** Define *DAQ*.  
  **Ans.** hardware and software acquiring signals
- **Q.** Define *Sampling Rate*.  
  **Ans.** samples per second
- **Q.** Define *Multiplexer*.  
  **Ans.** selects one of several channels

### Long answer (7 marks)

- **Q.** Explain *Operational Amplifier Circuits* in detail with a neat diagram.  
  **Key points:** Op-amps condition sensor signals. Inverting Amplifier — gain −Rf/Rin; Differential Amplifier — amplifies difference of two inputs; Instrumentation Amplifier — high CMRR for small signals.
- **Q.** Explain *Filtering & Protection* in detail with a neat diagram.  
  **Key points:** Filters remove noise; protection prevents damage. Low-pass Filter — removes high-frequency noise; Optical Isolation — optocoupler separates circuits; Wheatstone Bridge — converts resistance change to voltage.
- **Q.** Explain *ADC & DAC* in detail with a neat diagram.  
  **Key points:** Converters link analog and digital domains. ADC — converts analog signal into digital value; Resolution — smallest change detectable, Vref/2^n; DAC — converts digital value into analog signal.
- **Q.** Explain *Data Acquisition Systems* in detail with a neat diagram.  
  **Key points:** DAQ systems gather data for computers. DAQ — hardware and software acquiring signals; Sampling Rate — samples per second; Multiplexer — selects one of several channels.
