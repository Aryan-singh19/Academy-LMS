  **Ans.** triangular weld at corner
- **Q.** Define *Butt Weld*.

- **Q.** Define *Effective Throat*.  
  **Ans.** 0.7 × size of fillet weld

## Unit 2: Tension & Compression Members

### Short answer (2-3 marks)

- **Q.** Define *Gross Section Yielding*.  
  **Ans.** Tdg = Ag fy / γm0
- **Q.** Define *Net Section Rupture*.  
  **Ans.** Tdn = 0.9 An fu / γm1
- **Q.** Define *Block Shear*.  
  **Ans.** tearing along shear and tension planes
- **Q.** Define *Slenderness Ratio*.  
  **Ans.** KL/r
- **Q.** Define *Buckling Class*.  
  **Ans.** a, b, c, d based on section
- **Q.** Define *Design Compressive Stress*.  
  **Ans.** from IS 800 buckling curves
- **Q.** Define *Lacing*.  
  **Ans.** diagonal bars connecting components
- **Q.** Define *Battening*.  
  **Ans.** plates connecting components
- **Q.** Define *Built-up Column*.  
  **Ans.** two or more sections combined
- **Q.** Define *Slab Base*.  
  **Ans.** thick plate under column
- **Q.** Define *Gusseted Base*.  
  **Ans.** with gusset plates
- **Q.** Define *Base Plate Thickness*.  
  **Ans.** from bearing pressure

### Long answer (7 marks)

- **Q.** Explain *Tension Members* in detail with a neat diagram.  
  **Key points:** Tension members are checked for three modes. Gross Section Yielding — Tdg = Ag fy / γm0; Net Section Rupture — Tdn = 0.9 An fu / γm1; Block Shear — tearing along shear and tension planes.
- **Q.** Explain *Compression Members* in detail with a neat diagram.  
  **Key points:** Struts and columns buckle. Slenderness Ratio — KL/r; Buckling Class — a, b, c, d based on section; Design Compressive Stress — from IS 800 buckling curves.
- **Q.** Explain *Built-up Columns* in detail with a neat diagram.  
  **Key points:** Laced and battened columns. Lacing — diagonal bars connecting components; Battening — plates connecting components; Built-up Column — two or more sections combined.
- **Q.** Explain *Column Bases* in detail with a neat diagram.  
  **Key points:** Bases transfer load to foundation. Slab Base — thick plate under column; Gusseted Base — with gusset plates; Base Plate Thickness — from bearing pressure.

## Unit 3: Flexural Members

### Short answer (2-3 marks)

- **Q.** Define *Plastic Section*.  
  **Ans.** develops full plastic moment
- **Q.** Define *Design Bending Strength*.  
  **Ans.** Md = βb Zp fy / γm0
- **Q.** Define *Shear Strength*.  
  **Ans.** Vd = Av fy/(√3 γm0)
- **Q.** Define *Lateral Torsional Buckling*.  
  **Ans.** twisting and lateral bending
- **Q.** Define *Effective Length*.  
  **Ans.** depends on restraint
- **Q.** Define *Elastic Critical Moment*.  
  **Ans.** Mcr for LTB
- **Q.** Define *Web Buckling*.  
  **Ans.** compression failure of web
- **Q.** Define *Web Crippling*.  
  **Ans.** local yielding under load
- **Q.** Define *Bearing Stiffener*.  
  **Ans.** prevents web failure
- **Q.** Define *Purlin*.  
  **Ans.** beam spanning between trusses
- **Q.** Define *Angle Purlin*.  
  **Ans.** simple design for light roofs
- **Q.** Define *Channel Purlin*.  
  **Ans.** heavier roofs

### Long answer (7 marks)

- **Q.** Explain *Laterally Supported Beams* in detail with a neat diagram.  
  **Key points:** Beams with restrained compression flange. Plastic Section — develops full plastic moment; Design Bending Strength — Md = βb Zp fy / γm0; Shear Strength — Vd = Av fy/(√3 γm0).
- **Q.** Explain *Laterally Unsupported Beams* in detail with a neat diagram.

- **Q.** Explain *Web Buckling & Crippling* in detail with a neat diagram.

  **Key points:** Purlins support roof sheeting. Purlin — beam spanning between trusses; Angle Purlin — simple design for light roofs; Channel Purlin — heavier roofs.
