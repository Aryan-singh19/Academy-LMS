# BT-104 Basic Electrical & Electronics Engineering — Question Bank with Answer Hints

## Unit 1: DC Circuits

### Short answer (2-3 marks)

- **Q.** Define *Ohm's Law*.  
  **Ans.** V = IR
- **Q.** Define *Resistivity*.  
  **Ans.** R = ρL/A
- **Q.** Define *Power*.  
  **Ans.** P = VI = I²R
- **Q.** Define *KCL*.  
  **Ans.** sum of currents at a node is zero
- **Q.** Define *KVL*.  
  **Ans.** sum of voltages around a loop is zero
- **Q.** Define *Voltage Divider*.  
  **Ans.** Vout = Vin·R2/(R1 + R2)
- **Q.** Define *Thevenin's Theorem*.  
  **Ans.** equivalent voltage source with series resistance
- **Q.** Define *Norton's Theorem*.  
  **Ans.** equivalent current source with parallel resistance
- **Q.** Define *Superposition*.  
  **Ans.** response is sum of individual source responses
- **Q.** Define *Delta to Star*.  
  **Ans.** RA = R1R2/(R1 + R2 + R3)
- **Q.** Define *Star to Delta*.  
  **Ans.** R12 = R1 + R2 + R1R2/R3
- **Q.** Define *Application*.  
  **Ans.** simplifying bridge networks

### Long answer (7 marks)

- **Q.** Explain *Circuit Elements & Ohm's Law* in detail with a neat diagram.  
  **Key points:** Basic laws describe electric circuits. Ohm's Law — V = IR; Resistivity — R = ρL/A; Power — P = VI = I²R.
- **Q.** Explain *Kirchhoff's Laws* in detail with a neat diagram.  
  **Key points:** KCL and KVL analyse networks. KCL — sum of currents at a node is zero; KVL — sum of voltages around a loop is zero; Voltage Divider — Vout = Vin·R2/(R1 + R2).
- **Q.** Explain *Network Theorems* in detail with a neat diagram.  
  **Key points:** Theorems simplify circuits. Thevenin's Theorem — equivalent voltage source with series resistance; Norton's Theorem — equivalent current source with parallel resistance; Superposition — response is sum of individual source responses.
- **Q.** Explain *Star-Delta Transformation* in detail with a neat diagram.  
  **Key points:** Networks are converted for analysis. Delta to Star — RA = R1R2/(R1 + R2 + R3); Star to Delta — R12 = R1 + R2 + R1R2/R3; Application — simplifying bridge networks.

## Unit 2: AC Circuits

### Short answer (2-3 marks)

- **Q.** Define *RMS Value*.  
  **Ans.** Vm/√2 for a sine wave
- **Q.** Define *Average Value*.  
  **Ans.** 2Vm/π for a half cycle
- **Q.** Define *Form Factor*.  
  **Ans.** RMS / average = 1.11
- **Q.** Define *Impedance*.  
  **Ans.** Z = R + jX
- **Q.** Define *Power Factor*.  
  **Ans.** cos φ, ratio of real to apparent power
- **Q.** Define *Inductive Reactance*.  
  **Ans.** XL = 2πfL
- **Q.** Define *Resonant Frequency*.  
  **Ans.** f0 = 1/(2π√(LC))
- **Q.** Define *Quality Factor*.  
  **Ans.** Q = ω0L/R
- **Q.** Define *Series Resonance*.  
  **Ans.** impedance minimum, current maximum
- **Q.** Define *Star Connection*.  
  **Ans.** VL = √3 Vph, IL = Iph
- **Q.** Define *Delta Connection*.  
  **Ans.** VL = Vph, IL = √3 Iph
- **Q.** Define *Three-phase Power*.  
  **Ans.** P = √3 VL IL cos φ

### Long answer (7 marks)

- **Q.** Explain *AC Fundamentals* in detail with a neat diagram.  
  **Key points:** Alternating quantities vary sinusoidally. RMS Value — Vm/√2 for a sine wave; Average Value — 2Vm/π for a half cycle; Form Factor — RMS / average = 1.11.
- **Q.** Explain *Phasors & Single-phase Circuits* in detail with a neat diagram.  
  **Key points:** Phasors represent sinusoids. Impedance — Z = R + jX; Power Factor — cos φ, ratio of real to apparent power; Inductive Reactance — XL = 2πfL.
- **Q.** Explain *Resonance* in detail with a neat diagram.  
  **Key points:** Series RLC resonates when XL = XC. Resonant Frequency — f0 = 1/(2π√(LC)); Quality Factor — Q = ω0L/R; Series Resonance — impedance minimum, current maximum.
- **Q.** Explain *Three-phase Systems* in detail with a neat diagram.  
  **Key points:** Three-phase supply powers industry. Star Connection — VL = √3 Vph, IL = Iph; Delta Connection — VL = Vph, IL = √3 Iph; Three-phase Power — P = √3 VL IL cos φ.

## Unit 3: Magnetic Circuits & Transformers

### Short answer (2-3 marks)

- **Q.** Define *MMF*.  
  **Ans.** magnetomotive force NI
- **Q.** Define *Reluctance*.  
  **Ans.** S = l/(μA)
- **Q.** Define *Flux*.  
  **Ans.** Φ = MMF / reluctance
- **Q.** Define *Faraday's Law*.  
  **Ans.** e = −N dΦ/dt
- **Q.** Define *Lenz's Law*.  
  **Ans.** induced current opposes the change
- **Q.** Define *Self Inductance*.  
  **Ans.** L = NΦ/I
- **Q.** Define *EMF Equation*.  
  **Ans.** E = 4.44 f N Φm
- **Q.** Define *Turns Ratio*.  
  **Ans.** V1/V2 = N1/N2
- **Q.** Define *Ideal Transformer*.  
  **Ans.** no losses
- **Q.** Define *Core Loss*.  
  **Ans.** hysteresis and eddy current loss
- **Q.** Define *Copper Loss*.  
  **Ans.** I²R loss in windings
- **Q.** Define *Maximum Efficiency*.  
  **Ans.** when copper loss equals core loss

### Long answer (7 marks)

- **Q.** Explain *Magnetic Circuits* in detail with a neat diagram.  
  **Key points:** Magnetic circuits are analogous to electric circuits. MMF — magnetomotive force NI; Reluctance — S = l/(μA); Flux — Φ = MMF / reluctance.
- **Q.** Explain *Electromagnetic Induction* in detail with a neat diagram.  
  **Key points:** Changing flux induces emf. Faraday's Law — e = −N dΦ/dt; Lenz's Law — induced current opposes the change; Self Inductance — L = NΦ/I.
- **Q.** Explain *Single-phase Transformer* in detail with a neat diagram.  
  **Key points:** Transformers change AC voltage levels. EMF Equation — E = 4.44 f N Φm; Turns Ratio — V1/V2 = N1/N2; Ideal Transformer — no losses.
- **Q.** Explain *Transformer Losses & Efficiency* in detail with a neat diagram.  
  **Key points:** Losses reduce efficiency. Core Loss — hysteresis and eddy current loss; Copper Loss — I²R loss in windings; Maximum Efficiency — when copper loss equals core loss.

## Unit 4: Electrical Machines

### Short answer (2-3 marks)

- **Q.** Define *DC Generator EMF*.  
  **Ans.** E = PΦZN/(60A)
- **Q.** Define *Back EMF*.  
  **Ans.** Eb = V − IaRa in a motor
- **Q.** Define *DC Series Motor*.  
  **Ans.** high starting torque
- **Q.** Define *Synchronous Speed*.  
  **Ans.** Ns = 120f/P
- **Q.** Define *Slip*.  
  **Ans.** (Ns − N)/Ns
- **Q.** Define *Rotating Magnetic Field*.  
  **Ans.** produced by three-phase stator currents
- **Q.** Define *Split-phase Motor*.  
  **Ans.** auxiliary winding for starting
- **Q.** Define *Capacitor Start Motor*.  
  **Ans.** capacitor gives starting torque
- **Q.** Define *Universal Motor*.  
  **Ans.** runs on AC and DC
- **Q.** Define *Alternator*.  
  **Ans.** synchronous generator
- **Q.** Define *Synchronous Motor*.  
  **Ans.** runs at constant synchronous speed
- **Q.** Define *Not Self-starting*.  
  **Ans.** synchronous motors need starting methods

### Long answer (7 marks)

- **Q.** Explain *DC Machines* in detail with a neat diagram.  
  **Key points:** DC machines convert energy with commutators. DC Generator EMF — E = PΦZN/(60A); Back EMF — Eb = V − IaRa in a motor; DC Series Motor — high starting torque.
- **Q.** Explain *Three-phase Induction Motor* in detail with a neat diagram.  
  **Key points:** Most common industrial motor. Synchronous Speed — Ns = 120f/P; Slip — (Ns − N)/Ns; Rotating Magnetic Field — produced by three-phase stator currents.
- **Q.** Explain *Single-phase Motors* in detail with a neat diagram.  
  **Key points:** Small appliances use single-phase motors. Split-phase Motor — auxiliary winding for starting; Capacitor Start Motor — capacitor gives starting torque; Universal Motor — runs on AC and DC.
- **Q.** Explain *Synchronous Machines* in detail with a neat diagram.  
  **Key points:** Alternators generate power at constant speed. Alternator — synchronous generator; Synchronous Motor — runs at constant synchronous speed; Not Self-starting — synchronous motors need starting methods.

## Unit 5: Basic Electronics

### Short answer (2-3 marks)

- **Q.** Define *PN Junction*.  
  **Ans.** junction of p- and n-type semiconductor
- **Q.** Define *Forward Bias*.  
  **Ans.** p connected to positive; diode conducts
- **Q.** Define *Zener Diode*.  
  **Ans.** regulates voltage in reverse breakdown
- **Q.** Define *Half-wave Rectifier*.  
  **Ans.** uses one diode
- **Q.** Define *Bridge Rectifier*.  
  **Ans.** four diodes, full-wave output
- **Q.** Define *Ripple Factor*.  
  **Ans.** AC content in rectified output
- **Q.** Define *BJT*.  
  **Ans.** bipolar junction transistor
- **Q.** Define *CE Configuration*.  
  **Ans.** common emitter amplifier
- **Q.** Define *Transistor as Switch*.  
  **Ans.** operates in cut-off and saturation
- **Q.** Define *Logic Gate*.  
  **Ans.** performs Boolean operation
- **Q.** Define *Universal Gate*.  
  **Ans.** NAND or NOR
- **Q.** Define *Number Systems*.  
  **Ans.** binary, octal, decimal and hexadecimal

### Long answer (7 marks)

- **Q.** Explain *Semiconductor Diode* in detail with a neat diagram.  
  **Key points:** Diodes conduct in one direction. PN Junction — junction of p- and n-type semiconductor; Forward Bias — p connected to positive; diode conducts; Zener Diode — regulates voltage in reverse breakdown.
- **Q.** Explain *Rectifiers* in detail with a neat diagram.  
  **Key points:** Rectifiers convert AC to DC. Half-wave Rectifier — uses one diode; Bridge Rectifier — four diodes, full-wave output; Ripple Factor — AC content in rectified output.
- **Q.** Explain *Transistors* in detail with a neat diagram.  
  **Key points:** Transistors amplify and switch. BJT — bipolar junction transistor; CE Configuration — common emitter amplifier; Transistor as Switch — operates in cut-off and saturation.
- **Q.** Explain *Digital Electronics Basics* in detail with a neat diagram.  
  **Key points:** Logic gates process binary signals. Logic Gate — performs Boolean operation; Universal Gate — NAND or NOR; Number Systems — binary, octal, decimal and hexadecimal.
