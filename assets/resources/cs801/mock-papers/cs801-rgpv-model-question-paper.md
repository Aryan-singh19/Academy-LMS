## Answer Hints (Set A)

- **Q1(a):** Internet of Things: network of physical objects with sensors, software and connectivity
- **Q1(b):** Three-layer Architecture: perception, network and application layers | Physical Design of IoT: the things, their interfaces and protocols | Logical Design of IoT: functional blocks and communication models
- **Q2(a):** Servo Motor: motor with feedback for precise angular position
- **Q2(b):** Arduino: open-source microcontroller board based on ATmega chips | Raspberry Pi: single-board Linux computer for gateways and edge tasks | ESP32: low-cost microcontroller with built-in Wi-Fi and Bluetooth
- **Q3(a):** AMQP: message-queue protocol with reliable delivery and routing
- **Q3(b):** 6LoWPAN: IPv6 over low-power wireless personal area networks | IPv6 Address Space: 128-bit addresses, enough for billions of devices | RPL: routing protocol for low-power and lossy networks
- **Q4(a):** SDN: separates control plane from data plane
- **Q4(b):** Cloud Computing for IoT: remote storage and analytics for device data | Edge Computing: processing data near its source to cut latency | Fog Computing: intermediate layer between edge devices and cloud
- **Q5(a):** Device Authentication: verifying a device's identity before granting access
- **Q5(b):** Data Minimisation: collect only data needed for the purpose | Lightweight Cryptography: ciphers designed for constrained devices | End-to-end Encryption: data encrypted from device to final application
- **Q6(a):** Push-Pull Model: producers push to queues, consumers pull from them
- **Q6(b):** Internet of Things: network of physical objects with sensors, software and connectivity | Interoperability: ability of heterogeneous devices to work together | Self-configuring: devices discover and configure themselves with minimal human input
- **Q7(a):** Zigbee: low-power mesh networking on IEEE 802.15.4
- **Q7(b):** MQTT: publish-subscribe protocol over TCP using a broker | QoS Levels: MQTT offers 0 at most once, 1 at least once, 2 exactly once | Topic: hierarchical string to which messages are published
- **Q8(a):** Lightweight Cryptography: ciphers designed for constrained devices
- **Q8(b):** Smart Home: automated lighting, security and appliances controlled remotely | Smart City: IoT for traffic, waste, parking and utility management | Smart Grid: electricity network with sensing and two-way communication
