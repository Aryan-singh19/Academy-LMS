## Answer Hints (Set A)

- **Q1(a):** CPU: central processing unit with ALU and control unit
- **Q1(b):** Binary: base 2 | Hexadecimal: base 16 | Bit and Byte: 8 bits make one byte
- **Q2(a):** Time-sharing OS: CPU time shared among users
- **Q2(b):** File System: method of storing and organising files | Directory: container of files | Linux Commands: ls, cd, mkdir, cp
- **Q3(a):** Call by Reference: function modifies caller's variable
- **Q3(b):** Class: blueprint for objects | Inheritance: deriving new class from existing | Polymorphism: same interface, different behaviour
- **Q4(a):** Malware: malicious software such as viruses
- **Q4(b):** LAN: local area network | WAN: wide area network | Topology: arrangement such as star, bus, ring
- **Q5(a):** Table: rows and columns of data
- **Q5(b):** Cloud Computing: on-demand resources over network | SaaS: software as a service | Virtualisation: running multiple OS on one machine
- **Q6(a):** Compiler vs Interpreter: whole program translation versus line-by-line
- **Q6(b):** CPU: central processing unit with ALU and control unit | Primary Memory: RAM and ROM directly accessed by CPU | Secondary Storage: HDD, SSD for permanent storage
- **Q7(a):** Variable: named storage location
- **Q7(b):** if-else: conditional branching | for Loop: repeats a known number of times | switch: multi-way branching
- **Q8(a):** SaaS: software as a service
- **Q8(b):** IoT: network of connected devices | Artificial Intelligence: machines performing intelligent tasks | Machine Learning: learning from data
