# BT-205 Basic Computer Engineering — Unit-wise Study Notes

> Computer fundamentals, operating systems, C++ programming basics, networking, databases and emerging technologies.

## Unit 1: Computer Fundamentals

### Computer Organisation

A computer has input, processing, memory and output units.

- **CPU:** central processing unit with ALU and control unit
- **Primary Memory:** RAM and ROM directly accessed by CPU
- **Secondary Storage:** HDD, SSD for permanent storage

### Number Systems

Computers use binary representation.

- **Binary:** base 2
- **Hexadecimal:** base 16
- **Bit and Byte:** 8 bits make one byte

### Generations & Types of Computers

Computers evolved through generations.

- **First Generation:** vacuum tubes
- **Fourth Generation:** microprocessors
- **Supercomputer:** highest performance computer

### Software Types

Software is system or application software.

- **System Software:** operating system, compilers
- **Application Software:** programs for user tasks
- **Compiler vs Interpreter:** whole program translation versus line-by-line

## Unit 2: Operating Systems

### OS Functions

OS manages hardware and resources.

- **Operating System:** interface between user and hardware
- **Process Management:** scheduling and executing programs
- **Memory Management:** allocating memory to processes

### Types of OS

OS designs serve different needs.

- **Batch OS:** jobs processed in batches
- **Time-sharing OS:** CPU time shared among users
- **Real-time OS:** strict timing constraints

### File Systems & Commands

OS organises files in directories.

- **File System:** method of storing and organising files
- **Directory:** container of files
- **Linux Commands:** ls, cd, mkdir, cp

### Windows & Linux

Popular operating systems.

- **Windows:** GUI-based OS by Microsoft
- **Linux:** open-source Unix-like OS
- **Shell:** command-line interpreter

## Unit 3: Programming in C++

### Basics of C++

C++ supports procedural and object-oriented programming.

- **Variable:** named storage location
- **Data Types:** int, float, char, bool
- **cin and cout:** standard input and output

### Control Structures

Control flow directs program execution.

- **if-else:** conditional branching
- **for Loop:** repeats a known number of times
- **switch:** multi-way branching

### Functions & Arrays

Functions modularise code; arrays store lists.

- **Function:** reusable block of code
- **Array:** collection of same-type elements
- **Call by Reference:** function modifies caller's variable

### OOP Concepts

C++ supports classes and objects.

- **Class:** blueprint for objects
- **Inheritance:** deriving new class from existing
- **Polymorphism:** same interface, different behaviour

## Unit 4: Networking & Internet

### Computer Networks

Networks connect computers to share resources.

- **LAN:** local area network
- **WAN:** wide area network
- **Topology:** arrangement such as star, bus, ring

### Internet & Protocols

Internet uses standard protocols.

- **TCP/IP:** protocol suite of the Internet
- **IP Address:** unique address of a device
- **HTTP:** protocol for web pages

### Network Devices

Devices route and connect traffic.

- **Router:** forwards packets between networks
- **Switch:** connects devices within a LAN
- **Modem:** modulates and demodulates signals

### Cyber Security Basics

Protecting systems from threats.

- **Malware:** malicious software such as viruses
- **Firewall:** filters network traffic
- **Encryption:** encoding data for confidentiality

## Unit 5: Databases & Emerging Technologies

### Database Basics

Databases store structured data.

- **DBMS:** software managing databases
- **Table:** rows and columns of data
- **SQL:** language to query databases

### Cloud Computing

Computing delivered over the Internet.

- **Cloud Computing:** on-demand resources over network
- **SaaS:** software as a service
- **Virtualisation:** running multiple OS on one machine

### IoT & AI

New technologies connect devices and add intelligence.

- **IoT:** network of connected devices
- **Artificial Intelligence:** machines performing intelligent tasks
- **Machine Learning:** learning from data

### Big Data & Blockchain

Data scale and distributed ledgers.

- **Big Data:** very large and complex datasets
- **Blockchain:** distributed tamper-proof ledger
- **Data Analytics:** examining data to draw conclusions
