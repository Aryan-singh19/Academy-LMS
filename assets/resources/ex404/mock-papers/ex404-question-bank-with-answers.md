## Unit 3: Transmission Line Performance

### Short answer (2-3 marks)

- **Q.** Define *Short Line*.  
  **Ans.** series impedance only
- **Q.** Define *Regulation*.  
  **Ans.** (VS − VR)/VR
- **Q.** Define *Efficiency*.  
  **Ans.** output power / input power
- **Q.** Define *Nominal T Method*.  
  **Ans.** capacitance at midpoint
- **Q.** Define *Nominal π Method*.  
  **Ans.** capacitance split at ends
- **Q.** Define *ABCD Constants*.  
  **Ans.** relate sending and receiving quantities
- **Q.** Define *Propagation Constant*.  
  **Ans.** γ = √(zy)
- **Q.** Define *Surge Impedance*.  
  **Ans.** Zc = √(z/y)
- **Q.** Define *SIL*.  
  **Ans.** surge impedance loading V²/Zc
- **Q.** Define *Ferranti Effect*.  
  **Ans.** receiving voltage exceeds sending at no load
- **Q.** Define *Shunt Reactor*.  
  **Ans.** compensates line charging
- **Q.** Define *Series Capacitor*.  
  **Ans.** reduces line reactance

### Long answer (7 marks)

- **Q.** Explain *Short Transmission Lines* in detail with a neat diagram.  
  **Key points:** Lines up to 80 km neglect capacitance. Short Line — series impedance only; Regulation — (VS − VR)/VR; Efficiency — output power / input power.
- **Q.** Explain *Medium Transmission Lines* in detail with a neat diagram.  
  **Key points:** Lines 80-250 km use lumped capacitance. Nominal T Method — capacitance at midpoint; Nominal π Method — capacitance split at ends; ABCD Constants — relate sending and receiving quantities.
- **Q.** Explain *Long Transmission Lines* in detail with a neat diagram.  
  **Key points:** Distributed parameters needed. Propagation Constant — γ = √(zy); Surge Impedance — Zc = √(z/y); SIL — surge impedance loading V²/Zc.
- **Q.** Explain *Ferranti Effect & Compensation* in detail with a neat diagram.  
  **Key points:** Light loads raise receiving voltage. Ferranti Effect — receiving voltage exceeds sending at no load; Shunt Reactor — compensates line charging; Series Capacitor — reduces line reactance.
