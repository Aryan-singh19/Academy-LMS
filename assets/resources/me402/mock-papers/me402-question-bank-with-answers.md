## Unit 2: Displacement, Force & Torque Measurement

### Short answer (2-3 marks)

- **Q.** Define *LVDT*.  
  **Ans.** transformer with movable core for linear displacement
- **Q.** Define *Potentiometer*.  
  **Ans.** sliding contact giving resistance proportional to position
- **Q.** Define *Capacitive Transducer*.  
  **Ans.** capacitance changes with gap or area
- **Q.** Define *Strain Gauge*.  
  **Ans.** resistance changes with strain
- **Q.** Define *Wheatstone Bridge Circuit*.  
  **Ans.** converts resistance change to voltage
- **Q.** Define *Gauge Factor*.  
  **Ans.** (ΔR/R)/ε, about 2 for metal gauges
- **Q.** Define *Load Cell*.  
  **Ans.** elastic element with strain gauges
- **Q.** Define *Proving Ring*.  
  **Ans.** elastic ring used to calibrate force
- **Q.** Define *Hydraulic Load Cell*.  
  **Ans.** force measured by fluid pressure
- **Q.** Define *Dynamometer*.  
  **Ans.** device measuring torque and power
- **Q.** Define *Stroboscope*.  
  **Ans.** measures speed by apparently freezing motion
- **Q.** Define *Tachogenerator*.  
  **Ans.** generator producing voltage proportional to speed

### Long answer (7 marks)

- **Q.** Explain *Displacement Measurement* in detail with a neat diagram.  
  **Key points:** Displacement transducers convert motion to signal. LVDT — transformer with movable core for linear displacement; Potentiometer — sliding contact giving resistance proportional to position; Capacitive Transducer — capacitance changes with gap or area.
- **Q.** Explain *Strain Measurement* in detail with a neat diagram.  
  **Key points:** Strain gauges measure surface strain. Strain Gauge — resistance changes with strain; Wheatstone Bridge Circuit — converts resistance change to voltage; Gauge Factor — (ΔR/R)/ε, about 2 for metal gauges.
- **Q.** Explain *Force Measurement* in detail with a neat diagram.  
  **Key points:** Load cells measure force. Load Cell — elastic element with strain gauges; Proving Ring — elastic ring used to calibrate force; Hydraulic Load Cell — force measured by fluid pressure.
- **Q.** Explain *Torque & Speed Measurement* in detail with a neat diagram.  
  **Key points:** Shaft output is measured with dynamometers and tachometers. Dynamometer — device measuring torque and power; Stroboscope — measures speed by apparently freezing motion; Tachogenerator — generator producing voltage proportional to speed.

## Unit 3: Pressure & Flow Measurement

### Short answer (2-3 marks)

- **Q.** Define *Manometer*.  
  **Ans.** liquid column measuring pressure difference
- **Q.** Define *Bourdon Tube*.  
  **Ans.** curved tube that straightens with pressure
- **Q.** Define *Gauge Pressure*.  
  **Ans.** absolute pressure minus atmospheric pressure
- **Q.** Define *McLeod Gauge*.  
  **Ans.** compresses gas to measure vacuum
- **Q.** Define *Pirani Gauge*.  
  **Ans.** thermal conductivity vacuum gauge
- **Q.** Define *Ionisation Gauge*.  
  **Ans.** measures very high vacuum
- **Q.** Define *Venturimeter*.  
  **Ans.** converging-diverging tube measuring flow
- **Q.** Define *Orifice Meter*.  
  **Ans.** plate with hole; cheap but higher loss
- **Q.** Define *Coefficient of Discharge*.  
  **Ans.** actual flow / theoretical flow
- **Q.** Define *Rotameter*.  
  **Ans.** variable-area meter with float
- **Q.** Define *Hot-wire Anemometer*.  
  **Ans.** measures velocity by heat loss
- **Q.** Define *Electromagnetic Flowmeter*.  
  **Ans.** measures conductive fluid flow by induced emf

### Long answer (7 marks)

- **Q.** Explain *Pressure Gauges* in detail with a neat diagram.  
  **Key points:** Pressure is measured relative to atmosphere or vacuum. Manometer — liquid column measuring pressure difference; Bourdon Tube — curved tube that straightens with pressure; Gauge Pressure — absolute pressure minus atmospheric pressure.
- **Q.** Explain *Low Pressure Measurement* in detail with a neat diagram.  
  **Key points:** Vacuum gauges measure low pressure. McLeod Gauge — compresses gas to measure vacuum; Pirani Gauge — thermal conductivity vacuum gauge; Ionisation Gauge — measures very high vacuum.
- **Q.** Explain *Obstruction Flow Meters* in detail with a neat diagram.  
  **Key points:** Flow is inferred from pressure drop. Venturimeter — converging-diverging tube measuring flow; Orifice Meter — plate with hole; cheap but higher loss; Coefficient of Discharge — actual flow / theoretical flow.
- **Q.** Explain *Other Flow Meters* in detail with a neat diagram.  
  **Key points:** Various principles measure flow. Rotameter — variable-area meter with float; Hot-wire Anemometer — measures velocity by heat loss; Electromagnetic Flowmeter — measures conductive fluid flow by induced emf.

## Unit 4: Temperature Measurement

### Short answer (2-3 marks)

- **Q.** Define *Bimetallic Strip*.  
  **Ans.** two metals bend differently with temperature
- **Q.** Define *Liquid-in-glass Thermometer*.  
  **Ans.** liquid expands in a capillary
- **Q.** Define *Pressure Thermometer*.  
  **Ans.** gas or liquid pressure in a bulb
- **Q.** Define *Seebeck Effect*.  
  **Ans.** emf generated in a junction of dissimilar metals
- **Q.** Define *Law of Intermediate Metals*.  
  **Ans.** third metal at same temperature adds no emf
- **Q.** Define *K-type Thermocouple*.  
  **Ans.** chromel-alumel, widely used
- **Q.** Define *RTD*.  
  **Ans.** platinum resistance thermometer
- **Q.** Define *Thermistor*.  
  **Ans.** semiconductor with high temperature sensitivity
- **Q.** Define *PT100*.  
  **Ans.** platinum RTD with 100 Ω at 0 °C
- **Q.** Define *Radiation Pyrometer*.  
  **Ans.** measures emitted thermal radiation
- **Q.** Define *Optical Pyrometer*.  
  **Ans.** compares brightness with a calibrated filament
- **Q.** Define *Emissivity*.  
  **Ans.** ratio of emitted radiation to black body radiation

### Long answer (7 marks)

- **Q.** Explain *Expansion Thermometers* in detail with a neat diagram.  
  **Key points:** Expansion of materials indicates temperature. Bimetallic Strip — two metals bend differently with temperature; Liquid-in-glass Thermometer — liquid expands in a capillary; Pressure Thermometer — gas or liquid pressure in a bulb.
- **Q.** Explain *Thermocouples* in detail with a neat diagram.  
  **Key points:** Thermocouples generate voltage from temperature difference. Seebeck Effect — emf generated in a junction of dissimilar metals; Law of Intermediate Metals — third metal at same temperature adds no emf; K-type Thermocouple — chromel-alumel, widely used.
- **Q.** Explain *Resistance Thermometers* in detail with a neat diagram.  
  **Key points:** Resistance varies with temperature. RTD — platinum resistance thermometer; Thermistor — semiconductor with high temperature sensitivity; PT100 — platinum RTD with 100 Ω at 0 °C.
- **Q.** Explain *Pyrometers* in detail with a neat diagram.  
  **Key points:** Non-contact methods measure high temperature. Radiation Pyrometer — measures emitted thermal radiation; Optical Pyrometer — compares brightness with a calibrated filament; Emissivity — ratio of emitted radiation to black body radiation.

## Unit 5: Control Systems

### Short answer (2-3 marks)

- **Q.** Define *Open-loop Control*.  
  **Ans.** no feedback of output
- **Q.** Define *Closed-loop Control*.  
  **Ans.** output compared with set point
- **Q.** Define *Error Signal*.  
  **Ans.** set point minus measured value
- **Q.** Define *Transfer Function*.  
  **Ans.** Laplace output / input
- **Q.** Define *Block Diagram*.  
  **Ans.** graphical representation of system
- **Q.** Define *Closed-loop Gain*.  
  **Ans.** G/(1 + GH)
- **Q.** Define *On-Off Control*.  
  **Ans.** two-position control with differential gap
- **Q.** Define *Proportional Control*.  
  **Ans.** output proportional to error, leaves offset
- **Q.** Define *PID Control*.  
  **Ans.** proportional, integral and derivative actions combined
- **Q.** Define *Hydraulic Actuator*.  
  **Ans.** uses pressurised oil for large forces
- **Q.** Define *Pneumatic Control*.  
  **Ans.** uses compressed air
- **Q.** Define *Servo Valve*.  
  **Ans.** valve controlling flow in proportion to signal

### Long answer (7 marks)

- **Q.** Explain *Open & Closed Loop Control* in detail with a neat diagram.  
  **Key points:** Feedback improves accuracy. Open-loop Control — no feedback of output; Closed-loop Control — output compared with set point; Error Signal — set point minus measured value.
- **Q.** Explain *Transfer Function & Block Diagrams* in detail with a neat diagram.  
  **Key points:** Systems are modelled mathematically. Transfer Function — Laplace output / input; Block Diagram — graphical representation of system; Closed-loop Gain — G/(1 + GH).
- **Q.** Explain *Controller Modes* in detail with a neat diagram.  
  **Key points:** Controllers act on error in different ways. On-Off Control — two-position control with differential gap; Proportional Control — output proportional to error, leaves offset; PID Control — proportional, integral and derivative actions combined.
- **Q.** Explain *Hydraulic & Pneumatic Control* in detail with a neat diagram.  
  **Key points:** Fluid power actuates industrial systems. Hydraulic Actuator — uses pressurised oil for large forces; Pneumatic Control — uses compressed air; Servo Valve — valve controlling flow in proportion to signal.
