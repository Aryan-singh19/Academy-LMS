## Answer Hints (Set A)

- **Q1(a):** 1G: analog voice systems such as AMPS
- **Q1(b):** Cell: geographic area served by one base station | Cluster Size: N = i² + ij + j² | Co-channel Reuse Ratio: Q = D/R = √(3N)
- **Q2(a):** Knife-edge Diffraction: bending over obstacles
- **Q2(b):** Multipath Fading: constructive and destructive interference of paths | Rayleigh Fading: fading with no line-of-sight component | Rician Fading: fading with a dominant line-of-sight path
- **Q3(a):** RAKE Receiver: combines multipath components in CDMA
- **Q3(b):** MIMO: multiple-input multiple-output antenna systems | Spatial Multiplexing: independent streams on different antennas | Beamforming: steering energy towards a user
- **Q4(a):** IS-95: first CDMA cellular standard
- **Q4(b):** BTS: base transceiver station | MSC: mobile switching centre routing calls | HLR and VLR: home and visitor location registers
- **Q5(a):** WCDMA: 5 MHz wideband CDMA air interface
- **Q5(b):** eNodeB: LTE base station | EPC: evolved packet core | OFDMA Downlink: LTE downlink multiple access
- **Q6(a):** Microcell Zone Concept: zones under one base station reduce handoffs
- **Q6(b):** 1G: analog voice systems such as AMPS | 2G: digital voice systems such as GSM and IS-95 | 4G LTE: all-IP broadband using OFDMA
- **Q7(a):** FDMA: each user gets a separate frequency band
- **Q7(b):** CDMA: users separated by orthogonal spreading codes | Near-far Problem: strong nearby users swamp distant ones; solved by power control | OFDMA: users assigned groups of orthogonal subcarriers
- **Q8(a):** EPC: evolved packet core
- **Q8(b):** eMBB: enhanced mobile broadband | URLLC: ultra-reliable low-latency communication | mmWave: millimetre-wave bands for very high capacity
