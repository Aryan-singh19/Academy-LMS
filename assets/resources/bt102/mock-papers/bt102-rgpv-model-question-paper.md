## Answer Hints (Set A)

- **Q1(a):** Rolle's Theorem: f(a) = f(b) implies f'(c) = 0 for some c in (a,b)
- **Q1(b):** Taylor Series: f(a + h) = f(a) + hf'(a) + h²f''(a)/2! + … | Maclaurin Series: Taylor series about 0 | Series of e^x: 1 + x + x²/2! + x³/3! + …
- **Q2(a):** D'Alembert's Ratio Test: converges if limit of a(n+1)/a(n) < 1
- **Q2(b):** p-series: Σ 1/n^p converges for p > 1 | Leibniz Test: alternating series converges if terms decrease to zero | Absolute Convergence: convergence of series of absolute values
- **Q3(a):** Sum of Eigenvalues: trace of A
- **Q3(b):** Cayley-Hamilton Theorem: every square matrix satisfies its characteristic equation | Diagonalisation: P⁻¹AP = D using eigenvectors | Inverse by Cayley-Hamilton: A⁻¹ from the characteristic polynomial
- **Q4(a):** Lagrange Multiplier Method: extremise f subject to g = 0 using F = f + λg
- **Q4(b):** Partial Derivative: rate of change keeping other variables constant | Euler's Theorem: x∂u/∂x + y∂u/∂y = nu for homogeneous u | Total Derivative: du = (∂u/∂x)dx + (∂u/∂y)dy
- **Q5(a):** Change of Order: swapping integration order with new limits
- **Q5(b):** Polar Element: dx dy = r dr dθ | Change of Variables: uses Jacobian | Area in Polar: ∫∫ r dr dθ
- **Q6(a):** Point of Inflection: curvature changes sign
- **Q6(b):** Rolle's Theorem: f(a) = f(b) implies f'(c) = 0 for some c in (a,b) | Lagrange MVT: f'(c) = (f(b) − f(a))/(b − a) | Cauchy MVT: generalisation using two functions
- **Q7(a):** Rank: order of largest non-zero minor
- **Q7(b):** Consistent System: rank of A equals rank of augmented matrix | Unique Solution: rank equals number of unknowns | Homogeneous System: AX = 0 always has trivial solution
- **Q8(a):** Change of Variables: uses Jacobian
- **Q8(b):** Triple Integral: ∫∫∫ f dx dy dz | Volume: ∫∫∫ dV | Spherical Coordinates: dV = r² sin θ dr dθ dφ
