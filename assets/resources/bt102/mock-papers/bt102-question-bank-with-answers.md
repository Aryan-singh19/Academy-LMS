# BT-102 Mathematics-I — Question Bank with Answer Hints

## Unit 1: Calculus

### Short answer (2-3 marks)

- **Q.** Define *Rolle's Theorem*.  
  **Ans.** f(a) = f(b) implies f'(c) = 0 for some c in (a,b)
- **Q.** Define *Lagrange MVT*.  
  **Ans.** f'(c) = (f(b) − f(a))/(b − a)
- **Q.** Define *Cauchy MVT*.  
  **Ans.** generalisation using two functions
- **Q.** Define *Taylor Series*.  
  **Ans.** f(a + h) = f(a) + hf'(a) + h²f''(a)/2! + …
- **Q.** Define *Maclaurin Series*.  
  **Ans.** Taylor series about 0
- **Q.** Define *Series of e^x*.  
  **Ans.** 1 + x + x²/2! + x³/3! + …
- **Q.** Define *L'Hospital's Rule*.  
  **Ans.** limit of f/g equals limit of f'/g' for 0/0 or ∞/∞
- **Q.** Define *Indeterminate Forms*.  
  **Ans.** 0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞
- **Q.** Define *Logarithmic Method*.  
  **Ans.** handles 1^∞ and 0^0 forms
- **Q.** Define *Stationary Point*.  
  **Ans.** f'(x) = 0
- **Q.** Define *Second Derivative Test*.  
  **Ans.** f''(x) < 0 gives maximum
- **Q.** Define *Point of Inflection*.  
  **Ans.** curvature changes sign

### Long answer (7 marks)

- **Q.** Explain *Rolle's & Mean Value Theorems* in detail with a neat diagram.  
  **Key points:** Mean value theorems link function values and derivatives. Rolle's Theorem — f(a) = f(b) implies f'(c) = 0 for some c in (a,b); Lagrange MVT — f'(c) = (f(b) − f(a))/(b − a); Cauchy MVT — generalisation using two functions.
- **Q.** Explain *Taylor & Maclaurin Series* in detail with a neat diagram.  
  **Key points:** Functions are expanded as power series. Taylor Series — f(a + h) = f(a) + hf'(a) + h²f''(a)/2! + …; Maclaurin Series — Taylor series about 0; Series of e^x — 1 + x + x²/2! + x³/3! + ….
- **Q.** Explain *Indeterminate Forms* in detail with a neat diagram.  
  **Key points:** Limits of forms like 0/0 are evaluated. L'Hospital's Rule — limit of f/g equals limit of f'/g' for 0/0 or ∞/∞; Indeterminate Forms — 0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞; Logarithmic Method — handles 1^∞ and 0^0 forms.
- **Q.** Explain *Maxima & Minima* in detail with a neat diagram.  
  **Key points:** Extreme values are found from derivatives. Stationary Point — f'(x) = 0; Second Derivative Test — f''(x) < 0 gives maximum; Point of Inflection — curvature changes sign.

## Unit 2: Sequences & Series

### Short answer (2-3 marks)

- **Q.** Define *Convergent Sequence*.  
  **Ans.** approaches a finite limit
- **Q.** Define *Monotonic Sequence*.  
  **Ans.** always increasing or always decreasing
- **Q.** Define *Bounded Sequence*.  
  **Ans.** all terms lie within a fixed range
- **Q.** Define *Comparison Test*.  
  **Ans.** compare with a known series
- **Q.** Define *D'Alembert's Ratio Test*.  
  **Ans.** converges if limit of a(n+1)/a(n) < 1
- **Q.** Define *Cauchy's Root Test*.  
  **Ans.** converges if nth root of a(n) tends to below 1
- **Q.** Define *p-series*.  
  **Ans.** Σ 1/n^p converges for p > 1
- **Q.** Define *Leibniz Test*.  
  **Ans.** alternating series converges if terms decrease to zero
- **Q.** Define *Absolute Convergence*.  
  **Ans.** convergence of series of absolute values
- **Q.** Define *Fourier Coefficients*.  
  **Ans.** a0, an and bn computed by integration
- **Q.** Define *Half-range Series*.  
  **Ans.** sine or cosine series over half period
- **Q.** Define *Even Function Series*.  
  **Ans.** contains only cosine terms

### Long answer (7 marks)

- **Q.** Explain *Sequences* in detail with a neat diagram.  
  **Key points:** Sequences are ordered lists with limits. Convergent Sequence — approaches a finite limit; Monotonic Sequence — always increasing or always decreasing; Bounded Sequence — all terms lie within a fixed range.
- **Q.** Explain *Tests for Convergence* in detail with a neat diagram.  
  **Key points:** Tests decide whether series converge. Comparison Test — compare with a known series; D'Alembert's Ratio Test — converges if limit of a(n+1)/a(n) < 1; Cauchy's Root Test — converges if nth root of a(n) tends to below 1.
- **Q.** Explain *p-series & Alternating Series* in detail with a neat diagram.  
  **Key points:** Standard series aid testing. p-series — Σ 1/n^p converges for p > 1; Leibniz Test — alternating series converges if terms decrease to zero; Absolute Convergence — convergence of series of absolute values.
- **Q.** Explain *Fourier Series Basics* in detail with a neat diagram.  
  **Key points:** Periodic functions as sine-cosine sums. Fourier Coefficients — a0, an and bn computed by integration; Half-range Series — sine or cosine series over half period; Even Function Series — contains only cosine terms.

## Unit 3: Matrices

### Short answer (2-3 marks)

- **Q.** Define *Rank*.  
  **Ans.** order of largest non-zero minor
- **Q.** Define *Echelon Form*.  
  **Ans.** row-reduced form revealing rank
- **Q.** Define *Normal Form*.  
  **Ans.** [I 0; 0 0] form via elementary operations
- **Q.** Define *Consistent System*.  
  **Ans.** rank of A equals rank of augmented matrix
- **Q.** Define *Unique Solution*.  
  **Ans.** rank equals number of unknowns
- **Q.** Define *Homogeneous System*.  
  **Ans.** AX = 0 always has trivial solution
- **Q.** Define *Characteristic Equation*.  
  **Ans.** det(A − λI) = 0
- **Q.** Define *Eigenvector*.  
  **Ans.** non-zero X with AX = λX
- **Q.** Define *Sum of Eigenvalues*.  
  **Ans.** trace of A
- **Q.** Define *Cayley-Hamilton Theorem*.  
  **Ans.** every square matrix satisfies its characteristic equation
- **Q.** Define *Diagonalisation*.  
  **Ans.** P⁻¹AP = D using eigenvectors
- **Q.** Define *Inverse by Cayley-Hamilton*.  
  **Ans.** A⁻¹ from the characteristic polynomial

### Long answer (7 marks)

- **Q.** Explain *Rank of a Matrix* in detail with a neat diagram.  
  **Key points:** Rank measures independent rows. Rank — order of largest non-zero minor; Echelon Form — row-reduced form revealing rank; Normal Form — [I 0; 0 0] form via elementary operations.
- **Q.** Explain *System of Linear Equations* in detail with a neat diagram.  
  **Key points:** Consistency is decided by ranks. Consistent System — rank of A equals rank of augmented matrix; Unique Solution — rank equals number of unknowns; Homogeneous System — AX = 0 always has trivial solution.
- **Q.** Explain *Eigenvalues & Eigenvectors* in detail with a neat diagram.  
  **Key points:** Eigen-analysis finds invariant directions. Characteristic Equation — det(A − λI) = 0; Eigenvector — non-zero X with AX = λX; Sum of Eigenvalues — trace of A.
- **Q.** Explain *Cayley-Hamilton & Diagonalisation* in detail with a neat diagram.  
  **Key points:** Matrices satisfy their characteristic equation. Cayley-Hamilton Theorem — every square matrix satisfies its characteristic equation; Diagonalisation — P⁻¹AP = D using eigenvectors; Inverse by Cayley-Hamilton — A⁻¹ from the characteristic polynomial.

## Unit 4: Multivariable Calculus

### Short answer (2-3 marks)

- **Q.** Define *Partial Derivative*.  
  **Ans.** rate of change keeping other variables constant
- **Q.** Define *Euler's Theorem*.  
  **Ans.** x∂u/∂x + y∂u/∂y = nu for homogeneous u
- **Q.** Define *Total Derivative*.  
  **Ans.** du = (∂u/∂x)dx + (∂u/∂y)dy
- **Q.** Define *Jacobian*.  
  **Ans.** determinant of partial derivatives ∂(u,v)/∂(x,y)
- **Q.** Define *Functional Dependence*.  
  **Ans.** Jacobian zero implies dependence
- **Q.** Define *Chain Property*.  
  **Ans.** J·J' = 1 for inverse transformations
- **Q.** Define *Condition for Extremum*.  
  **Ans.** fx = fy = 0
- **Q.** Define *rt − s² Test*.  
  **Ans.** maximum if rt − s² > 0 and r < 0
- **Q.** Define *Saddle Point*.  
  **Ans.** rt − s² < 0
- **Q.** Define *Lagrange Multiplier Method*.  
  **Ans.** extremise f subject to g = 0 using F = f + λg
- **Q.** Define *Constraint*.  
  **Ans.** condition the variables must satisfy
- **Q.** Define *Stationary Conditions*.  
  **Ans.** ∂F/∂x = ∂F/∂y = ∂F/∂λ = 0

### Long answer (7 marks)

- **Q.** Explain *Partial Differentiation* in detail with a neat diagram.  
  **Key points:** Derivatives with respect to one variable at a time. Partial Derivative — rate of change keeping other variables constant; Euler's Theorem — x∂u/∂x + y∂u/∂y = nu for homogeneous u; Total Derivative — du = (∂u/∂x)dx + (∂u/∂y)dy.
- **Q.** Explain *Jacobians* in detail with a neat diagram.  
  **Key points:** Jacobians relate variable transformations. Jacobian — determinant of partial derivatives ∂(u,v)/∂(x,y); Functional Dependence — Jacobian zero implies dependence; Chain Property — J·J' = 1 for inverse transformations.
- **Q.** Explain *Maxima & Minima of Two Variables* in detail with a neat diagram.  
  **Key points:** Extrema use second partial derivatives. Condition for Extremum — fx = fy = 0; rt − s² Test — maximum if rt − s² > 0 and r < 0; Saddle Point — rt − s² < 0.
- **Q.** Explain *Lagrange Multipliers* in detail with a neat diagram.  
  **Key points:** Constrained optimisation. Lagrange Multiplier Method — extremise f subject to g = 0 using F = f + λg; Constraint — condition the variables must satisfy; Stationary Conditions — ∂F/∂x = ∂F/∂y = ∂F/∂λ = 0.
