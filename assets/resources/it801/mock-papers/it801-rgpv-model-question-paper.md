## Answer Hints (Set A)

- **Q1(a):** Data Science: interdisciplinary field extracting insight from data
- **Q1(b):** Structured Data: data organised in rows and columns | Unstructured Data: text, images or audio without a fixed schema | Nominal vs Ordinal: categories without order versus ordered categories
- **Q2(a):** Central Limit Theorem: sample means approach a normal distribution as n grows
- **Q2(b):** Null Hypothesis: default claim of no effect | p-value: probability of results at least as extreme if the null is true | Type I Error: rejecting a true null hypothesis
- **Q3(a):** Correlation Matrix: table of pairwise correlation coefficients
- **Q3(b):** Feature Engineering: creating informative input variables from raw data | Feature Selection: choosing a subset of relevant features | Dimensionality Reduction: reducing variables, e.g. with PCA
- **Q4(a):** Overfitting: model fits noise in training data and fails on new data
- **Q4(b):** Logistic Regression: models probability of a binary outcome | Random Forest: ensemble of decision trees using bagging | Support Vector Machine: finds the maximum-margin separating hyperplane
- **Q5(a):** Histogram: bar chart of value frequencies in bins
- **Q5(b):** Matplotlib: foundational Python plotting library | Seaborn: statistical visualisation library built on Matplotlib | Tableau: business intelligence tool for interactive dashboards
- **Q6(a):** Jupyter Notebook: interactive environment mixing code, output and text
- **Q6(b):** Data Science: interdisciplinary field extracting insight from data | Data Scientist: practitioner combining statistics, programming and domain knowledge | CRISP-DM: process model: business understanding, data understanding, preparation, modelling, evaluation, deployment
- **Q7(a):** Missing Value Imputation: filling gaps using mean, median or models
- **Q7(b):** Normalisation: scaling values to a fixed range such as 0 to 1 | Standardisation: rescaling to zero mean and unit variance | One-hot Encoding: converting categories into binary indicator columns
- **Q8(a):** Seaborn: statistical visualisation library built on Matplotlib
- **Q8(b):** Apache Spark: in-memory distributed data processing engine | HDFS: Hadoop distributed file system | NoSQL Database: non-relational store such as MongoDB or Cassandra
