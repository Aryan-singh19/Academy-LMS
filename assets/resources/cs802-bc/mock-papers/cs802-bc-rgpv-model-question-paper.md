## Answer Hints (Set A)

- **Q1(a):** Blockchain: chain of blocks, each linking to the previous block's hash
- **Q1(b):** Public Blockchain: anyone can read, transact and validate, e.g. Bitcoin | Private Blockchain: controlled by one organisation | Consortium Blockchain: governed by a group of organisations
- **Q2(a):** Merkle Root: top hash stored in the block header
- **Q2(b):** Public Key: shared key used to verify signatures and derive addresses | ECDSA: elliptic curve digital signature algorithm used in Bitcoin and Ethereum | Wallet: software storing private keys and creating transactions
- **Q3(a):** Finality: point after which a transaction cannot be reversed
- **Q3(b):** Soft Fork: backward-compatible rule tightening | Hard Fork: non-backward-compatible change splitting the chain | Orphan Block: valid block not included in the main chain
- **Q4(a):** ERC-20: standard for fungible tokens on Ethereum
- **Q4(b):** UTXO: unspent transaction output model used by Bitcoin | Bitcoin Script: simple stack-based language locking outputs | Block Reward: new coins plus fees given to the miner
- **Q5(a):** Chaincode: smart contract in Hyperledger Fabric
- **Q5(b):** Scalability Trilemma: trade-off among decentralisation, security and scalability | Sharding: splitting the network so shards process transactions in parallel | Lightning Network: Bitcoin layer-2 payment channels
- **Q6(a):** Trustless System: participants need not trust each other, only the protocol
- **Q6(b):** Blockchain: chain of blocks, each linking to the previous block's hash | Distributed Ledger: database shared and synchronised across many nodes | Immutability: recorded data cannot be altered without breaking the chain
- **Q7(a):** Proof of Work: consensus where miners find a nonce giving a hash below a target
- **Q7(b):** Proof of Stake: validators selected in proportion to coins staked | Slashing: penalty destroying stake of misbehaving validators | Delegated PoS: token holders elect a small set of validators
- **Q8(a):** Sharding: splitting the network so shards process transactions in parallel
- **Q8(b):** Supply Chain Traceability: recording product movement on a shared ledger | Self-sovereign Identity: users control their own identity credentials | DeFi: decentralised finance services built on smart contracts
