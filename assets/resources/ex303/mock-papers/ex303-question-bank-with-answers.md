# EX-303 Electrical Measurements & Measuring Instruments — Question Bank with Answer Hints

## Unit 1: Measurement Fundamentals & Galvanometers

### Short answer (2-3 marks)

- **Q.** Define *Absolute Instrument*.  
  **Ans.** gives value from constants, e.g. tangent galvanometer
- **Q.** Define *Secondary Instrument*.  
  **Ans.** calibrated against absolute instrument
- **Q.** Define *Deflecting Torque*.  
  **Ans.** torque moving the pointer
- **Q.** Define *Controlling Torque*.  
  **Ans.** spring or gravity torque opposing deflection
- **Q.** Define *Damping Torque*.  
  **Ans.** brings pointer to rest quickly
- **Q.** Define *Eddy Current Damping*.  
  **Ans.** damping by induced currents
- **Q.** Define *D'Arsonval Galvanometer*.  
  **Ans.** moving coil in permanent magnet field
- **Q.** Define *Current Sensitivity*.  
  **Ans.** deflection per unit current
- **Q.** Define *Critical Damping Resistance*.  
  **Ans.** resistance for critical damping
- **Q.** Define *Ballistic Galvanometer*.  
  **Ans.** measures quantity of charge
- **Q.** Define *Ballistic Throw*.  
  **Ans.** first maximum deflection
- **Q.** Define *Flux Meter*.  
  **Ans.** special ballistic galvanometer for flux

### Long answer (7 marks)

- **Q.** Explain *Measurement Basics* in detail with a neat diagram.  
  **Key points:** Instruments are classified by operation and output. Absolute Instrument — gives value from constants, e.g. tangent galvanometer; Secondary Instrument — calibrated against absolute instrument; Deflecting Torque — torque moving the pointer.
- **Q.** Explain *Torques in Instruments* in detail with a neat diagram.  
  **Key points:** Three torques act in indicating instruments. Controlling Torque — spring or gravity torque opposing deflection; Damping Torque — brings pointer to rest quickly; Eddy Current Damping — damping by induced currents.
- **Q.** Explain *D'Arsonval Galvanometer* in detail with a neat diagram.  
  **Key points:** Moving coil galvanometer detects small currents. D'Arsonval Galvanometer — moving coil in permanent magnet field; Current Sensitivity — deflection per unit current; Critical Damping Resistance — resistance for critical damping.
- **Q.** Explain *Ballistic Galvanometer* in detail with a neat diagram.  
  **Key points:** Measures charge in short pulses. Ballistic Galvanometer — measures quantity of charge; Ballistic Throw — first maximum deflection; Flux Meter — special ballistic galvanometer for flux.

## Unit 2: Indicating Instruments

### Short answer (2-3 marks)

- **Q.** Define *PMMC*.  
  **Ans.** permanent magnet moving coil, linear scale
- **Q.** Define *Torque Equation*.  
  **Ans.** Td = NBAI
- **Q.** Define *Swamping Resistance*.  
  **Ans.** reduces temperature error
- **Q.** Define *Attraction Type*.  
  **Ans.** iron drawn into coil
- **Q.** Define *Repulsion Type*.  
  **Ans.** two irons repel each other
- **Q.** Define *Square Law Scale*.  
  **Ans.** deflection proportional to I²
- **Q.** Define *Electrodynamometer*.  
  **Ans.** no iron, accurate for AC
- **Q.** Define *Transfer Instrument*.  
  **Ans.** calibrated on DC, used on AC
- **Q.** Define *Wattmeter Application*.  
  **Ans.** current and pressure coils
- **Q.** Define *Shunt Resistance*.  
  **Ans.** Rsh = Rm/(m − 1)
- **Q.** Define *Multiplier*.  
  **Ans.** Rs = Rm(m − 1)
- **Q.** Define *Universal Shunt*.  
  **Ans.** Ayrton shunt for multi-range ammeters

### Long answer (7 marks)

- **Q.** Explain *PMMC Instrument* in detail with a neat diagram.  
  **Key points:** Accurate DC measurement. PMMC — permanent magnet moving coil, linear scale; Torque Equation — Td = NBAI; Swamping Resistance — reduces temperature error.
- **Q.** Explain *Moving Iron Instruments* in detail with a neat diagram.  
  **Key points:** Rugged instruments for AC and DC. Attraction Type — iron drawn into coil; Repulsion Type — two irons repel each other; Square Law Scale — deflection proportional to I².
- **Q.** Explain *Electrodynamometer Instruments* in detail with a neat diagram.  
  **Key points:** Fixed and moving coils interact. Electrodynamometer — no iron, accurate for AC; Transfer Instrument — calibrated on DC, used on AC; Wattmeter Application — current and pressure coils.
- **Q.** Explain *Extending Ranges* in detail with a neat diagram.  
  **Key points:** Shunts and multipliers extend range. Shunt Resistance — Rsh = Rm/(m − 1); Multiplier — Rs = Rm(m − 1); Universal Shunt — Ayrton shunt for multi-range ammeters.
