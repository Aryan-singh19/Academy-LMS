# EC-801 Optical Fibre Communication — Question Bank with Answer Hints

## Unit 1: Optical Fibre Fundamentals

### Short answer (2-3 marks)

- **Q.** Define *Optical Fibre*.  
  **Ans.** thin glass waveguide carrying light
- **Q.** Define *Advantages of OFC*.  
  **Ans.** huge bandwidth, low loss, EMI immunity
- **Q.** Define *Optical Windows*.  
  **Ans.** low-loss bands near 850, 1310 and 1550 nm
- **Q.** Define *Total Internal Reflection*.  
  **Ans.** reflection when angle exceeds critical angle
- **Q.** Define *Critical Angle*.  
  **Ans.** sin θc = n2/n1
- **Q.** Define *Snell's Law*.  
  **Ans.** n1 sin θ1 = n2 sin θ2
- **Q.** Define *Numerical Aperture*.  
  **Ans.** NA = √(n1² − n2²)
- **Q.** Define *Acceptance Angle*.  
  **Ans.** maximum entry angle for guided rays
- **Q.** Define *Relative Index Difference*.  
  **Ans.** Δ = (n1 − n2)/n1
- **Q.** Define *V-number*.  
  **Ans.** V = (2πa/λ)·NA
- **Q.** Define *Single-mode Condition*.  
  **Ans.** V < 2.405
- **Q.** Define *Number of Modes*.  
  **Ans.** approximately V²/2 for step-index fibre

### Long answer (7 marks)

- **Q.** Explain *Optical Communication Overview* in detail with a neat diagram.  
  **Key points:** Light carries data through glass fibres. Optical Fibre — thin glass waveguide carrying light; Advantages of OFC — huge bandwidth, low loss, EMI immunity; Optical Windows — low-loss bands near 850, 1310 and 1550 nm.
- **Q.** Explain *Total Internal Reflection* in detail with a neat diagram.  
  **Key points:** Light is guided by refraction at core-cladding boundary. Total Internal Reflection — reflection when angle exceeds critical angle; Critical Angle — sin θc = n2/n1; Snell's Law — n1 sin θ1 = n2 sin θ2.
- **Q.** Explain *Numerical Aperture & Acceptance Angle* in detail with a neat diagram.  
  **Key points:** NA measures light-gathering ability. Numerical Aperture — NA = √(n1² − n2²); Acceptance Angle — maximum entry angle for guided rays; Relative Index Difference — Δ = (n1 − n2)/n1.
- **Q.** Explain *Modes & V-number* in detail with a neat diagram.  
  **Key points:** Fibres support modes depending on V. V-number — V = (2πa/λ)·NA; Single-mode Condition — V < 2.405; Number of Modes — approximately V²/2 for step-index fibre.

## Unit 2: Fibre Types & Transmission Characteristics

### Short answer (2-3 marks)

- **Q.** Define *Step-index Fibre*.  
  **Ans.** uniform core index with abrupt change
- **Q.** Define *Graded-index Fibre*.  
  **Ans.** core index decreases radially, reducing modal dispersion
- **Q.** Define *Single-mode Fibre*.  
  **Ans.** small core carrying one mode
- **Q.** Define *Attenuation*.  
  **Ans.** α = (10/L) log(Pin/Pout) dB/km
- **Q.** Define *Rayleigh Scattering*.  
  **Ans.** loss proportional to 1/λ⁴
- **Q.** Define *Absorption Loss*.  
  **Ans.** due to impurities such as OH ions
- **Q.** Define *Intermodal Dispersion*.  
  **Ans.** different modes arrive at different times
- **Q.** Define *Chromatic Dispersion*.  
  **Ans.** different wavelengths travel at different speeds
- **Q.** Define *Polarisation Mode Dispersion*.  
  **Ans.** differential delay of polarisation modes
- **Q.** Define *Macrobending*.  
  **Ans.** loss from large-radius bends
- **Q.** Define *Microbending*.  
  **Ans.** loss from small random distortions
- **Q.** Define *Fusion Splice*.  
  **Ans.** joining fibres by melting, low loss

### Long answer (7 marks)

- **Q.** Explain *Step-index & Graded-index Fibres* in detail with a neat diagram.  
  **Key points:** Index profile affects dispersion. Step-index Fibre — uniform core index with abrupt change; Graded-index Fibre — core index decreases radially, reducing modal dispersion; Single-mode Fibre — small core carrying one mode.
- **Q.** Explain *Attenuation* in detail with a neat diagram.  
  **Key points:** Signal power is lost along the fibre. Attenuation — α = (10/L) log(Pin/Pout) dB/km; Rayleigh Scattering — loss proportional to 1/λ⁴; Absorption Loss — due to impurities such as OH ions.
- **Q.** Explain *Dispersion* in detail with a neat diagram.  
  **Key points:** Pulses broaden and limit bandwidth. Intermodal Dispersion — different modes arrive at different times; Chromatic Dispersion — different wavelengths travel at different speeds; Polarisation Mode Dispersion — differential delay of polarisation modes.
- **Q.** Explain *Bending & Splicing Losses* in detail with a neat diagram.  
  **Key points:** Mechanical effects cause loss. Macrobending — loss from large-radius bends; Microbending — loss from small random distortions; Fusion Splice — joining fibres by melting, low loss.

## Unit 3: Optical Sources

### Short answer (2-3 marks)

- **Q.** Define *Surface-emitting LED*.  
  **Ans.** emits from the surface with broad pattern
- **Q.** Define *Edge-emitting LED*.  
  **Ans.** higher brightness and narrower spectrum
- **Q.** Define *Internal Quantum Efficiency*.  
  **Ans.** fraction of recombinations that emit photons
- **Q.** Define *Stimulated Emission*.  
  **Ans.** photon triggers emission of identical photon
- **Q.** Define *Population Inversion*.  
  **Ans.** more electrons in excited state than ground
- **Q.** Define *Threshold Current*.  
  **Ans.** current above which lasing begins
- **Q.** Define *DFB Laser*.  
  **Ans.** distributed feedback laser with grating, single longitudinal mode
- **Q.** Define *VCSEL*.  
  **Ans.** vertical-cavity surface-emitting laser
- **Q.** Define *Fabry-Perot Laser*.  
  **Ans.** simple cavity laser with multiple modes
- **Q.** Define *Direct Modulation*.  
  **Ans.** varying drive current
- **Q.** Define *External Modulator*.  
  **Ans.** e.g. Mach-Zehnder modulator for high speed
- **Q.** Define *Chirp*.  
  **Ans.** frequency shift during modulation causing dispersion

### Long answer (7 marks)

- **Q.** Explain *LED Sources* in detail with a neat diagram.  
  **Key points:** LEDs are simple incoherent sources. Surface-emitting LED — emits from the surface with broad pattern; Edge-emitting LED — higher brightness and narrower spectrum; Internal Quantum Efficiency — fraction of recombinations that emit photons.
- **Q.** Explain *Laser Diodes* in detail with a neat diagram.  
  **Key points:** Lasers give coherent narrow-linewidth light. Stimulated Emission — photon triggers emission of identical photon; Population Inversion — more electrons in excited state than ground; Threshold Current — current above which lasing begins.
- **Q.** Explain *Laser Types* in detail with a neat diagram.  
  **Key points:** Structures improve single-mode operation. DFB Laser — distributed feedback laser with grating, single longitudinal mode; VCSEL — vertical-cavity surface-emitting laser; Fabry-Perot Laser — simple cavity laser with multiple modes.
- **Q.** Explain *Modulation of Sources* in detail with a neat diagram.  
  **Key points:** Data is impressed on light. Direct Modulation — varying drive current; External Modulator — e.g. Mach-Zehnder modulator for high speed; Chirp — frequency shift during modulation causing dispersion.

## Unit 4: Optical Detectors & Receivers

### Short answer (2-3 marks)

- **Q.** Define *Responsivity*.  
  **Ans.** R = Ip/P0 A/W
- **Q.** Define *Quantum Efficiency*.  
  **Ans.** electrons generated per incident photon
- **Q.** Define *Cut-off Wavelength*.  
  **Ans.** λc = 1.24/Eg µm
- **Q.** Define *PIN Photodiode*.  
  **Ans.** intrinsic layer widens depletion region
- **Q.** Define *APD*.  
  **Ans.** avalanche photodiode with internal gain
- **Q.** Define *Excess Noise Factor*.  
  **Ans.** extra noise due to avalanche multiplication
- **Q.** Define *Shot Noise*.  
  **Ans.** from discrete photon arrivals
- **Q.** Define *Thermal Noise*.  
  **Ans.** from load resistor
- **Q.** Define *Receiver Sensitivity*.  
  **Ans.** minimum power for a target BER
- **Q.** Define *Transimpedance Amplifier*.  
  **Ans.** converts photocurrent to voltage
- **Q.** Define *High-impedance Front End*.  
  **Ans.** low noise but limited bandwidth
- **Q.** Define *Bit Error Rate*.  
  **Ans.** fraction of erroneous bits, often 10^−9 target

### Long answer (7 marks)

- **Q.** Explain *Photodetector Principles* in detail with a neat diagram.  
  **Key points:** Detectors convert light into current. Responsivity — R = Ip/P0 A/W; Quantum Efficiency — electrons generated per incident photon; Cut-off Wavelength — λc = 1.24/Eg µm.
- **Q.** Explain *PIN & APD Photodiodes* in detail with a neat diagram.  
  **Key points:** Two main detector types. PIN Photodiode — intrinsic layer widens depletion region; APD — avalanche photodiode with internal gain; Excess Noise Factor — extra noise due to avalanche multiplication.
- **Q.** Explain *Receiver Noise & Sensitivity* in detail with a neat diagram.  
  **Key points:** Noise limits detection. Shot Noise — from discrete photon arrivals; Thermal Noise — from load resistor; Receiver Sensitivity — minimum power for a target BER.
- **Q.** Explain *Receiver Structures* in detail with a neat diagram.  
  **Key points:** Front ends amplify the photocurrent. Transimpedance Amplifier — converts photocurrent to voltage; High-impedance Front End — low noise but limited bandwidth; Bit Error Rate — fraction of erroneous bits, often 10^−9 target.

## Unit 5: Optical Links & Networks

### Short answer (2-3 marks)

- **Q.** Define *Power Budget*.  
  **Ans.** Ptx − Prx(min) ≥ total losses + margin
- **Q.** Define *System Margin*.  
  **Ans.** extra power allowed for ageing
- **Q.** Define *Splice and Connector Loss*.  
  **Ans.** per-joint losses included in budget
- **Q.** Define *Rise Time Budget*.  
  **Ans.** system rise time is root-sum-square of components
- **Q.** Define *NRZ Requirement*.  
  **Ans.** tsys ≤ 0.7/B
- **Q.** Define *Component Rise Times*.  
  **Ans.** transmitter, fibre dispersion and receiver
- **Q.** Define *WDM*.  
  **Ans.** multiple wavelengths on one fibre
- **Q.** Define *DWDM*.  
  **Ans.** dense WDM with narrow channel spacing
- **Q.** Define *EDFA*.  
  **Ans.** erbium-doped fibre amplifier for the 1550 nm band
- **Q.** Define *SONET/SDH*.  
  **Ans.** synchronous optical network standards
- **Q.** Define *PON*.  
  **Ans.** passive optical network for FTTH
- **Q.** Define *OTDR*.  
  **Ans.** optical time domain reflectometer locating faults

### Long answer (7 marks)

- **Q.** Explain *Link Power Budget* in detail with a neat diagram.  
  **Key points:** Budgets ensure enough power reaches the receiver. Power Budget — Ptx − Prx(min) ≥ total losses + margin; System Margin — extra power allowed for ageing; Splice and Connector Loss — per-joint losses included in budget.
- **Q.** Explain *Rise Time Budget* in detail with a neat diagram.  
  **Key points:** Bandwidth is checked through rise times. Rise Time Budget — system rise time is root-sum-square of components; NRZ Requirement — tsys ≤ 0.7/B; Component Rise Times — transmitter, fibre dispersion and receiver.
- **Q.** Explain *WDM & Optical Amplifiers* in detail with a neat diagram.  
  **Key points:** WDM multiplies fibre capacity. WDM — multiple wavelengths on one fibre; DWDM — dense WDM with narrow channel spacing; EDFA — erbium-doped fibre amplifier for the 1550 nm band.
- **Q.** Explain *Optical Networks* in detail with a neat diagram.  
  **Key points:** Fibres form access and core networks. SONET/SDH — synchronous optical network standards; PON — passive optical network for FTTH; OTDR — optical time domain reflectometer locating faults.
