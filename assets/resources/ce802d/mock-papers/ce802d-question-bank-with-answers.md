## Unit 3: Seismic Analysis as per IS 1893

### Short answer (2-3 marks)

- **Q.** Define *Design Base Shear*.  
  **Ans.** VB = Ah W
- **Q.** Define *Design Horizontal Coefficient*.  
  **Ans.** Ah = (Z/2)(I/R)(Sa/g)
- **Q.** Define *Importance Factor*.  
  **Ans.** 1.0 or 1.5 for important buildings
- **Q.** Define *Response Reduction Factor*.  
  **Ans.** R, e.g. 5 for SMRF
- **Q.** Define *SMRF*.  
  **Ans.** special moment resisting frame
- **Q.** Define *OMRF*.  
  **Ans.** ordinary moment resisting frame
- **Q.** Define *Vertical Distribution*.  
  **Ans.** Qi = VB Wi hi² / Σ Wj hj²
- **Q.** Define *Fundamental Period*.  
  **Ans.** Ta = 0.075 h^0.75 for RC frames
- **Q.** Define *Storey Drift Limit*.  
  **Ans.** 0.004 times storey height
- **Q.** Define *Soft Storey*.  
  **Ans.** stiffness much less than storey above
- **Q.** Define *Torsional Irregularity*.  
  **Ans.** uneven lateral stiffness distribution
- **Q.** Define *Re-entrant Corner*.  
  **Ans.** L or T shaped plans

### Long answer (7 marks)

- **Q.** Explain *Design Lateral Force* in detail with a neat diagram.  
  **Key points:** Codes give design base shear. Design Base Shear — VB = Ah W; Design Horizontal Coefficient — Ah = (Z/2)(I/R)(Sa/g); Importance Factor — 1.0 or 1.5 for important buildings.
- **Q.** Explain *Response Reduction Factor* in detail with a neat diagram.  
  **Key points:** Ductility reduces design forces. Response Reduction Factor — R, e.g. 5 for SMRF; SMRF — special moment resisting frame; OMRF — ordinary moment resisting frame.
- **Q.** Explain *Equivalent Static Method* in detail with a neat diagram.  
  **Key points:** Base shear is distributed by height. Vertical Distribution — Qi = VB Wi hi² / Σ Wj hj²; Fundamental Period — Ta = 0.075 h^0.75 for RC frames; Storey Drift Limit — 0.004 times storey height.
- **Q.** Explain *Irregularities* in detail with a neat diagram.  
  **Key points:** Irregular buildings perform poorly. Soft Storey — stiffness much less than storey above; Torsional Irregularity — uneven lateral stiffness distribution; Re-entrant Corner — L or T shaped plans.
