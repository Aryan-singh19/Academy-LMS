## Unit 1: Exergy Analysis

### Short answer (2-3 marks)

- **Q.** Define *Exergy*.  
  **Ans.** maximum useful work relative to dead state
- **Q.** Define *Dead State*.  
  **Ans.** equilibrium with environment
- **Q.** Define *Exergy Destruction*.  
  **Ans.** T0 × entropy generation
- **Q.** Define *Closed System Exergy Balance*.  
  **Ans.** exergy in − out − destroyed = change
- **Q.** Define *Flow Exergy*.  
  **Ans.** (h − h0) − T0(s − s0) + V²/2 + gz
- **Q.** Define *Second-law Efficiency*.  
  **Ans.** exergy recovered / exergy supplied
- **Q.** Define *Rankine Cycle Exergy*.  
  **Ans.** losses mainly in boiler
- **Q.** Define *Gas Turbine Exergy*.  
  **Ans.** losses in combustor
- **Q.** Define *Exergoeconomics*.  
  **Ans.** cost of exergy losses
- **Q.** Define *Gouy-Stodola Theorem*.  
  **Ans.** lost work = T0 Sgen
- **Q.** Define *Entropy Generation Number*.  
  **Ans.** dimensionless irreversibility
- **Q.** Define *Optimum Design*.  
  **Ans.** balances heat transfer and friction irreversibility

### Long answer (7 marks)

- **Q.** Explain *Exergy Concept* in detail with a neat diagram.  
  **Key points:** Exergy is the useful work potential. Exergy — maximum useful work relative to dead state; Dead State — equilibrium with environment; Exergy Destruction — T0 × entropy generation.
- **Q.** Explain *Exergy Balance* in detail with a neat diagram.  
  **Key points:** Balances locate losses. Closed System Exergy Balance — exergy in − out − destroyed = change; Flow Exergy — (h − h0) − T0(s − s0) + V²/2 + gz; Second-law Efficiency — exergy recovered / exergy supplied.
- **Q.** Explain *Exergy of Power Cycles* in detail with a neat diagram.  
  **Key points:** Second-law analysis of cycles. Rankine Cycle Exergy — losses mainly in boiler; Gas Turbine Exergy — losses in combustor; Exergoeconomics — cost of exergy losses.
- **Q.** Explain *Entropy Generation Minimisation* in detail with a neat diagram.  
  **Key points:** Design to reduce irreversibility. Gouy-Stodola Theorem — lost work = T0 Sgen; Entropy Generation Number — dimensionless irreversibility; Optimum Design — balances heat transfer and friction irreversibility.

## Unit 2: Thermodynamic Relations

### Short answer (2-3 marks)

- **Q.** Define *Maxwell Relation*.  
  **Ans.** (∂T/∂v)s = −(∂p/∂s)v
- **Q.** Define *Helmholtz Function*.  
  **Ans.** a = u − Ts
- **Q.** Define *Gibbs Function*.  
  **Ans.** g = h − Ts
- **Q.** Define *Clapeyron Equation*.  
  **Ans.** dp/dT = hfg/(T vfg)
- **Q.** Define *Joule-Thomson Coefficient*.  
  **Ans.** μJT = (∂T/∂p)h
- **Q.** Define *cp − cv Relation*.  
  **Ans.** T v β²/κ
- **Q.** Define *Compressibility Factor*.  
  **Ans.** Z = pv/(RT)
- **Q.** Define *Van der Waals Equation*.  
  **Ans.** (p + a/v²)(v − b) = RT
- **Q.** Define *Law of Corresponding States*.  
  **Ans.** Z depends on reduced properties
- **Q.** Define *Reduced Pressure*.  
  **Ans.** p/pc
- **Q.** Define *Enthalpy Departure*.  
  **Ans.** deviation from ideal gas
- **Q.** Define *Fugacity*.  
  **Ans.** effective pressure of real gas

### Long answer (7 marks)

- **Q.** Explain *Maxwell Relations* in detail with a neat diagram.  
  **Key points:** Relations among properties. Maxwell Relation — (∂T/∂v)s = −(∂p/∂s)v; Helmholtz Function — a = u − Ts; Gibbs Function — g = h − Ts.
- **Q.** Explain *General Property Relations* in detail with a neat diagram.  
  **Key points:** Derive unmeasured properties. Clapeyron Equation — dp/dT = hfg/(T vfg); Joule-Thomson Coefficient — μJT = (∂T/∂p)h; cp − cv Relation — T v β²/κ.
- **Q.** Explain *Real Gases* in detail with a neat diagram.  
  **Key points:** Ideal gas law fails at high pressure. Compressibility Factor — Z = pv/(RT); Van der Waals Equation — (p + a/v²)(v − b) = RT; Law of Corresponding States — Z depends on reduced properties.
- **Q.** Explain *Generalised Charts* in detail with a neat diagram.  
  **Key points:** Charts give real gas properties. Reduced Pressure — p/pc; Enthalpy Departure — deviation from ideal gas; Fugacity — effective pressure of real gas.

## Unit 3: Mixtures & Psychrometry

  **Ans.** total pressure equals sum of partial pressures
- **Q.** Define *Amagat's Law*.  
  **Ans.** total volume equals sum of partial volumes
- **Q.** Define *Mole Fraction*.  
  **Ans.** moles of component / total
- **Q.** Define *Kay's Rule*.  
  **Ans.** pseudo-critical properties of mixture
- **Q.** Define *Partial Molar Property*.  
  **Ans.** property per mole in mixture
- **Q.** Define *Activity Coefficient*.  
  **Ans.** deviation from ideal solution
- **Q.** Define *Adiabatic Saturation*.  
  **Ans.** defines thermodynamic wet bulb
- **Q.** Define *Humidity Ratio*.  
  **Ans.** mass of vapour per mass of dry air
- **Q.** Define *Enthalpy of Moist Air*.  
  **Ans.** h = 1.005T + ω(2501 + 1.88T)
- **Q.** Define *Gibbs Phase Rule*.

- **Q.** Define *Raoult's Law*.  
  **Ans.** partial pressure = mole fraction × vapour pressure
- **Q.** Define *Chemical Potential*.
