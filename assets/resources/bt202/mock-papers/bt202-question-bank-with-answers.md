# BT-202 Mathematics-II — Question Bank with Answer Hints

## Unit 1: First Order ODEs

### Short answer (2-3 marks)

- **Q.** Define *Exactness Condition*.  
  **Ans.** ∂M/∂y = ∂N/∂x
- **Q.** Define *Integrating Factor*.  
  **Ans.** multiplier making equation exact
- **Q.** Define *Solution*.  
  **Ans.** ∫M dx + ∫(terms of N without x) dy = c
- **Q.** Define *Linear Equation*.  
  **Ans.** dy/dx + Py = Q
- **Q.** Define *Integrating Factor of Linear*.  
  **Ans.** e^(∫P dx)
- **Q.** Define *Bernoulli Equation*.  
  **Ans.** dy/dx + Py = Qy^n
- **Q.** Define *Clairaut's Equation*.  
  **Ans.** y = px + f(p)
- **Q.** Define *Singular Solution*.  
  **Ans.** solution not obtained from general solution
- **Q.** Define *Solvable for p*.  
  **Ans.** factorise in p = dy/dx
- **Q.** Define *Newton's Law of Cooling*.  
  **Ans.** dT/dt = −k(T − Ts)
- **Q.** Define *Exponential Growth*.  
  **Ans.** dN/dt = kN
- **Q.** Define *RL Circuit*.  
  **Ans.** L di/dt + Ri = E

### Long answer (7 marks)

- **Q.** Explain *Exact Differential Equations* in detail with a neat diagram.  
  **Key points:** Exact equations come from a total differential. Exactness Condition — ∂M/∂y = ∂N/∂x; Integrating Factor — multiplier making equation exact; Solution — ∫M dx + ∫(terms of N without x) dy = c.
- **Q.** Explain *Linear & Bernoulli Equations* in detail with a neat diagram.  
  **Key points:** Linear first-order equations have closed forms. Linear Equation — dy/dx + Py = Q; Integrating Factor of Linear — e^(∫P dx); Bernoulli Equation — dy/dx + Py = Qy^n.
- **Q.** Explain *Equations of Higher Degree* in detail with a neat diagram.  
  **Key points:** Equations solvable for p, x or y. Clairaut's Equation — y = px + f(p); Singular Solution — solution not obtained from general solution; Solvable for p — factorise in p = dy/dx.
- **Q.** Explain *Applications of First Order ODEs* in detail with a neat diagram.  
  **Key points:** ODEs model growth, cooling and circuits. Newton's Law of Cooling — dT/dt = −k(T − Ts); Exponential Growth — dN/dt = kN; RL Circuit — L di/dt + Ri = E.

## Unit 2: Higher Order Linear ODEs

### Short answer (2-3 marks)

- **Q.** Define *Auxiliary Equation*.  
  **Ans.** replace D by m and solve
- **Q.** Define *Distinct Roots*.  
  **Ans.** y = c1e^(m1x) + c2e^(m2x)
- **Q.** Define *Complex Roots*.  
  **Ans.** y = e^(αx)(c1 cos βx + c2 sin βx)
- **Q.** Define *Complete Solution*.  
  **Ans.** CF + PI
- **Q.** Define *PI for e^(ax)*.  
  **Ans.** e^(ax)/f(a) if f(a) ≠ 0
- **Q.** Define *PI for sin ax*.  
  **Ans.** replace D² by −a²
- **Q.** Define *Variation of Parameters*.  
  **Ans.** uses Wronskian to find PI
- **Q.** Define *Wronskian*.  
  **Ans.** W = y1y2' − y2y1'
- **Q.** Define *Method of Undetermined Coefficients*.  
  **Ans.** guess PI form
- **Q.** Define *Cauchy-Euler Equation*.  
  **Ans.** x²y'' + axy' + by = f(x)
- **Q.** Define *Substitution*.  
  **Ans.** x = e^z converts to constant coefficients
- **Q.** Define *Legendre's Equation*.  
  **Ans.** (ax + b) form generalisation

### Long answer (7 marks)

- **Q.** Explain *Homogeneous Equations* in detail with a neat diagram.  
  **Key points:** Solution uses the auxiliary equation. Auxiliary Equation — replace D by m and solve; Distinct Roots — y = c1e^(m1x) + c2e^(m2x); Complex Roots — y = e^(αx)(c1 cos βx + c2 sin βx).
- **Q.** Explain *Particular Integral* in detail with a neat diagram.  
  **Key points:** PI handles the non-homogeneous term. Complete Solution — CF + PI; PI for e^(ax) — e^(ax)/f(a) if f(a) ≠ 0; PI for sin ax — replace D² by −a².
- **Q.** Explain *Variation of Parameters* in detail with a neat diagram.  
  **Key points:** General method for PI. Variation of Parameters — uses Wronskian to find PI; Wronskian — W = y1y2' − y2y1'; Method of Undetermined Coefficients — guess PI form.
- **Q.** Explain *Cauchy-Euler Equations* in detail with a neat diagram.  
  **Key points:** Variable coefficient equations reduce to constant. Cauchy-Euler Equation — x²y'' + axy' + by = f(x); Substitution — x = e^z converts to constant coefficients; Legendre's Equation — (ax + b) form generalisation.

## Unit 3: Partial Differential Equations

### Short answer (2-3 marks)

- **Q.** Define *PDE*.  
  **Ans.** equation with partial derivatives
- **Q.** Define *Order*.  
  **Ans.** highest derivative order
- **Q.** Define *Eliminating Arbitrary Functions*.  
  **Ans.** forms PDE from relation
- **Q.** Define *Lagrange's Equation*.  
  **Ans.** Pp + Qq = R
- **Q.** Define *Subsidiary Equations*.  
  **Ans.** dx/P = dy/Q = dz/R
- **Q.** Define *General Solution*.  
  **Ans.** φ(u, v) = 0
- **Q.** Define *Charpit's Method*.  
  **Ans.** general method for non-linear PDEs
- **Q.** Define *Complete Integral*.  
  **Ans.** solution with arbitrary constants
- **Q.** Define *Standard Form f(p,q)*.  
  **Ans.** 0 = z = ax + by + c
- **Q.** Define *Separation of Variables*.  
  **Ans.** assume u = X(x)T(t)
- **Q.** Define *Heat Equation*.  
  **Ans.** ∂u/∂t = c²∂²u/∂x²
- **Q.** Define *Wave Equation*.  
  **Ans.** ∂²u/∂t² = c²∂²u/∂x²

### Long answer (7 marks)

- **Q.** Explain *Formation of PDEs* in detail with a neat diagram.  
  **Key points:** PDEs arise by eliminating constants or functions. PDE — equation with partial derivatives; Order — highest derivative order; Eliminating Arbitrary Functions — forms PDE from relation.
- **Q.** Explain *Lagrange's Linear Equation* in detail with a neat diagram.  
  **Key points:** First order linear PDEs. Lagrange's Equation — Pp + Qq = R; Subsidiary Equations — dx/P = dy/Q = dz/R; General Solution — φ(u, v) = 0.
- **Q.** Explain *Non-linear First Order PDEs* in detail with a neat diagram.  
  **Key points:** Standard forms have known solutions. Charpit's Method — general method for non-linear PDEs; Complete Integral — solution with arbitrary constants; Standard Form f(p,q) — 0 = z = ax + by + c.
- **Q.** Explain *Method of Separation of Variables* in detail with a neat diagram.  
  **Key points:** PDEs are separated into ODEs. Separation of Variables — assume u = X(x)T(t); Heat Equation — ∂u/∂t = c²∂²u/∂x²; Wave Equation — ∂²u/∂t² = c²∂²u/∂x².
